Introduction
############

nProbe™ Agent is a lightweight probe that implements a low-overhead event-based monitoring, mostly based on technologies such as eBPF and Netlink.
nProbe™ Agent enhances network visibility by means of system introspection. It enriches classical network data such as IP addresses, bytes and 
packets with system-introspected processes, users, containers, orchestrators, and other performance indicators. 

Installation
============

nProbe™ Agent is currently available for Ubuntu 18.04 LTS and CentOS 7 (x64). They can installed using binary packages available at http://packages.ntop.org/ and installed as:

.. code:: bash

   apt-get install nprobe-agent

Licensing
=========

nProbe™ Agent requires a license per machine. The license is released according to the EULA (End User License Agreement). Each license is 
perpetual (i.e. it does not expire) and it allows to install updates for one year since purchase/license issue. Please read the 
`FAQ <https://www.ntop.org/support/faq/are-licenses-permanent-what-about-maintenance/>`_ for further information.

Licenses are generated using the orderId and email you provided when the license has been purchased on https://shop.ntop.org/.

Once the license has been generated, it can be applied in order for nProbe™ Agent to become fully-functional. The license must be placed in a 
one-line file :code:`/etc/nprobe-agent.license`. 

.. note::

   If you are using a container please read https://www.ntop.org/support/faq/license-inside-a-container/
