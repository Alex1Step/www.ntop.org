Конфигурация агента

nProbe Агент поддерживает несколько опций (параметров командной строки). Чтобы увидеть обновленный список, просто введите команду nprobe-agent -h. Пример:

-h                          | Print this help
-v                          | Verbose output
[-z|--zmq <option>]         | Specify the ZMQ endpoint to which JSON data will be delivered
[-k|--kafka <broker>,<topic>]
                            | Exports flows to the specified Kafka <topic>, using the list of
                            | brokers retrieved from the metadata obtained from <broker>
-e                          | Disable eBPF polling
-n                          | Disable Netlink polling
-l                          | Discard loopback information
-L                          | Discard listening sockets
[-V|--version]              | Display probe version
[-C|--check-license]        | Checks if the license is present and valid
[-M|--check-maintenance]    | Checks the maintenance status

Наиболее важные параметры кратко обсуждаются в разделах ниже.

ZMQ Экспорт

-z|--zmq <socket>

Укажите конечную точку (например, tcp://*:5556), который будет использоваться для доставки потоков подписчикам, опрашивающим сокет. Пример:

nprobe-agent --zmq tcp://\*:5556

ntopng можно использовать для анализа потоков, генерируемых агентом nProbe в формате от JSON до ZMQ. При использовании с ntopng, nProbe Агент может действовать как дистанционный и световой зонд, а ntopng — как центральный. консоль мониторинга сети. Пример:

ntopng -i tcp://*:1234c -m "192.168.2.0/24"

Kafka Экспорт

-k|--kafka <broker>,<topic>

Экспортировать данные в указанный Kafka <topic>. Список брокеров который будет использоваться для экспорта, получен из метаданных получено из <broker>.

В настоящее время данные eBPF и Netlink экспортируются в один и тот же <topic>.

Предполагая, что тема называется test доступен через брокер на 127.0.0.1:9092, можно использовать следующую конфигурацию

nprobe-agent -k 127.0.0.1:9092,test

Рабочий режим

-e

Отключает опрос eBPF. eBPF предоставляет информацию о потоках трафика (создание, удаление и обновление). Сюда входят события принятия/подключения/сбоя соединения/закрытия/повторной передачи для TCP, отправки/получения для UDP. Для запуска eBPF необходимы права администратора (root).

-n

Отключает опрос Netlink. Netlink предоставляет периодическую информацию о состоянии сети (например, об установленных соединениях) и статистику трафика на интерфейсах.

-l

Отбрасывает информацию для интерфейса обратной связи.

-L

Отбрасывает информацию для прослушивания сокетов.

Лицензия

--check-license

Проверяет, действительна ли настроенная лицензия.

--check-maintenance

Проверяет, действительна ли настроенная лицензия, и отображает информацию об обслуживании.

-V|--version

Этот флаг используется для печати номера и даты версии агента nProbe, а также другой информации.

Разное

-v

Используя этот флаг, агент nProbe генерирует подробный вывод.

-h: print help

Распечатывает справку агента nProbe.
