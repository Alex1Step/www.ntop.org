Запустите nProbe Агент как услугу.

Системы на базе Systemd

Служба агента nProbe (nprobe-агент) контролируется с помощью утилиты systemctl в операционных системах и дистрибутивах, использующих диспетчер служб systemd. Он использует файл конфигурации, расположенный по адресу /etc/nprobe-agent/nprobe-agent.conf, который во время установки заполняется некоторыми параметрами по умолчанию. Файл конфигурации можно редактировать и расширять с помощью любого параметра конфигурации, поддерживаемого nProbe Агентом (см. nprobe-агент -h). Пример:

$ cat /etc/nprobe-agent/nprobe-agent.conf
--zmq=tcp://127.0.0.1:1234c

Пожалуйста, проверьте Файл конфигурации раздел для получения дополнительной информации о формате файла конфигурации. После изменения файла конфигурации требуется перезапуск службы.

Старт и стоп

Чтобы запустить, остановите и перезапустите тип службы по умолчанию nProbe:

systemctl start nprobe-agent
systemctl stop nprobe-agent
systemctl restart nprobe-agent

Чтобы предотвратить запуск агента nProbe при типе загрузки:

systemctl disable nprobe-agent

Или чтобы запустить агент nProbe при загрузке, введите:

systemctl enable nprobe-agent

Чтобы проверить статус службы, включая ее выходные данные и PID, введите:

systemctl status nprobe-agent
