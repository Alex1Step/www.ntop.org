Файл конфигурации

Поскольку в некоторых случаях удобно иметь файл конфигурации, который будет использоваться в место параметров командной строки (это обязательно при запуске приложения например, как служба с systemd), можно запустить nProbe Агент предоставление пути к файлу конфигурации следующим образом:

nprobe-agent <configuration file path>

где файл конфигурации содержит те же параметры, которые указаны в командная строка. Единственная разница между командной строкой и конфигурацией заключается в том, что в разных строках необходимо указывать разные параметры. Например:

nprobe-agent --zmq tcp://127.0.0.1:1234c -l

то же самое, что:

nprobe-agent /etc/nprobe-agent/nprobe-agent.conf

где /etc/nprobe-agent/nprobe-agent.conf содержит следующие строки:

# cat /etc/nprobe-agent/nprobe-agent.conf
--zmq=tcp://127.0.0.1:1234c
-l
