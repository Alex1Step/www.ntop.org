Функции

Вот список некоторых уникальных функций, которые предоставляет nEdge:

  • Защитите DNS, чтобы заблокировать вредоносные домены.

  • Обеспечьте справедливое распределение пропускной способности между устройствами локальной сети.

  • Блокировать/регулировать нежелательные протоколы

  • Создавайте пользователей, чтобы группировать устройства и назначать политики ограничения блокировки/пропускной способности.

  • Защитите детей от нежелательного контента

  • Определите квоты времени/трафика для каждого пользователя и каждого протокола.

  • Определите настраиваемые политики маршрутизации с аварийным переключением и балансировкой нагрузки.

  • Настройка устройства вспомогательного мониторинга

Более того, поскольку nEdge основан на известном программном обеспечении для мониторинга ntopng, многое другое доступны интересные функции:

  • Обнаружение вредоносных хостов с помощью черных списков

  • Активное обнаружение и классификация активных устройств в сети.

  • Точная классификация трафика L7 благодаря nDPI

  • Множество данных о трафике, например, по каждому пользователю, стране, просмотрам операционной системы.

  • Просмотр потоков по хостам/устройствам

  • Отчеты о пробках и графики прошлого трафика

  • Система оповещений со слабой интеграцией

Однако некоторые из функций ntopng нет доступно в nEdge:

  • Нет профилей трафика

  • Нет возможности читать данные из nProbe (например, данные NetFlow/sFlow)

  • Нет интеграции LDAP

  • Нет мониторинга устройств SNMP

Предупреждение

В настоящее время трафик IPv6 не обрабатывается и не пересылается нЭдж. IPv6 трафик никогда не перенаправляется на устройства LAN или WAN.
