Резервное копирование конфигурации

Нажав «Конфигурация резервного копирования» под значок, можно загрузить nEdge конфигурация. При этом будет загружена копия конфигурации nEdge в виде сжатого архива (.tar.gz), включая:

  • Файл конфигурации (если для предоставления параметров не используется командная строка)

  • Конфигурация системы (system.config)

  • Конфигурация времени выполнения (runtimeprefs.json)

  • папка /etc/ntopng

  • Файл лицензии

Восстановление конфигурации

Конфигурацию nEdge можно восстановить, поместив сжатый архив. (загружается через конфигурацию резервного копирования) в каталог данных nEdge. и перезапуск службы. Архив должен называться conf.tar.gz.

Например, если каталог данных по умолчанию /var/lib/ntopng не был изменен, можно восстановить конфигурацию из резервной копии, поместив сжатый файл tarball в /var/lib/ntopng/conf.tar.gz, а затем выпустив systemctl restart nedge.

Примечание

После восстановления сжатый архив в директорию data. автоматически удаляется.

Примечание

Восстановление поддерживается только для упакованных установок ntopng на системы, использующие systemd.
