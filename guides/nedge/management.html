Управление устройствами

nEdge спроектирован так, чтобы быть (в значительной степени) безголовым. Почти каждый Функциональность программного обеспечения настраивается с помощью GUI. Это означает что также управление устройством может осуществляться просто из GUI. Однако могут быть случаи, когда потребуется системный администратор. вручную изменить некоторые конфигурации. Такие случаи могут быть для пример создания пользовательских сетевых интерфейсов для управления или для других задач.

В следующем разделе описывается, как nEdge обрабатывает конфигурации базовой системы и какая система администратор может вручную изменить такие конфигурации.

Сетевые интерфейсы

nEdge предназначен для перенастройки сетевых интерфейсов машины на котором он установлен.

Реконфигурация производится следующим образом:

  1. Существующие /etc/netplan/*.yaml файлы сохраняются в том же каталоге, что и суффикс «.old».

  2. Новый файл /etc/netplan/20-nedge.yaml создан, чтобы настроить сетевые интерфейсы на основе настроек GUI применяется.

  3. Если Cloud-init установлен, файл /etc/cloud/cloud.cfg.d/99-disable-network-config.cfg создан для отключения конфигурации сети Cloud-Init.

Администратор может настроить пользовательские интерфейсы в соответствующих файлах. в /etc/netplan после система nEdge настроена и конфигурация применена из nEdge GUI.
