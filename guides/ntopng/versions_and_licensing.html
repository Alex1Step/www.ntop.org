Доступные версии и лицензирование

Программное обеспечение ntopng поставляется в четырех версиях: Community, Professional, Enterprise M, Enterprise L и Enterprise L Bundle. Каждая версия открывает дополнительные функции по сравнению с меньшей.

Полный список возможностей и различий между версиями доступен в разделе ntopng. Страница продукта.

ntopng Сообщество

Версия сообщества бесплатна для использования и имеет открытый исходный код. Полный исходный код можно найти на Гитхаб.

ntopng Профессионал

Профессиональная версия предлагает некоторые дополнительные функции по отношению к Сообществу, которые особенно полезны для малого и среднего бизнеса, включая графические отчеты, профили трафика и аутентификацию LDAP / OIDC (SSO).

ntopng Предприятие М

Версия Enterprise M предлагает некоторые дополнительные функции по сравнению с версией Professional, которые особенно полезны для крупных организаций, включая поддержку SNMP, расширенное управление оповещениями. Enterprise M и все более высокие версии также включают нАналитик, агент-помощник по сетевой разведке AI; количество доступных инструментов nAnalyst растет с выходом версии (см. Инструменты nAnalyst и лицензирование).

ntopng Предприятие L

Версия Enterprise L предлагает некоторые дополнительные функции по сравнению с версией Enterprise M, включая быстрый экспорт ClickHouse, просмотр и анализ исторических данных, управление идентификацией (возможность сопоставлять пользователей с трафиком).

ntopng Пакет «Корпоративный L»

Пакет Enterprise L открывает доступ к ntopng Enterprise L, nProbe Pro (Flow Collection) и n2disk 1 Gbit (непрерывная запись).

Предупреждение

ntopng и nProbe должны находиться на одном компьютере, чтобы их можно было разблокировать с помощью лицензии ntopng Enterprise L Bundle. Пакетную лицензию необходимо поместить в /etc/ntopng/ntopng.license.

ntopng Предприятие XL/XXL/XXXL

Версия Enterprise XL/XXL/XXXL предлагает дополнительные функции и снимает некоторые ограничения с точки зрения количества хостов, устройств SNMP и количества коллекторов потока. Ниже на этой странице приведена таблица совместимости, в которой показаны различия между редакциями.

Лицензирование

Версия Community не требует какой-либо лицензии. Профессиональный и Предпринимательский версии требуют лицензии. ntopng автоматически переключается на одну из этих четырех версий, в зависимости от наличия лицензии.

Лицензия предназначена для каждого сервера и выпускается в соответствии с EULA (конечный пользователь). Лицензионное соглашение). Каждая лицензия является бессрочной (т.е. она не истекает) и позволяет устанавливать обновления в течение одного года с момента проблема с покупкой/лицензией. Это означает, что лицензия, созданная на 01.01.2021 можно будет активировать новые версии ПО до 31.12.2021. Если вы хотите установить новые версии программного обеспечения после этой даты вам необходимо возобновить техническое обслуживание или избежать дальнейшего обновление программного обеспечения. Для получения информации о ntopng на основе источника вы можете обратиться к Лицензия GPL-v3.

ntopng лицензии генерируются с использованием предоставленного вами идентификатора заказа и адреса электронной почты. когда лицензия была куплена на https://shop.ntop.org/.

После создания лицензии ее можно применить к ntopng просто посетив страницу «Настройки» -> «Лицензия» в Интернете GUI и вставка лицензионного ключа в форму лицензии.

Альтернативно, лицензионный ключ можно поместить в однострочный файл. ntopng.license:

  • В Linux файл необходимо поместить в /etc/ntopng.license

  • На Windows файл должен быть помещен в Program Files/ntopng/ntopng.license

Примечание

После применения лицензии рекомендуется перезапустить ntopng. чтобы убедиться, что все новые функции будут разблокированы.

Покупка лицензии

Первый шаг – покупка лицензии. Лицензии можно приобрести онлайн на сайте https://shop.ntop.org. Для оптовых закупок, скидок реселлеров или любых других особых требований, связанных с приобретением лицензий, вы можете контакт ntop напрямую. После успешного завершения покупки вы получите Идентификатор заказа.

Идентификатор заказа — числовой идентификатор, связанный с покупкой. Наряду с Идентификатор заказа вы также найдете электронная почта указанный во время процедуры покупки. Оба Идентификатор заказа и электронная почта необходимы для генерации лицензионного ключа.

Генерация лицензионного ключа

Лицензионные ключи генерируются по адресу https://shop.ntop.org/mkntopng/. Для генерации лицензионного ключа вам необходимо:

  • Идентификатор заказа получено после покупки и электронная почта указанный при процедуре покупки (см. Покупка лицензии).

  • Идентификатор системы, то есть идентификатор, связанный с хостом, на котором работает ntopng

  • ntopng версия, то есть строка, представляющая версию установленного ntopng (например, 5.1.210819).

Примечание

Идентификатор системы и версия можно получить только после успешной установки ntopng. Если вы еще не установили его, следуйте процедуре установки, указанной на https://packages.ntop.org/ прежде чем перейти к созданию лицензионного ключа.

Идентификатор системы и версия всегда можно получить на странице ntopng пользовательского интерфейса. «Помощь -> О программе»

В Linux, FreeBSD и других системах на базе Unix Идентификатор системы и версия также можно получить из командной строки, просто с помощью ntopng --version

Использование менеджера лицензий

Помимо стандартных лицензий, описанных выше, ntopng может использовать менеджер лицензий (LM). Пожалуйста, обратитесь к https://www.ntop.org/guides/nprobe/introduction.html#using-the-license-manager подробнее о LM.

Чтобы использовать LM, просто выполните `ntopng --license-mgr <licensemgr>.conf <other ntopng options>`.

Ниже вы можете найти пример файла конфигурации менеджера лицензий для ntopng:

LICENSE_MANAGER=127.0.0.1:9999

#
# Unique instance name
#
INSTANCE_NAME=dummy ntopng instance

#
# User authentication token
#
AUTH_TOKEN=fjfgsfgsj

#
# nprobe ntopng
#
PRODUCT_FAMILY=ntopng

#
# pro enterprise_s enterprise_m enterprise_l
#
PRODUCT_EDITION=enterprise_m

где

  • LICENSE_MANAGER — это IP-адрес и порт хоста, на котором работает LM.

  • INSTANCE_NAME — это строка, используемая для определения данного конкретного экземпляра.

  • AUTH_TOKEN — это токен, который LM может использовать для предотвращения выдачи действительных лицензий для неизвестного AUTH_TOKEN. Его значение необходимо настроить в LM.

  • PRODUCT_FAMILY и PRODUCT_EDITION определяют, какую лицензию будет использовать приложение ntop в качестве LM при обращении к нему.
