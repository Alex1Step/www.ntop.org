Установка

Для установки ClickHouse обратитесь к официальному гид используя следующие пакеты:

  • Debian/Ubuntu: https://clickhouse.com/docs/en/install/#install-from-deb-packages

  • RedHat/RockyLinux: https://clickhouse.com/docs/en/install/#from-rpm-packages

  • FreeBSD/Другое: https://clickhouse.com/docs/en/install#quick-install (читайте примечания ниже)

Предупреждение

  • Убедитесь, что ClickHouse версия 22 или новее установлен. Старые версии не поддерживаются, поскольку в них отсутствуют важные функции, такие как уровень совместимости MySQL.

  • Если несколько экземпляров ntopng записываются в такой же ClickHouse базы данных, у них должны быть разные имена экземпляров. По умолчанию ntopng использует имя хоста в качестве имени экземпляра, но в случае, если такие имена не уникальный, пожалуйста, рассмотрите возможность использования --instance-name Параметр командной строки, позволяющий установить уникальное значение имени пользовательского экземпляра для всех экземпляров ntopng, записывающих в одну и ту же базу данных.

Примечание

База данных ClickHouse (сервер) может работать где угодно, как локально на машине, на которой работает ntopng, так и на удаленной машине. Однако клиент clickhouse (clickhouse или clickhouse-client) всегда должен быть установлен локально, так как он используется ntopng для подключения к серверу ClickHouse.

FreeBSD Примечания

На FreeBSD убедитесь, что двоичный файл clickhouse помещен в /usr/local/bin, чтобы его мог обнаружить ntopng.

Скачать бинарный файл можно, следуя инструкциям, доступным на официальном сайте. гиди установите его с помощью ./clickhouse install или вручную следующим образом:

curl https://clickhouse.com/ | sh
mv clickhouse /usr/local/bin/

Конфигурация кластера

Для крупных развертываний или репликации данных кластер является лучшим вариантом по сравнению с развертыванием автономной базы данных. В эта страница мы делимся простыми заметками по настройке для развертывания кластера ClickHouse за считанные минуты.

ClickHouse Облако

В случае, если вместо ClickHouse Облака, настройка довольно проста; после создания сервиса в облаке ClickHouse включите подключение MySQL из Соединять раздел. Затем добавьте в файл конфигурации ntopng -Ф опция правильно настроена:

clickhouse-cloud;<host[@port]|socket>;<dbname>;<clickhouse-user>,<mysql-user>;<pw>;<cluster name>

Например:

./ntopng -F "clickhouse-cloud;my-cloud-host.clickhouse.org@9440,3306s;ntopng;ch-user,mysql-user;ch-password"

Примечание

с после портов означает использование защищенного соединения, дополнительную информацию см.

Примечание

Даже при использовании ClickHouse Cloud на локальном компьютере необходим clickhouse-клиент.

ClickHouse Тюнинг

Конфигурация службы по умолчанию ClickHouse не оптимизирована с точки зрения использования памяти и диска. Чтобы уменьшить использование таких ресурсов, пожалуйста, обратитесь к этому руководству которые подробно объясняют, как оптимизировать конфигурацию базы данных.
