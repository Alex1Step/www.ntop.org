Отправка сообщений на Kafka

Помимо экспорта и сбора потоков, вы можете использовать kafka из сценариев Lua для доставки сообщений удаленным получателям. Этого можно добиться с помощью вызова API ntop.sendKafkaMessage(<broker>,<message>). Эта функция принимает на вход две строки:

  • строка брокера указывает, как подключиться к инфраструктуре Kafka. Его формат <broker IPs>;<topic>;<options>. Как уже было описано, IP-адреса брокеров разделяются запятыми (,) и могут иметь дополнительный порт. topic указывает, куда доставлять сообщения, и <options> содержит дополнительные спецификации, используемые при соединении с брокером. Вы можете прочитать весь список поддерживаемые опции kafka чтобы узнать, какие опции поддерживаются.

  • строковое сообщение, которое будет доставлено в указанную тему.

Пример

Ниже вы можете найти несколько примеров:

  • Отправьте строку «Hello World» в тему hello: ntop.sendKafkaMessage("127.0.0.1;hello;", "Hello World")

  • Отправьте сообщение «Передай привет ntopng!» строка в тему брокера 192.168.1.1:9092, информация через сжатое соединение: ntop.sendKafkaMessage("192.168.1.1;info;compression.codec=gzip", "Hello World")
