Питон API

ntopng предоставляет Python 3 API для запроса движка и получения информации о трафике с помощью языка Python.

API основан на ntopng REST API и позволяет пользователям выполнять такие операции, как:

  • Чтение статистики хоста

  • Получить список активных потоков

  • Запросить статистику сетевого интерфейса

  • Поиск исторических потоков

Для каждого компонента ntopng существует соответствующий класс Python (Host, Interface, Historical), а для каждого вызова REST API существует соответствующий метод. Класс ntopng используется для хранения информации о конфигурации ntopng, включая IP-адрес и учетные данные, необходимые для подключения.

Предварительные условия

API использует Pandas и NumPy для работы с данными временных рядов,plotly и fpdf для создания отчетов в формате PDF, а также несколько дополнительных библиотек.

pip3 install -r requirements.txt

Установка

Для вашего удобства ntop периодически собирает пакеты pip. Вы можете установить последний доступный пакет следующим образом:

pip3 install ntopng

Примеры

Несколько примеров приложений распространяются с исходным кодом ntopng и доступны по адресу https://github.com/ntop/ntopng/tree/dev/python/examples

Все примеры требуют:

  • ntopng URL (опция -n, локальный хост: 3000 по умолчанию)

  • ntopng учетные данные

    • ntopng пользователь (опция -u, администратор по умолчанию) и пароль ntopng (опция -p, администратор по умолчанию)

    • или ntopng Токен (https://www.ntop.org/guides/ntopng/user_interface/shared/settings/preferences.html#token-based-authentication)

В некоторых примерах также требуется идентификатор интерфейса ntopng (опция -i) и дополнительные параметры (например, хост).

Пример:

python3 alerts.py -n http://localhost:3000 -i admin -p password -i 0

Этот пример приложения печатает статистику предупреждений. Ниже приведен фрагмент кода, позволяющий добиться того же:

# Connect to ntopng using the Ntopng class
my_ntopng = Ntopng(username, password, auth_token, ntopng_url)

# Get an Historical instance for a specific interface by ID
my_historical = my_ntopng.get_historical_interface(iface_id)

# Read alert statistics
data = my_historical.get_alerts_stats(epoch_begin, epoch_end)

# Print the raw statistics
print(data)
