3. Спецификация RESTful API v1

3.1. Аутентификация

Следует использовать аутентификацию HTTP/HTTPS, например, с завиток можно указать имя пользователя и пароль с помощью -u <user>:<password>

В целях безопасности рекомендуется использовать HTTPS. Видеть этот пост чтобы включить HTTPS.

3.2. Формат запроса

Параметры могут быть предоставлены как с помощью GET со строкой запроса, так и с помощью POST с помощью JSON (в этом случае убедитесь, что правильный Тип контента указан). Например, чтобы загрузить данные для хоста, вы можете используйте ниже завиток командная строка с помощью GET:

curl -s -u admin:admin "http://192.168.1.1:3000/lua/rest/v1/get/host/data.lua?ifid=1&host=192.168.1.2"

или ниже завиток командная строка с использованием POST:

curl -s -u admin:admin -H "Content-Type: application/json" -d '{"ifid": "1", "host": "192.168.1.2"}' "http://192.168.1.1:3000/lua/rest/v1/get/host/data.lua"

Пожалуйста, проверьте Примеры раздел для получения дополнительных примеров.

3.3. Формат ответа

Ответ API обычно представлен сообщением JSON, соответствующим стандартной структуре. Это сообщение JSON представляет собой конверт, содержащий:

  • код возврата ЖК

  • удобочитаемая строка rc_str описание кода возврата

  • реальный ответ в РСП

Пример:

{
 "rc": 0
 "rc_str": "OK",
 "rsp": {
    ...
 }
}
