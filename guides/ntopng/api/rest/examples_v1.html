4.2.3. Получить пользовательские данные хоста

Получите пользовательские данные хоста: «ip,bytes.sent=tdb,packets.sent» для хоста: «10.222.222.119» на интерфейс мониторинга (ifid): 0. Доступные поля можно найти из вывода из «Получить данные хоста» выше. Каждое поле может иметь необязательное имя-псевдоним. Использование синтаксис «field=alias» для определения псевдонима поля. Отделите каждый поле/псевдоним поля через запятую.

завиток

curl --silent --insecure -u "admin:admin" \
  -H "Content-Type: application/json" -d '{"ifid": 0, "host": "10.222.222.119", "field_alias": "ip,bytes.sent=tdb,packets.sent"}' \
  "https://localhost:3001/lua/rest/v1/get/host/custom_data.lua"

Ответ:

{
  "rc_str": "OK",
  "rc": 0,
  "rsp": {
    "tdb": 71787960,
    "ip": "10.222.222.119",
    "packets.sent": 243977
  }
}
