Метрики

Вот полный список метрик, экспортированных в виде временных рядов по ntopng.

В настоящее время ntopng экспортирует два типа метрик: счетчики и датчики.

  • счетчики используются для непрерывного увеличения показателей, таких как общее количество байтов.

  • датчики используются для таких показателей, как количество активных потоков или активных хостов в определенный момент времени.

ntopng поддерживает два бэкэнда для хранения таймсерий: RRD и InfluxDB. Поддерживаемое разрешение может измениться на основе серверной части и может быть настроен через настройки времени выполнения (это случай InfluxDB для некоторые показатели, как указано ниже).

  • Разрешение: то же, что flowdev_port:ndpi

Теги

То же, что flowdev_port:ndpi, ifid, device и port являются обязательными.
