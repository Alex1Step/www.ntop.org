Metrics

Here is the full list of metrics exported as timeseries by ntopng.

There are two types of metrics exported by ntopng currently: counters and gauges.

  • counters are used for continuous incrementing metrics such as the total number of bytes.

  • gauges are used for metrics such as the number of active flows or active hosts at a certain point in time.

ntopng supports two backends for storing timeseries: RRD and InfluxDB. The supported resolution may change based on the backend and can be configured through the Runtime Preferences (this is the case of InfluxDB for some of the metrics as reported below).

flowdev_port:ndpi_usage

Usage of an application on a port of a flow device, as percentage of the configured port speed. This metric is not stored: it is calculated at query time from flowdev_port:ndpi and the port uplink/downlink speed, so it is only available through the timeseries REST API (e.g. /lua/rest/v2/get/timeseries/ts.lua).

  • Type: gauge (derived)

  • Resolution: same as flowdev_port:ndpi

Tags

Same as flowdev_port:ndpi, ifid, device and port are mandatory.

Fields

Name

Description

bytes_sent

Uplink (out) usage percentage.

bytes_rcvd

Downlink (in) usage percentage.

The top applications usage, for a single direction, can be requested with the top:flowdev_port:ndpi_usage_downlink and top:flowdev_port:ndpi_usage_uplink schemas.
