Доступ к метрикам

Полный список всех метрик, уже встроенных и экспортированных в виде таймсерий в ntopng, доступен в разделе «Метрики». В этом разделе представлено несколько примеров доступа к этим метрикам.

Метрики интерфейса

Поддерживаемые метрики для создания временных рядов интерфейса:

  • Отправленные и полученные байты приложений уровня 7

  • Уровень-4 TCP, UDP, ICMP отправленных и полученных байтов

  • Общее количество отправленных и полученных байтов

  • Всего оповещений

  • и т. д.

Постоянно обновляемый список метрик можно определить, проверив метод NetworkInterface::lua: https://github.com/ntop/ntopng/blob/dev/src/NetworkInterface.cpp

Метрики интерфейса доступны в виде таблицы Lua. Отрывок из такого таблица показана ниже:

speed number 1000
id number 1
stats table
stats.http_hosts number 0
stats.drops number 0
stats.devices number 2
stats.current_macs number 6
stats.hosts number 23
stats.num_live_captures number 0
stats.bytes number 50559082
stats.flows number 30
stats.local_hosts number 3
stats.packets number 64984

Метрики хоста

Поддерживаемые метрики для создания временных рядов хоста:

  • Отправленные и полученные байты приложений уровня 7

  • Уровень-4 TCP, UDP, ICMP отправленных и полученных байтов

  • Общее количество отправленных и полученных байтов

  • Активные потоки как клиент и как сервер

  • Аномальные потоки как клиента, так и сервера

  • Всего оповещений

  • Количество хостов, к которым обращаются в качестве клиента

  • Количество контактов хостов в качестве сервера

Постоянно обновляемый список метрик хоста можно определить, проверив этот файл: https://github.com/ntop/ntopng/blob/dev/src/HostTimeseriesPoint.cpp

Метрики хоста доступны в удобной таблице Lua, например пример ниже:

ndpi_categories table
ndpi_categories.Cloud number 2880
misbehaving_flows.as_server number 0
active_flows.as_client number 0
bytes.rcvd number 2880
icmp.bytes.rcvd number 0
tcp.bytes.rcvd number 0
total_alerts number 0
udp.bytes.rcvd number 2880
icmp.bytes.sent number 0
other_ip.bytes.rcvd number 0
other_ip.bytes.sent number 0
misbehaving_flows.as_client number 0
contacts.as_server number 1
bytes.sent number 0
instant number 1550836500
tcp.bytes.sent number 0
udp.bytes.sent number 0
contacts.as_client number 0
ndpi table
ndpi.Dropbox string 0|2880
active_flows.as_server number 1

В частности, протоколы приложений уровня 7 помещаются в таблицу. ndpi, чьи ключи являются именами приложений, например Dropbox. Для каждого приложения есть два разделенных значения. по каналу, а именно отправленные и полученные байты. Например, в отрывок выше, Dropbox приложение получило 0 байт и на момент создания отрывка отправил 2880 байт.

Таблица также содержит поле instant что представляет собой время выборки показателей.

К приведенной выше таблице можно получить доступ, а ее содержимое можно прочитать/изменить. подготовить точки таймсерий.
