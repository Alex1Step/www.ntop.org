Основные понятия

Вот краткое введение в некоторые фундаментальные концепции API.

Схема

Схему можно рассматривать как таблицу базы данных. Он определяет формат и типы данных. Схема идентифицируется по своему имени и содержит следующую информацию:

  • Шаг: ожидаемый интервал в секундах между точками необработанных данных.

  • Теги: тег — это метка, которую можно использовать для фильтрации данных. Пример тегов: имя интерфейса, имя хоста и имя протокола nDPI.

  • Метрики: метрика — это частное значение, которое измеряется. Пример показателей: байты хоста, отправленные трафиком, количество потоков интерфейса и время прохождения ASN туда и обратно. Все метрики должны соответствовать указанному типу (см. ниже).

  • Тип: тип всех метрик схемы. В настоящее время «счетчик» или «датчик».

  • Опции: некоторые опции, специфичные для драйвера.

Все схемы, определенные ntopng, можно найти в скрипты/lua/модули/таймсерии/схемы. Схемы разделены на 3 файла, по одному на каждый периодический сценарий, чтобы не тратить время на загрузку. ненужные схемы. Тем не менее, включив ts_utils модуль, все доступные схемы загружаются автоматически.

Имя схемы

Имя схемы состоит из двух частей:

  • Префикс схемы, например «хост».

  • Суффикс схемы, например «ndpi».

Обе части разделены одной :, например, «host:ndpi» является допустимым имя схемы и указывает трафик приложения nDPI хоста. Только один допускается двоеточие, пробелы не допускаются. Для новых схем важно выбрать единообразное имя схемы.

Вот некоторые распространенные используемые префиксы схемы:

  • iface: схемы сетевых интерфейсов (например. iface:трафик)

  • host: схемы для локальных хостов

  • mac: схемы для устройств L2

  • asn: схемы для автономных систем

  • subnet: схемы для локальных сетей

  • country: схемы для стран

  • vlan: схемы для VLAN

Вот некоторые распространенные используемые суффиксы схемы:

  • traffic: схемы для таймсерий байтов (например. хост: трафик)

  • ndpi: схемы для таймсерий приложения nDPI

  • ndpi_categories: схемы для временных рядов категории nDPI

Обычно префикс схемы появляется также как тег в таймсериях и используется для идентификации элемента (например, схемы asn:ndpi как тег асн который держит номер АС).

Типы метрик

ntopng предоставляет метрики двух типов, а именно датчики и счетчики. Таймсерии могут быть созданы из датчиков и счетчиков. прозрачно. Единственное, что необходимо, это рассказать таймсерии фактический тип, то rest будет обрабатываться автоматически.

  • Счетчики предназначены для непрерывного увеличения показателей, таких как общий объем количество байтов (например, bytes.sent, bytes.rcvd). Это наиболее распространенный тип метрик для сетей.

  • Датчики — это такие показатели, как количество активных потоков. (например, active_flows.as_client, active_flows.as_server) или активный хосты в определенный момент времени.

Водитель

Таймсерия водитель реализует четко определенный интерфейс для обеспечения поддержки конкретная база данных. В настоящее время ntopng предоставляет драйверы RRD и InfluxDB для связи. с соответствующими базами данных.
