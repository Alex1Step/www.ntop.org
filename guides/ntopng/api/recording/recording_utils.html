Record_utils API

Параметры извлечения:

  • время_от: эпоха

  • time_to: эпоха

  • фильтр: фильтр nBPF

Запись параметров конфигурации:

  • размер_буфера: Размер буфера (MB)

  • max_file_size: Максимальная длина файла (MB)

  • max_file_duration: Максимальная продолжительность файла (сек)

  • max_disk_space: Максимальное дисковое пространство (MB)

  • Снэплен: Длина захвата

  • писатель_ядро: Связность потоков записи

  • reader_core: Сходство потоков чтения

  • indexer_cores: Сходство потоков индексатора

  • zmq_конечная точка: ZMQ конечная точка (необязательно)
