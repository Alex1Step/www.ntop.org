Управление оповещениями

nAnalyst может исследовать, контекстуализировать и подавлять оповещения, не требуя от аналитика вручную сопоставлять данные в нескольких представлениях.

Тревожное расследование

При срабатывании оповещения вы можете попросить nAnalyst объяснить его:

"Why did host 10.0.1.20 trigger a port scan alert?"

"Is the DNS tunnelling alert on 192.168.5.3 a false positive?"

nАналитик будет:

  1. Получение сведений об оповещениях и связанных потоках

  2. Извлеките исторический контекст трафика для задействованных хостов.

  3. Перекрестная ссылка на инвентаризацию активов и известное хорошее поведение.

  4. Верните объяснение с подтверждающими доказательствами.

Подавление оповещений (отключение звука)

Для оповещений, подтверждающих ложные срабатывания или заведомо хорошее поведение, nAnalyst может создавать исключения непосредственно из чата:

"Silence the certificate expiry alert for internal.corp.example.com"

"Add an exclusion for the domain alert on cdn.vendor.com"

Поддерживаемые типы исключений:

  • Исключения оповещений хоста — подавить определенный тип оповещения для данного хоста

  • Исключения оповещений о доменах — подавлять оповещения, вызванные заведомо исправным доменом

  • Исключения оповещений о сертификатах — подавлять предупреждения сертификатов TLS для внутренних или известных хостов

Все исключения записываются в журнал аудита с указанием ответственного пользователя и причины.

Рабочий процесс реагирования на инциденты

Типичный процесс обработки инцидентов с помощью AI с помощью nAnalyst:

  1. Тревога срабатывает в ntopng

  2. Аналитик спрашивает nAnalyst: «Изучите это предупреждение»

  3. nAnalyst извлекает потоки, историю хостов и данные геолокации.

  4. Журнал доказательств собран и показан

  5. nAnalyst предлагает: подтвердить вредоносность → создать политику; или подтвердите доброкачественность → отключить оповещение

  6. Аналитик одобряет действие; nAnalyst выполняет это

  7. Действие записывается в журнал аудита.
