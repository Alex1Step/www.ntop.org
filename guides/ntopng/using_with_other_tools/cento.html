Использование ntopng с nProbe Cento

nProbe Ченто является высокопроизводительным датчик потока, предназначенный для обработки сетевого трафика на линейной скорости (10/40/100Gbit и выше) с использованием технологии аппаратного ускорения захвата, такие как PF_RING ЗЦ. Он отделяет тяжелую обработку пакетов от анализа и визуализации, выполняемых ntopng, что делает его рекомендуемым решением для мониторинга больших или высокоскоростных сетей.

Примечание

Для работы Cento на линейной скорости требуется лицензия nProbe Cento и PF_RING ZC. высокоскоростные адаптеры.

ntopng может собирать потоки от nProbe Cento двумя способами:

  • ZMQ: объем экспорта Cento превышает от ZMQ до ntopng. Это работает по сети и поддерживает удаленные ntopng экземпляры. Это тот же механизм, который используется nProbe.

  • PF_RING Очередь ZC: Локальное соединение с копией zero между Cento и ntopng, работающее на один и тот же физический хост, обеспечивающий высочайшую производительность.

Кроме того, Cento может экспортировать потоки непосредственно в ClickHouse база данных, которая ntopng может затем запросите анализ и визуализацию исторического потока. Это описано в Сброс потока до ClickHouse раздел.

Сбор потоков через ZMQ

Интеграция между Cento и ntopng на основе ZMQ работает так же, как описано в Использование ntopng с nProbe раздел. Cento выступает в качестве издателя ZMQ, а ntopng — в качестве ZMQ подписчик (или коллектор).

Ниже приведен пример минимальной рабочей конфигурации, предполагающий, что Cento и ntopng работают на тот же хозяин. Если они работают на разных машинах, замените 127.0.0.1 с IP-адрес машины, на которой размещен Cento.

ntopng Конфигурация

ntopng -i tcp://127.0.0.1:5556c

Конфигурация Центо

cento -i zc:eth1 --zmq tcp://127.0.0.1:5556

Cento выступает в роли инициатора соединения, а завершающий c в конечной точке ntopng сообщает ntopng о прослушивании входящего соединения (режим коллектора).

Сбор потоков через PF_RING ZC

Когда Cento и ntopng работают на одном физическом хосте, сокет PF_RING ZC обеспечивает zero-копия, альтернатива ZMQ с меньшей задержкой. В этом режиме Cento передает потоки напрямую до ntopng без каких-либо накладных расходов на сериализацию.

Запустите Cento с помощью --monitor|-A опция, позволяющая включить экспорт сокетов ZC. Ченто напечатает имя интерфейса, которое будет использоваться в ntopng в журнале запуска, например:

ntopng -i zcflow:10@0

Примечание

Очередь PF_RING ZC представляет собой только локальное соединение и поддерживает одного потребителя. Используйте ZMQ, если ntopng работает на другом хосте или если требуется несколько потребителей.

Для сценариев с несколькими очередями захвата и прямым мониторингом Cento можно запустить как:

cento -i zc:eth1@[0-3] -A --direct-monitor

Это устраняет накладные расходы на агрегацию и обеспечивает параллельную обработку нескольких ntopng интерфейсы.

Шифрование данных

ntopng и Cento поддерживают шифрование данных через ZMQ на основе собственного шифрования CURVE. поддержка в ZMQ (доступна с ZMQ >= 4.1).

Шифрование теперь включено по умолчанию: ntopng больше не принимает открытый текст ZMQ трафик по умолчанию. Если шифрование не настроено явно пользователем, ntopng (и Cento) вернитесь к общедоступной встроенной паре ключей по умолчанию. Этот ключ по умолчанию предотвращает только случайное раскрытие открытого текста и должно быть заменено правильной настройкой выделенной пары ключей.

Чтобы настроить выделенную пару ключей, добавьте --zmq-encryption вариант для ntopng конфигурация. Пара частного/открытого ключей автоматически генерируется с помощью ntopng и открытый ключ отображается на странице состояния интерфейса.

Затем открытый ключ следует настроить в Cento с помощью --zmq-encryption-key '<pub key>' вариант.

Пример:

  • Начните ntopng следующим образом: ntopng -i tcp://127.0.0.1:5556c --zmq-encryption

  • Подключитесь к сети ntopng GUI, перейдите на страницу состояния интерфейса ZMQ и скопируйте ценность --zmq-encryption-key '...'

  • Запустите Cento следующим образом: cento -i zc:eth1 --zmq tcp://127.0.0.1:5556 --zmq-encryption-key '<pub key>'

Примечание

Если не указан закрытый ключ, ntopng генерирует пару открытого/закрытого ключей и сохраняет это под /var/lib/ntopng/key.{pub,priv}.

Если шифрование вообще нежелательно (например, в полностью доверенной сети или в старых развертываниях) с экземплярами Cento, экспортирующими открытый текст ZMQ), его можно отключить с помощью --zmq-disable-encryption.

Сброс потока до ClickHouse

nProbe Cento может экспортировать потоки напрямую в ClickHouse база данных, минуя канал ZMQ. ntopng затем подключается к тому же экземпляру ClickHouse в режиме только для чтения для анализ и визуализация исторических потоков.

Архитектура соответствует этому шаблону:

Network Traffic --> nProbe Cento (write) --> ClickHouse <-- ntopng (read-only)

Этот подход особенно подходит для высокоскоростных сред, где хранятся все потоки. через ntopng станет узким местом.

Опции Cento ClickHouse

Следующие параметры Cento управляют экспортом ClickHouse:

  • --clickhouse <host[:port]> — адрес сервера ClickHouse и собственный порт TCP (порт по умолчанию: 9000). Добавить s чтобы включить SSL (например. 192.168.1.1:9000s).

  • --clickhouse-auth <user:password> — Учетные данные пользователя ClickHouse. Пользователь по умолчанию default.

  • --clickhouse-dbname <name> — Имя целевой базы данных ClickHouse. По умолчанию ntopng, что соответствует соглашению об именах ntopng.

  • --clickhouse-interface-id <id> — Потоки ассоциированных компаний, экспортируемые Cento с определенным идентификатором интерфейса ntopng, необходимым для привязки потоков к правильному ntopng интерфейс. Значение по умолчанию: 0.

Пример конфигурации

Шаг 1 — Запустите nProbe Cento с экспортом ClickHouse:

cento -i zc:eth1 --zmq tcp://127.0.0.1:5556 --clickhouse 192.168.1.1 --dpi-level 2

Шаг 2 — Запустите ntopng в режиме дампа потока только для чтения:

ntopng -i tcp://*:5556c -F clickhouse --readonly-flows-dump

--readonly-flows-dump опция сообщает ntopng не записывать потоки в ClickHouse сам по себе, поскольку Cento является автором в этой настройке.

Для локального комплексного развертывания, где Cento, ClickHouse и ntopng работают на одном и том же хозяин:

cento -i zc:eth1 --clickhouse 127.0.0.1 --clickhouse-interface-id 1
ntopng -i tcp://*:5556c -F clickhouse --readonly-flows-dump
