Использование ntopng с nProbe (режим коллектора)

ntopng в режиме коллектора прослушивает входящие данные через ZMQ. Один или несколько nProbe могут подключить ntopng для отправки своих данных.

Для запуска ntopng в режиме коллектора укажите доп. c в конце конечной точки ZMQ.

Например, чтобы запустить ntopng в режиме коллектора и прослушивать входящие соединения nProbe на порту. 5556 можно использовать следующую конфигурацию

ntopng -i tcp://*:5556c

Звездочка * сообщает ntopng прослушивать любой доступный адрес. Вместо звездочки можно указать конкретный адрес, например,

ntopng -i tcp://127.0.0.1:5556c

В приведенной выше конфигурации ntopng будет прослушивать только соединения nProbe, поступающие на localhost.

Для подключения экземпляров nProbe к ntopng, прослушивающих в режиме коллектора, IP-адрес ntopng и дополнительные --zmq-probe-mode должен быть указан в конфигурации nProbe.

Например, чтобы подключить nProbe к экземпляру ntopng, работающему в режиме сборщика на хосте. 192.168.2.222 порт 5556 можно использовать

nprobe --zmq tcp://192.168.2.222:5556 --zmq-probe-mode <other nprobe options>

Несколько экземпляров nProbe можно подключить к одному и тому же экземпляру ntopng, работающему в режиме коллектора, используя одну и ту же конфигурацию. ntopng способен автоматически распознавать отдельные экземпляры nProbe.

Примечание

Количество экземпляров nProbe, которые можно подключить к одному экземпляру ntopng, ограничено и зависит от лицензии. Проверьте страницу продукта nProbe, чтобы узнать фактические ограничения.

Варианты использования

Необходимо запустить ntopng в коллекторном режиме, когда

  • Несколько экземпляров nProbe необходимо подключить к одному и тому же ntopng.

  • nProbe находится за брандмауэром и, следовательно, должен быть инициатором соединения.

Видеть Использование ntopng с nProbe для получения дополнительной информации.
