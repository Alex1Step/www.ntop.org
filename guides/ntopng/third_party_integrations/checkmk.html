Checkmk Интеграция

ntopng легко интегрируется с Checkmk, популярным инструментом мониторинга инфраструктуры с открытым исходным кодом, обеспечивая комплексную видимость трафика наряду с традиционным мониторингом ИТ-инфраструктуры. Эта интеграция сочетает в себе общую картину мониторинга ИТ-инфраструктуры с подробной информацией об использовании сети из ntopng.

Обзор

Интеграция делает данные говорящих и слушателей, обнаруженных ntopng, напрямую доступными в Checkmk. Он добавляет информацию о сетевых потоках из ntopng на соответствующие хосты в Checkmk, объединяя все данные в одно решение с несколькими панелями мониторинга и опциями построения графиков. Это позволяет ускорить анализ первопричин с меньшими усилиями.

Благодаря использованию REST и API ntopng интеграция устраняет необходимость перехода между ntopng и вашим инструментом мониторинга ИТ-инфраструктуры. Информация о сетевом потоке из ntopng автоматически распределяется между хостами при мониторинге Checkmk, объединяя информацию, собранную Checkmk, с наиболее важной информацией о трафике из ntopng.

Варианты использования

Интеграция предлагает несколько представлений и информационных панелей в Checkmk для поддержки различных сценариев мониторинга:

  • Анализируйте хосты, приложения или протоколы, взаимодействующие друг с другом.

  • Выявление возможных узких мест или аномалий

  • Определите «самых говорящих» и «лучших слушателей» в вашей сети

  • Просмотр использования сети на хост и другие подробные показатели

  • Импортируйте уведомления из ntopng и объединяйте их с оповещениями об инфраструктуре.

Предварительные условия

Прежде чем настраивать интеграцию, убедитесь, что у вас установлены правильные версии:

ntopng Требования: - Профессиональная или Корпоративная версия 4.2 или выше. - REST API Поддержка V1 (доступно начиная с версии 4.2)

Checkmk Требования: - Версия Enterprise Edition 2.0 или выше - ntopng надстройка интеграции (платно)

Примечание

Доступна бесплатная пробная версия Checkmk Enterprise Edition, которая включает в себя все функции, но ограничена 25 хостами через 30 дней.

Настраивать

Подготовка: настройка параметров ntopng

Checkmk требуется учетная запись пользователя в ntopng для доступа к данным. Вы можете ограничить доступ, используя пользователя ntopng с ограниченными привилегиями, в зависимости от вашей среды и того, какие сетевые интерфейсы вы хотите использовать совместно с Checkmk.

В этом уроке мы будем использовать самый простой вариант: пользователь ntopng с доступом администратора, который предоставляет Checkmk полный доступ ко всем интерфейсам.

Вам понадобится: - ntopng имя пользователя и пароль - ntopng имя хоста сервера и TCP порт - Сетевое подключение от сервера Checkmk к серверу ntopng.

Шаг 1. Настройте пользователя ntopng в Checkmk

  1. Откройте свой сайт Checkmk и перейдите к Настройка → Общие → Глобальные настройки.

  2. Нажмите на Ntopng (платная надстройка)

  3. Нажмите на Ntopng Параметры подключения (платная надстройка)

  4. Настройте следующие параметры:

    • Адрес хоста: имя хоста вашего сервера ntopng (должно быть DNS, разрешаемым для TLS)

    • Номер порта: порт TCP для ntopng (по умолчанию: 3000 для HTTP, 3001 для HTTPS)

    • Протокол: выберите HTTPS для обеспечения безопасности (отметьте SSL отключение проверки для самозаверяющих сертификатов)

    • Учетная запись пользователя для аутентификации: ntopng имя пользователя для доступа к данным

    • ntopng имя пользователя получить данные для: выберите подходящий вариант в зависимости от настроек вашего имени пользователя.

Шаг 2. Добавьте имя пользователя ntopng к пользователю Checkmk.

Если вы используете разные имена пользователей для учетных записей Checkmk и ntopng:

  1. Перейдите к Настройка → Пользователи

  2. Выберите свойства вашего пользователя Checkmk, щелкнув значок карандаша.

  3. Добавьте имя пользователя ntopng в ntopng Имя пользователя поле под Личность

  4. Нажмите Сохранять

  5. Активируйте изменения, щелкнув желтый восклицательный знак и выбрав Активировать на выбранных сайтах

Примечание

Пропустите этот шаг, если используете одинаковые имена пользователей в обеих системах.

Шаг 3. Проверьте интеграцию

  1. Нажмите Монитор в боковой панели

  2. Найдите новую тему под названием Статистика сети

  3. Это подтверждает, что интеграция работает правильно.

Шаг 4. Добавьте хосты в Checkmk

В отличие от мониторинга сетевого потока, мониторинг инфраструктуры требует упреждающего добавления хоста. Если ваша среда Checkmk уже содержит взаимодействующие сетевые узлы, пропустите этот шаг.

Для новых установок Checkmk:

  1. Перейдите к Настройка → Хосты

  2. Нажмите Добавить хост

  3. Настройте имя хоста (добавьте IP-адрес, если не разрешено DNS)

  4. Под Агенты мониторинга, настройте соответствующий метод мониторинга (например, SNMP)

  5. Установите учетные данные, если необходимо

  6. Нажмите Сохранить и перейти к настройке сервиса

  7. Просмотр автоматически обнаруженных сервисов

  8. Нажмите Исправить все добавить обнаруженные службы

  9. Активируйте изменения с помощью желтого восклицательного знака

Шаг 5: Мониторинг ntopng хостов в Checkmk

  1. Перейдите к Монитор → Статистика сети → Ntop Хосты

  2. Просмотрите обзор всех хостов, отслеживаемых как в Checkmk, так и в ntopng.

  3. Получите доступ к подробной информации о хосте через Ntopng интеграция этого хоста в меню действий

  4. Используйте различные вкладки для разных ракурсов: - Хозяин: Основная информация и резюме. - Дополнительные вкладки для конкретной информации о сети.

  5. Нажмите Просмотр данных в ntopng чтобы перейти непосредственно к хосту в ntopng

Интеграция оповещений

ntopng может экспортировать оповещения о трафике в консоль событий Checkmk, расширяя возможности мониторинга за пределы базовых показателей.

Процесс настройки:

  1. Через ntopng: Настройте конечные точки и получателей в разделе Оповещения → Уведомления

  2. Через Checkmk: Настройка уровней обслуживания и правил консоли событий.

  3. Результат: получать уведомления ntopng в консоли событий Checkmk.

Подробную информацию о настройке интеграции оповещений см.: Как экспортировать сигналы тревоги ntopng в консоль событий Checkmk

Для интеграции требуется правильное сетевое соединение между серверами Checkmk и ntopng. Убедитесь, что правила брандмауэра разрешают связь через настроенные порты.

Кончик

Начните с ограниченного количества хостов, чтобы протестировать интеграцию, прежде чем масштабировать всю инфраструктуру.
