Мониторинг нескольких местоположений

Чтобы отслеживать данные из нескольких мест, даже географически распределенных, см. Использование ntopng с nProbe и чтобы Мониторинг нескольких местоположений. Работа с общедоступными сетями и брандмауэрами объясняется в сообщении блога. Лучшие практики сбора потоков с ntopng и nProbe.

Примечание

Для каждого местоположения требуется лицензия nProbe.
