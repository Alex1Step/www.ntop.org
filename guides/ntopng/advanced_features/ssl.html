SSL/HTTPS

Введение

Чтобы использовать SSL с ntopng (т. е. HTTPS), вам нужен сертификат; вы можете создать свой собственный самозаверяющий сертификат (1) или получить его в центрах сертификации (CA) (2):

  • получить файлы .pem

  • Мысленный файл PrivateKeyFile(.pem) и файл certificate/certificateChainFile(.pem)

  • Переименуйте его в ntopng-cert.pem и поместите внутрь ntopng/httpdocs/ssl/.

Сервер HTTPS запустится на порту 3001.

Примечание

Поскольку пакеты ntopng устанавливают HTTPS включенным по умолчанию (порт 3001) и HTTP отключенным, Самозаверяющий сертификат уже создан для вас при первой установке. Прочтите инструкции ниже, чтобы настроить свои собственные.

Ниже вы можете найти инструкции о том, как запустить ntopng либо с самоподписанным сертификатом, либо с сертификатом CA, сгенерированным Let’s Encrypt (https://letsencrypt.org)

САМОПОДПИСАННЫЙ СЕРТИФИКАТ

Для создания самозаверяющего сертификата вам необходимо установить OpenSSL.

Debian/Ubuntu: sudo apt-get install openssl OnRedHat/CentOS: sudo yum install openssl В OSX выполните: Brew Install openssl

Из исходного кода

Если вы используете исходный код, вы можете создать сертификат SSL внутри папки ntopng, выполнив команду ниже:

make cert

Отредактируйте файл /etc/ntopng/ntopng.conf, чтобы включить https, добавив:

--https-port=3001

Вы можете выбрать порты, отличные от 3001, но это должен быть порт, отличный от порта http, который по умолчанию является портом 3000. В качестве альтернативы вы можете полностью отключить небезопасный http, заменив строку -w=3000 на –http-port=0. (-w и –http-порт взаимозаменяемы)

Затем начните ntopng.

Из пакетов

Ниже приведены инструкции по созданию сертификата вручную. Сертификат должен быть установлен под ntopng делиться каталог, обычно расположенный по адресу /usr/share/ntopng или в /usr/local/share/ntopng. Следующие инструкции предполагают, что он расположен по адресу /usr/local/share/ntopng.

Ubuntu и Centos

cd /tmp/
openssl req -new -x509 -sha256 -extensions v3_ca -nodes -days 365 -out cert.pem -subj "/C=EU/CN=ntopng.local"
cat privkey.pem cert.pem > /usr/share/ntopng/httpdocs/ssl/ntopng-cert.pem
/bin/rm -f privkey.pem cert.pem
systemctl restart ntopng

ГлавнаяФормула пивоварения

cd /tmp/
openssl req -new -x509 -sha256 -extensions v3_ca -nodes -days 365 -out cert.pem -subj "/C=EU/CN=ntopng.local"
mkdir /usr/share/ntopng/httpdocs/ssl/
cat privkey.pem cert.pem > /usr/share/ntopng/httpdocs/ssl/ntopng-cert.pem
/bin/rm -f privkey.pem cert.pem
cd /usr/local/bin/
ln -s /opt/local/lib/libssl.dylib /opt/local/lib/libcrypto.dylib .
ntopng

HTTPS Аутентификация клиента

Включив эту функцию, вы можете предоставить доступ к ntopng с помощью клиентских сертификатов X.509.

Клиенты, предоставляющие действительный сертификат, выданный доверенным центром сертификации, аутентифицируются. без необходимости пароля, если общее имя X.509 (CN) соответствует существующему пользователю ntopng.

Клиенты, которые в противном случае не могут предоставить сертификат или действительный сертификат, возвращаются к обычному процесс входа в систему.

Доверенные центры сертификации считываются из httpdocs/ssl/ntopng-ca.crt, этот файл должен содержать объединенные список сертификатов центров сертификации в формате PEM. Любое изменение этого файла требует перезапуска ntopng. чтобы вступило в силу.

Используя openssl, вы можете легко активировать эту функцию и создать клиентские сертификаты. со следующими инструкциями.

Создайте свой собственный ЦС:

openssl genrsa -des3 -out ca.key 2048                        # create key
openssl req -new -x509 -days 365 -key ca.key -out ca.crt     # create CA self-signed cert
cat ca.crt >> ntopng/httpdocs/ssl/ntopng-ca.crt              # add cert to trusted CAs

Создайте один или несколько сертификатов клиента:

openssl genrsa -des3 -out client.key 2048                    # create key
openssl req -new -key client.key -out client.csr             # create client cert request
openssl x509 -req -days 365 -in client.csr -CA ca.crt -CAkey ca.key -CAcreateserial -out client.crt                                                                                                                          # create client cert signed by CA

Экспортировать клиент в предпочтительный формат браузера (обычно pkcs12):

openssl pkcs12 -export -clcerts -in client.crt -inkey client.key -out client.p12

Затем импортируйте сертификат клиента в браузер и перезапустите ntopng. Не забудьте сначала включить HTTPS Аутентификацию клиента в настройках->Аутентификация пользователя.
