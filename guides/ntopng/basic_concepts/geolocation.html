Геолокация

Введение

ntopng включает поддержку геолокации, предоставляемую следующими компаниями

  • МаксМинд

  • БД-ИП

ntopng геолокация основана на файле базы данных, хранящемся локально, без облака. доступ какой угодно.

Вы можете установить бесплатную (хотя и не очень точную) GeoIP. базы данных или коммерческие. По умолчанию ntopng-data включает в себя базы данных DB-IP, выпущенные на условиях Creative Commons Лицензия на атрибуцию.

Пожалуйста, установите ntopng-data пакет для включения геолокации в ntopng, если у вас уже не установлены базы данных геолокации.

Использование геолокации MaxMind в ntopng

Новые правила конфиденциальности, такие как GDPR и CCPA, накладывают ограничения, которые повлиять на нашу способность продолжать распространять базы данных MaxMind GeoLite2 в общественность ntopng-data упаковка. Причины подробно описаны на странице следующая страница https://blog.maxmind.com/2019/12/18/significant-changes-to-accessing-and-using-geolite2-databases/.

С 30 декабря 2019 г. мы продолжаем использовать геолокацию в ntop программного обеспечения, вам необходимо зарегистрировать учетную запись MaxMind и получить лицензионный ключ для загрузки баз геолокации GeoLite2.

В следующем разделе перечислены все шаги, необходимые для использования геолокация в ntopng.

  1. Установить пакет ntopng-data который включает загрузчик MaxMind geoipupdate как зависимость.

  2. Зарегистрируйте учетную запись MaxMind на сайте https://www.maxmind.com/en/geolite2/signup.

  3. Создайте лицензионный ключ на https://www.maxmind.com/en/accounts/current/license-key.

    1. Выберите «Создать новый лицензионный ключ».

    2. Добавьте описание лицензионного ключа и ответьте «Да» на вопрос. «Будет ли этот ключ использоваться для обновления GeoIP?».

    3. Затем выберите один из двух доступных вариантов «Сгенерировать лицензию». ключ и файл конфигурации». Выбор зависит от установленного geoipupdate версия. Скорее всего, установлена более старая версия. чем 3.1.1, поэтому правильный вариант выбора — «Создать лицензию». ключ и файл конфигурации для использования с geoipupdate версии более старые чем 3.1.1». Если вы не знаете тип версии geoipupdate -V.

  4. После создания лицензии вам будет предложено загрузить файл. GeoIP.conf который содержит идентификатор учетной записи и лицензионный ключ, необходимые для скачать базы данных. Загрузите и поместите этот файл в /etc/GeoIP.conf.

  5. Убедитесь, что EditionIDs раздел (или ProductIds согласно geoipupdate версия) в /etc/GeoIP.conf содержит GeoLite2-Country GeoLite2-City GeoLite2-ASN (GeoLite2-ASN может отсутствовать по умолчанию).

  6. Бегать sudo geoipupdate для загрузки файлов базы данных.

  7. Перезапустите все запущенное программное обеспечение ntop. После перезапуска программное обеспечение будет автоматически находить и загружать загруженные базы данных.

Последующие обновления ntopng-data пакет проверит наличие наличие новых баз данных геолокации и, возможно, будет обновляться их автоматически.

Если вы предпочитаете обрабатывать обновления вручную, вы можете пропустить ntopng-data установка и непосредственное использование geoipupdate. Инструкции по использованию geoipupdate доступны на https://dev.maxmind.com/geoip/geoipupdate/

Использование геолокации на ОС Raspberry Pi (Raspbian)

Поскольку geoipupdate пакет недоступен на Raspberry Pi, Базу данных MaxMind следует загрузить и установить вручную на этом компьютере. платформа. Пожалуйста, проверьте следующий раздел для получения дальнейших инструкций.

Как использовать MaxMind вместо DB-IP?

Самое простое решение — установить ntopng-data. Однако если это невозможно, пожалуйста, сделайте (от root):

sudo su
cd /usr/share/ntopng/httpdocs/geoip/
mkdir backup
mv *mmdb backup
ln -s /var/lib/GeoIP/GeoLite2-City.mmdb .
ln -s /var/lib/GeoIP/GeoLite2-ASN.mmdb .
service ntopng restart

Использование геолокации, когда ntopng-data не доступен

В случае упаковки ntopng-data или geoipupdate недоступен на ваша платформа:

  1. Загрузка файлов базы данных вручную

    • БД-ИП: dbip-city-lite, dbip-asn-lite, и dbip-country-lite (https://db-ip.com/db/) базы данных в MMDB формат

    • МаксМайнд: GeoLite2-ASN.mmdb и GeoLite2-City.mmdb из «GeoIP2 / GeoLite2» > раздел «Загрузить файлы» вашего MaxMind страница аккаунта

  2. Затем поместите загруженные файлы в определенную папку, которая зависит на платформе:

    • Линукс (включая ОС Raspberry Pi): поместите загруженные файлы в папку /var/lib/GeoIP/ (/usr/share/GeoIP/ это также действительный путь)

    • Windows: поместить загруженные файлы в Program Files/ntopng/httpdocs/geoip/

    • пакет ОС Х: поместить загруженные файлы в /usr/local/share/ntopng/httpdocs/geoip (в случае, если geoip папка отсутствует, необходимо создать ее с помощью mkdir -p /usr/local/share/ntopng/httpdocs/geoip перед копированием файлы)

Обновление с предыдущей версии ntopng-data

На случай, если старый ntopng-data пакет уже установлен в системе, вы можете получить сообщение Следующие пакеты были сдерживался со ссылкой на него.

# sudo apt-get update
[...]
Calculating upgrade... Done
The following packages have been kept back:
  ntopng-data

Обычно это происходит в debian, потому что зависимости изменились в тот ntopng-data вы установили так, что пакет geoipupdate от MaxMind должен быть установлен для выполнения обновления. В этом случае для решения проблемы достаточно запустить

sudo apt-get --with-new-pkgs upgrade
