Уведомления о вовлеченности

При первом достижении порогового значения ntopng помещает соответствующее предупреждение в помолвлен состояние. Набор оповещений которые в данный момент заняты, доступна на странице оповещений о вовлеченности, обозначенной значком песочных часов. Это применимо ко всем семействам оповещений, за исключением оповещений Flow.
