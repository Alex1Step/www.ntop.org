Поведенческие проверки локальных сетей

Эти проверки выполняются в локальных сетях (см. параметр командной строки -m).

Широковещательный домен слишком велик

Проверяет широковещательные домены.

Обнаружен трафик ARP между двумя MACS-адресами, принадлежащими разным широковещательным доменам.

Предупреждение отправляется, когда широковещательный домен слишком велик.

Интерфейс: Пакет & ZMQ

Категория: Сеть

Включено по умолчанию

Жертва наводнения

Проверяет поток наводнения.

В компьютерной сети лавинная рассылка возникает, когда маршрутизатор использует неадаптивный алгоритм маршрутизации. Когда в сети происходит больше заранее определенного количества потоков в минуту. Система отправляет уведомление, когда серверы отслеживаемых потоков превышают пороговое значение.

Оповещение отправляется в случае переполнения потока сервера.

Интерфейс: Пакет & ZMQ

Категория: Кибербезопасность

Не включено по умолчанию

Переассоциирование IP/MAC/спуфинг

Проверяет переассоциацию/подмену IP-адреса или MAC-адреса.

Это предупреждение может указывать на попытку подмены ARP.

Предупреждение отправляется, когда IP-адрес, который ранее отображался с MAC-адресом, теперь отображается с другим MAC-адресом. Работает только для встроенного получателя оповещений.

Интерфейс: Пакет & ZMQ

Категория: Сеть

Не включено по умолчанию

Сетевое обнаружение

Проверяет обнаружение сети.

Обнаружение сети — это процесс, который позволяет компьютерам и устройствам находить друг друга, когда они находятся в одной сети. Это первый шаг, который делают системные администраторы, когда хотят составить карту и контролировать свою сетевую инфраструктуру. Этот процесс иногда также называют обнаружением топологии.

Оповещение отправляется при обнаружении сетевого обнаружения.

Интерфейс: Пакет & ZMQ

Категория: Сеть

Включено по умолчанию

Проблемы с сетью

Проверяет обнаружение сети.

Проблемы с сетью, такие как потеря пакетов, могут указывать на проблему в сети.

Оповещение отправляется при выявлении проблем с сетью (повторные передачи, большое количество фрагментов и потеря пакетов).

Интерфейс: Пакет & ZMQ

Категория: Сеть

Включено по умолчанию

Оценка сети на хост

Проверяет рейтинг хостов в сети.

Высокий балл (в среднем на хост) на многих хостах сети может означать возможную проблему с самой сетью.

Оповещение отправляется, когда средний балл на узел сети превышает пороговое значение.

Интерфейс: Пакет & ZMQ

Категория: Сеть

Включено по умолчанию

СИН Жертва наводнения

Проверяет наличие SYN-флуда.

SYN-флуд – это распространенная форма DDoS-атаки , которая может быть нацелена на любую систему, подключенную к Интернету и предоставляющую TCP такие услуги, как веб-сервер, сервер электронной почты, передача файлов. SYN-флуд — это тип TCP атаки с исчерпанием состояния , которая пытается использовать таблицы состояний соединения, присутствующие во многих компонентах инфраструктуры, таких как балансировщики нагрузки, межсетевые экраны и IPS.

Оповещение отправляется, когда количество полученных SYN превышает пороговое значение.

Интерфейс: Пакет

Категория: Кибербезопасность

Не включено по умолчанию

Жертва SYN-сканирования

Проверяет наличие SYN Scan.

Сканирование SYN — это тактика, которую хакер может использовать для определения состояния коммуникационного порта без установления полного соединения. Этот подход, один из старейших, иногда используется для проведения DoS-атак. Сканирование SYN также известно как полуоткрытое сканирование.

Оповещение отправляется, когда количество полученных SYN превышает пороговое значение.

Интерфейс: Пакет & ZMQ

Категория: Кибербезопасность
