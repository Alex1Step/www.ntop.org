Поведенческие проверки системы

Системные проверки предназначены для выявления проблем ntopng и, таким образом, обеспечения работоспособности приложения.

BGP Обновление префикса

Проверяет наличие обновлений префикса BGP.

Оповещение отправляется для каждого уведомления об обновлении префикса BGP, полученного ntopng (объявления и отзыв префиксов).

Интерфейс: Пакет & ZMQ

Категория: Внутренности

Не включено по умолчанию

Недостаточно места на диске

Проверяет свободное место на диске.

Предупреждение отправляется, когда используемое пространство на томе данных ntopng (или на томе записи трафика, если он отдельный) превышает настроенный порог (по умолчанию: 90%). Предупреждение выдается, когда использованное пространство снова становится ниже порогового значения. Недоступно на Windows.

Интерфейс: Пакет & ZMQ

Категория: Система

Включено по умолчанию

Превышен лимит экспортеров

Проверяет количество экспортеров.

Каждая лицензия ntopng поддерживает определенное количество экспортеров.

Оповещение отправляется, когда количество экспортеров превышает количество, поддерживаемое лицензией.

Интерфейс: Пакет & ZMQ

Категория: Внутренности

Включено по умолчанию

Журнал обнаружения и предотвращения вторжений

Проверяет журналы обнаружения и предотвращения вторжений.

Ntopng уведомляет, когда хост был добавлен или удален из пула заблокированных хостов.

Оповещение отправляется при обнаружении необычных зарегистрированных событий.

Интерфейс: Пакет & ZMQ

Категория: Внутренности

Не включено по умолчанию

Периодическая деятельность не выполнена

Проверяет периодическое выполнение действий.

Система отправляет предупреждение, когда периодическое действие находится в очереди и не выполняется.

Предупреждение отправляется, когда рабочие потоки заняты.

Интерфейс: Пакет & ZMQ

Категория: Внутренности

Включено по умолчанию

Redis Превышено число операций чтения и записи

Проверяет количество операций Redis.

Оповещение отправляется, когда количество Redis операций чтения и записи за последние 24 часа является аномальным по сравнению с rest недели.

Интерфейс: Пакет & ZMQ

Категория: Внутренности

Включено по умолчанию

Медленная периодическая активность

Проверяет медленную периодическую активность.

Периодическому действию требуется время, чтобы начать выполнение.

Оповещение отправляется, чтобы уведомить о том, что периодическое действие занимает слишком много времени.

Интерфейс: Пакет & ZMQ

Категория: Внутренности

Включено по умолчанию

Системные оповещения сбрасываются

Проверяет наличие системных предупреждений.

За короткий период времени создается слишком много оповещений, это может привести к тому, что система откажется от оповещений.

Оповещение отправляется, когда во внутренней очереди оповещений нет места и оповещения удаляются.

Интерфейс: Пакет & ZMQ

Категория: Внутренности

Включено по умолчанию

Системная ошибка

Проверяет наличие системных ошибок.

Вызов оповещения при обнаружении системной ошибки (сбой ntopng).

Интерфейс: Пакет & ZMQ

Категория: Внутренности

Включено по умолчанию

Всегда включенные системные оповещения

Следующие оповещения не генерируются проверкой, поэтому они не перечислены в списке Поведенческие проверки страница. Они включены по умолчанию и не могут быть отключены.

Процесс

Предупреждение (process_notification) отправляется, когда ntopng запускается или останавливается.

Всегда включено, не может быть отключено

Ошибка входа

Предупреждение (login_failed) отправляется, когда не удается войти в Интернет GUI.

Всегда включено, не может быть отключено

Активность пользователя

Предупреждение (user_activity) отправляется, когда пользователь выполняет действие, связанное с управлением системой и безопасностью (см. Оповещения, Действия пользователя).

Всегда включено, не может быть отключено

Сценарий оболочки конечной точки выполнен

Предупреждение (shell_script_executed) отправляется, когда конечная точка сценария оболочки запускает сценарий.

Всегда включено, не может быть отключено

Команда Fail2Ban выполнена

Предупреждение (fail2ban_executed) отправляется, когда конечная точка Fail2Ban выполняет команду.

Всегда включено, не может быть отключено

Неправильно настроенное приложение

Предупреждение (misconfigured_app) отправляется, когда конфигурация ntopng недостаточна, например, когда имеется больше хостов или потоков, чем указано -x / -X пределы.

Всегда включено, не может быть отключено

Очередь пакетов очищена

Предупреждение (nfq_flushed) отправляется, когда очередь пакетов NFQUEUE интерфейса очищается, поскольку она заполнена.

Всегда включено, не может быть отключено

Загрузка списка не удалась

Предупреждение (list_download_failed) отправляется, когда черный список или список категорий не могут быть загружены.

Всегда включено, не может быть отключено

Загрузка списка завершена

Предупреждение (list_download_succeeded) отправляется при загрузке и обновлении черного списка или списка категорий.

Всегда включено, не может быть отключено

Шлюз недоступен

Предупреждение (gateway_unreachable) отправляется, когда шлюз не отвечает на ping (только nEdge).

Всегда включено, не может быть отключено

Неправильно настроен диапазон DHCP

Предупреждение (ip_outsite_dhcp_range) отправляется, когда устройство получает IP-адрес за пределами настроенного диапазона DHCP.

Всегда включено, не может быть отключено
