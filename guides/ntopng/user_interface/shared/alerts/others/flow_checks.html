Учетные данные в виде открытого текста

Указывает на небезопасное приложение для ваших учетных данных.

Вместо использования HTTPS некоторые приложения передают пароли по незашифрованным соединениям, что делает их уязвимыми. Чтобы воспользоваться этой уязвимостью, злоумышленник может шпионить за сетевым трафиком жертвы. Это происходит, когда клиент взаимодействует с сервером через небезопасное соединение, например общедоступную сеть Wi-Fi или корпоративную или домашнюю сеть, которая используется совместно со взломанным компьютером. Чтобы предотвратить этот тип атаки, крайне важно использовать зашифрованный транспортный уровень связи (SSL или TLS) для защиты всех конфиденциальных данных, передаваемых между клиентом и сервером.

Предупреждение появляется, когда учетные данные были вставлены в небезопасный/зашифрованный канал.

Проверяет, пропущен ли SNI.

Часто веб-сервер отвечает за несколько имен хостов или доменных имен. Каждое имя хоста имеет свой собственный сертификат SSL, если веб-сайты используют HTTPS. Проблема в том, что все эти имена хостов на одном сервере имеют один и тот же IP-адрес. Это не проблема для HTTP, потому что как только соединение TCP открывается, клиент укажет, к какому веб-сайту он пытается обратиться, в запросе HTTP. Но в HTTPS сначала происходит рукопожатие TLS, прежде чем может начаться разговор HTTP (HTTPS по-прежнему использует HTTP — он просто шифрует сообщения HTTP). Без SNI (имя индикации сервера) клиент не сможет указать серверу, с каким именем хоста он разговаривает. В результате сервер может выдать сертификат SSL для неправильного имени хоста. Если имя в сертификате SSL не соответствует имени, к которому пытается обратиться клиент, браузер клиента возвращает ошибку и обычно разрывает соединение.

Установка сервера DHCP в сети хакером по имени Rogue server DHCP может привести к атакам «Человек посередине», «Сниффинг» и «Разведка». Разместив в сети мошеннический сервер DHCP, злоумышленник может предоставить клиентам поддельные адреса и другую сетевую информацию для перехвата пакетов данных.

Предупреждение отправляется, когда система обнаруживает неожиданный сервер DHCP (IPv4 и IPv6), т.е. хост, отвечающий на запросы DHCP, которого нет в списке серверов DHCP конфигурации сети (проверка ничего не делает, если список пуст). Сообщается только о хостах, которые действительно отвечают: запрос без ответа (например, клиент, продлевающий аренду сервера, который больше не отвечает) не вызывает оповещение. Сервер DHCP считается атакующим и получает большую часть очков.

Примечание

DHCP агенты ретрансляции, доставляющие ответы клиентам, действуют для них как DHCP серверы: добавьте их также в список DHCP серверов. Агенты ретрансляции, пересылающие запросы на сервер DHCP списка, разрешены.

Веб-майнинг

Проверьте генерируемый трафик от/к хостам, которые, как известно, выполняют майнинг криптовалют.

Майнинг криптовалюты — это трудоемкая задача, требующая мощных ресурсов, таких как специализированное оборудование и процессоры, а также значительных затрат на электроэнергию и инвестиций в оборудование. Чтобы избежать затрат на все эти инструменты — дорогостоящее оборудование, киберпреступники заражают системы, чтобы использовать мощность CPU или графического процессора жертв и существующие ресурсы для майнинга криптовалют. Используя различные векторы атак, такие как спам-кампании и наборы эксплойтов, они способны превратить зараженные машины в армию майнеров криптовалюты.

XSS-атака

Проверка подтверждает возможную XSS-атаку.

Межсайтовый скриптинг (XSS) — это атака на клиентский код. Злоумышленник стремится выполнить вредоносные сценарии в веб-браузере жертвы, включив вредоносный код в законную веб-страницу или веб-приложение. Фактическая атака происходит, когда жертва посещает веб-страницу или веб-приложение, выполняющее вредоносный код. Веб-страница или веб-приложение становится способом доставки вредоносного сценария в браузер пользователя. Для атак с использованием межсайтовых сценариев обычно используются форумы, доски объявлений и веб-страницы, на которых разрешено оставлять комментарии.

Система отправляет оповещение в случае обнаружения возможной XSS-атаки на сайте.
