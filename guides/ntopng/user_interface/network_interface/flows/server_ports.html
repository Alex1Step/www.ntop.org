Порты сервера

Это представление представляет собой вкладку «Порты сервера» на странице «Живые потоки» (меню «Потоки», пункт «Живые потоки»).

Примечание

Серверные порты доступны только с лицензией Enterprise L.

Эта страница используется для понимания того, какие порты сервера в данный момент используются в текущем интерфейсе.


В левой части карты показаны сети VLAN, которые в настоящее время имеют трафик на некоторых портах сервера, в центре вместо этого можно найти протокол, а справа — используемый порт сервера. Можно добавить несколько фильтров, выбрав записи, доступные в правой верхней части таблицы. Более того, если ClickHouse включено, можно изменить таймфрейм и посмотреть не только реальный трафик, но даже исторический трафик.


При нажатии на порт или имя VLAN на карте пользователь перенаправляется к актуальным (или, с указанием таймфрейма, историческим) потокам с запрошенным фильтром. При нажатии на ссылку (VLAN, протокол, порт) потоки этой ссылки отображаются агрегированными по клиенту и серверу: вкладка «Агрегация» текущих потоков или запрос «Контакты сервера» исторических потоков с выбранным периодом времени, отфильтрованных по VLAN, протоколу L4, приложению и порту сервера.
