Локализация

При разработке сценариев для интеграции в ntopng следует проявлять некоторую осторожность. предпринято для обеспечения надлежащей поддержки локализации. Рассмотрим следующий пример:

gui = {
        i18n_title = "SYN Flood Victim Alert",
        i18n_description = "Trigger an alert when the number of received SYNs/sec exceeds the threshold",
}

это действительно в ntopng и даст ожидаемый результат в GUI, но это будет только работа на английском языке. Напротив, правильный способ обеспечить локализацию поддержка следующая:

gui = {
        i18n_title = "entity_thresholds.syn_victim_title",
        i18n_description = "entity_thresholds.syn_victim_description",
}

тот entity_thresholds.syn_victim_title и entity_thresholds.syn_victim_description являются ключами локализации. ntopng преобразует эти ключи в локализованные строки на основе текущий язык пользователя.

Все файлы сценариев, кроме manifest.lua, который предназначен только для фоновых операций, поддерживает локализацию.

Скрипты и локализация

Скрипты могут помещать свои собственные локализованные строки в файлы локализации в папке локали подкаталог скрипта (см. пример здесь). Каждый файл имеет код страны в качестве имени файла, например. it.lua содержит строки локализации на итальянском языке. ntopng на данный момент поддерживает следующие языки: Английский, чешский, немецкий, итальянский, японский, португальский. Предоставление английского файл локализации является обязательным для скрипта, так как это, черт возьми, используется, когда для определенного языка отсутствует определенная строка.

Вот пример ru.lua файл локализации для скрипта, который контролирует температуру в помещении (каталог скрипта называется room_temp_monitor):

return {
        my_title = "Room Temperature Monitor",
        description = "Monitors the room temperature and charts it",
}

Любой Lua-скрипт в ntopng может затем использовать указанные выше локализованные строки с i18n("room_temp_monitor.my_title") и i18n("room_temp_monitor.description"). Пользователь также может создать it.lua файл с следующее содержание:

return {
        my_title = "Temperatura della Stanza",
        description = "Monitora e grafica la temperatura della stanza",
}

ntopng теперь будет автоматически использовать строки, локализованные на итальянском языке, для итальянских пользователей.

В декларативной части скриптов нет необходимости вручную вызывать i18n функция. Эти ключи идентифицируются i18n_ префикс. Например, в этом коде:

gui = {
        i18n_title = "room_temp_monitor.my_title",
        i18n_description = "room_temp_monitor.my_title",
}

тот i18n функция будет автоматически вызываться ntopng при необходимости. Это обеспечивает повышение производительности, поскольку ntopng разрешает строки только при необходимости.

Внутренняя обработка

Таблица локализации — это таблица Lua, содержащая ключи и переведенные строки в качестве значений. Доступно несколько таблиц локализации, по одной для каждого поддерживаемого языка. ntopng выбирает таблицу локализации на основе языка, установленного для текущего пользователя. Все таблицы локализации ntopng доступны на GitHub.

Строка s локализуется следующим образом:

  1. s просматривается в таблице локализации языка, установленного для пользователя. Если ключ s существует в таблице локализации, локализованная строка принимается как значение ключа s и локализация заканчивается. Если ключ s не существует:

  2. s просматривается в таблице английской локализации. Если ключ s существует в таблице английской локализации fheck, локализованная строка принимается в качестве значения ключа s и локализация заканчивается. Если ключ s не существует:

  3. Строка s принимается дословно.

Если для пользователя установлен английский язык, используется только таблица английской локализации.

Точки . в строках разрешено локализовать. Точки рассматриваются как разделители для обработки подтаблиц локализации. Строка s.t просматривается в таблице локализации следующим образом:

  1. Ключ s просматривается в таблице локализации. Стоимость s ожидается, что это будет еще один стол.

  2. Ключ t просматривается в таблице, найденной как значение ключа s.

Скрипт может расширять ntopng таблицы локализации. Расширение осуществляется с использованием файлов Lua, расположенных в подкаталоге скриптов. ./locales. Файлы Lua содержат таблицы локализации. Каждый файл должен иметь имя одного из поддерживаемых языков ntopng и возвращать таблицу Lua. Например, чтобы расширить файл английской локализации ntopng, сценарий может использовать en.lua файл, как показано здесь. Таблицы локализации скриптов автоматически объединяются с таблицами локализации ntopng.

Параметры

Локализованные строки принимают параметры. Параметры не переводятся. Они автоматически передаются в строку с помощью ntopng. Параметры передаются в локализованную строку в виде таблицы Lua. Таблица Lua передается автоматически с помощью ntopng, но указывается в коде скрипта.

Параметры в локализованной строке выражаются как %{parameter_name}. Локализация заменяет %{parameter_name} с фактическим значением параметра, найденным в ключе parameter_name таблицы параметров Lua.

Примеры

Учитывать

i18n_title = "alerts_dashboard.blacklisted_flow"

Префикс i18n_ говорит ntopng alerts_dashboard.blacklisted_flow необходимо локализовать. Предполагая, что немецкий язык установлен в качестве языка для текущего пользователя:

  1. ntopng ищет ключ alerts_dashboard в таблице немецкой локализации. Если ключ найден и значение представляет собой таблицу, ntopng ищет ключ. blacklisted_flow в таблице найдено как значение. Если ключ blacklisted_flow найден, то его значение принимается как локализованная строка и локализация завершается. Если какой-либо из двух ключей не существует:

  2. Шаг 1 повторяется с таблицей английской локализации fheck. Если локализованная строка не найдена:

  3. alerts_dashboard.blacklisted_flow принимается дословно.

Рассмотрим теперь запись

["iface_download"] = "%{iface} download"

Найдено в файле ru.lua. Локализованная строка содержит параметр %{iface}. Этот параметр будет заменен значением, найденным в ключе iface таблицы параметров Lua. Так, например, если таблица параметров Lua равна {iface="eno1"}, локализованная строка станет "eno1 download".
