3. Silicom/Поддержка Fiberblaze

3.1. Предварительные условия

Установите пакет Fiberblaze:

mkdir /opt/fiberblaze && tar xvzf fbcapture_<OS>_release_<version>.tar.gz -C /opt/fiberblaze

Загрузите драйвер:

echo 34359738368 > /proc/sys/kernel/shmmax
echo 34359738368 > /proc/sys/kernel/shmall
echo 2048 > /sys/kernel/mm/hugepages/hugepages-2048kB/nr_hugepages
export PATH=/opt/fiberblaze/bin:$PATH
echo "/opt/fiberblaze/lib" > /etc/ld.so.conf.d/fiberblaze.conf; ldconfig
cd /opt/fiberblaze/driver; make; ./load_driver.sh hugepages='2G'; cd -
cd /opt/fiberblaze/bin; ./configurecard --device fbcard0 --configuration ../fbcard.cfg; cd -

3.2. Получать трафик

Начиная с версии 7.7, соглашение об именах для групп RX, подгрупп и колец RPB (как указано) в файле конфигурации fbcard.cfg, используемом configurecard), соответствует соглашению Fiberblaze: fbcard:CARD_ID:PRB_NAME, где CARD_ID — идентификатор карты, которую мы хотим открыть, PRB_NAME — это Название PRB Fiberblaze. Например, если в группе PRB настроены два PRB. а, имена интерфейсов PRB:

fbcard:0:a00
fbcard:0:a01

Если два PRB настроены с группой PRB а и подгруппа PRB б, имена PRB:

fbcard:0:a/b00
fbcard:0:a/b01

Пример групповой конфигурации с 8 кольцами PRB с использованием хеширования в /opt/fiberblaze/fbcard.cfg:

prbGroup "b"
{
    noPrbs 8
    hash HashPacket
    filter "hash"
}

Пример получения пакетов с карты 0, группа б, кольцо 0, с PF_RING 7.7 или новее:

pfcount -i fbcard:0:b00

Если вы хотите открыть один порт вместо всех портов на карте, вы можете указать input = PORT_ID в разделе фильтра:

prbGroup "a"
{
    noPrbs 1
    filter "input = 0"
}

3.2.1. PF_RING <= 7,6

В более старой версии PF_RING (раньше версии 7.7) соглашение об именах для RX было fbcard:CARD_ID:GROUP_NAME:GROUP_RING_ID где CARD_ID — идентификатор карты, которую мы хотим открыть, GROUP_NAME — название группы указанный в файле конфигурации fbcard.cfg, используемом configurecard, и RING_ID (в случае хеширования трафика, то есть RSS Fiberblaze), если идентификатор PRB. Например, если в группе PRB настроены два PRB. б, имена интерфейсов PRB в в этом случае:

fbcard:0:b:0
fbcard:0:b:1

3.3. Передача трафика

Соглашение об именах для TX: fbcard:CARD_ID:PORT_ID. Если у вас 4 порта NIC, PORT_ID будет от 0 до 3.

Пример (отправка пакетов с порта 1 с идентификатором карты 0):

pfsend -i fbcard:0:1
