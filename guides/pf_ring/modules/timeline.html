9. n2disk Модуль временной шкалы

Этот модуль можно использовать для плавного извлечения трафика из временной шкалы n2disk с помощью PF_RING API. n2disk — приложение для записи дорожного движения, создающее несколько файлов PCAP (ограничение продолжительности каждого файла). или размер можно использовать для управления размером файла), индекс для каждого файла и временную шкалу для хранения всех файлы в хронологическом порядке. Благодаря этому модулю можно запросить временную шкалу для конкретных пакеты, принадлежащие всему набору дампов за заданный интервал времени, соответствующие определенному фильтру BPF.

9.1. Требования

Установите pfring и n2disk, следуя инструкциям по адресу http://packages.ntop.org согласно вашему дистрибутив Linux и загрузите модуль ядра PF_RING, как описано в Установка из пакетов раздел.

systemctl start pf_ring

9.2. Создание набора дампов с помощью n2disk

Этот модуль извлекает трафик из набора дампов n2disk, состоящего из файлов PCAP, индексных файлов и временной шкалы. Чтобы указать n2disk создавать индексы «на лету», вам следует использовать опцию -I. Опция -A <путь> вместо этого его следует использовать для создания временной шкалы в <path>.

Пример командной строки:

n2disk -i eth1 -o /storage/n2disk/eth1 -I -A /storage/n2disk/eth1/timeline

Дополнительные возможности см. n2disk Документация.

9.3. Использование

Чтобы сообщить PF_RING, что вы хотите выбрать модуль временной шкалы, вам следует использовать префикс «timeline:». за которым следует путь временной шкалы в качестве имени интерфейса. В дополнение к этому обязательно наличие фильтра BPF. содержащий в начале временной интервал с использованием токенов «start» и «end», за которым следует фактический пакет фильтр (поддерживается подмножество синтаксиса BPF, обратитесь к документации n2disk), как в примере ниже:

pfcount -i timeline:/storage/n2disk/eth1/timeline -f "start 2016-09-22 8:40:53 and end 2016-09-22 10:43:54 and host 192.168.2.130"

Конкретный пример pftimeline есть также доступен в PF_RING примеры папка. Вы можете использовать pftimeline для извлечения трафика, создающего файл PCAP с соответствующим трафиком, или для передачи по конвейеру. другое приложение для непосредственной обработки соответствующего трафика. Пример:

pftimeline -t /storage/n2disk/eth1/timeline -b "2018-07-21 8:40:53" -e "2018-07-21 10:43:54" -f "host 192.168.2.130" -o - | tshark -i -

9.4. Wireshark поддержка

Одним из наиболее распространенных вариантов использования модуля временной шкалы является интеграция Wireshark, на самом деле это очень удобно. удобно запускать wireshark непосредственно на временной шкале n2disk, указав фильтр BPF для извлечения небольшого часть всего набора дампов и запуск задачи анализа во время извлечения. Для этого вы можете использовать модули extcap, которые мы предоставляем для Wireshark, как описано на странице https://github.com/ntop/wireshark-ntop
