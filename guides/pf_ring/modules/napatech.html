6. Napatech Поддержка

PF_RING имеет встроенную поддержку адаптеров Napatech, библиотеки Napatech. необходимо установить в /opt/napatech3, чтобы включить Napatech модуль во время выполнения.

6.1. Предварительное условие

Установлены драйверы Napatech и SDK (12.11.24 или новее).

Napatech SDK доступен для скачивания по адресу https://www.napatech.com/downloads/.

После установки Napatech SDK убедитесь, что драйвер загружен:

/opt/napatech3/bin/ntload.sh
/opt/napatech3/bin/ntstart.sh

6.2. Установка

Чтобы начать работу с Napatech при установке из исходного кода, выполните следующие команды:

cd PF_RING/kernel && make && sudo insmod pf_ring.ko
cd ../userland/lib && ./configure && make
cd ../libpcap && ./configure && make
cd ../examples && make
sudo ./pfcount -i nt:0

Обратите внимание, что при установке из репозитория все приложения уже скомпилированы с поддержкой Napatech.

6.3. Захват трафика

Для открытия порта с адаптера Napatech необходимо указать nt:<PORT>, пример:

pfcount -i nt:0

Для открытия потока необходимо указать nt:stream<ID>, пример:

pfcount -i nt:stream0

В случае нескольких адаптеров можно указать идентификатор адаптера для потока с помощью nt:<ID адаптера>:stream<ID>, пример:

pfcount -i nt:1:stream0

Потоки с агрегацией или распределением портов (аналогично RSS) можно создавать с помощью инструмента ntpl (ntpl -e «<команда>»)

Примечание: можно одновременно открыть один и тот же поток из нескольких приложений (самый медленный потребитель будет влияют на других!). Вместо этого невозможно открыть порт несколько раз (поскольку порт переназначается новому поток каждый раз, когда вы его открываете). В случае нескольких приложений можно установить размер буфера хоста (пожалуйста, обратитесь к документации Napatech для этого параметра), используя переменную среды PF_RING_PACKET_CAPTURE_PRIO (с значение от 1 до 100, обычно рекомендуется 80).

6.4. Конфигурация потоков

Пример команды для агрегации портов (2 и 3) в один поток (1):

/opt/napatech3/bin/ntpl -e "Delete = All"
/opt/napatech3/bin/ntpl -e "Assign[streamid=1] = port == 2,3"

Пример команды для балансировки нагрузки всех портов по 16 потокам:

/opt/napatech3/bin/ntpl -e "Delete = All"
/opt/napatech3/bin/ntpl -e "HashMode = Hash2TupleSorted"
/opt/napatech3/bin/ntpl -e "Assign[StreamId=(0..15)] = All"

Пример команды для балансировки нагрузки порта 0 по 4 потокам:

/opt/napatech3/bin/ntpl -e "Delete = All"
/opt/napatech3/bin/ntpl -e "HashMode = Hash2TupleSorted"
/opt/napatech3/bin/ntpl -e "Assign[StreamId=(0..3)] = port == 0"

Пример команды для объединения двух портов и балансировки нагрузки на них по 24 потокам, где первые 12 потоков связаны на узле 0, а оставшиеся 12 — на узле numa 1

/opt/napatech3/bin/ntpl -e "Delete=All"
/opt/napatech3/bin/ntpl -e "HashMode = Hash5TupleSorted"
/opt/napatech3/bin/ntpl -e "Setup[NUMANode=0]=Streamid==(0..11)"
/opt/napatech3/bin/ntpl -e "Setup[NUMANode=1]=Streamid==(12..23)"
/opt/napatech3/bin/ntpl -e "Assign[streamid=(0..23)]=port==0,1"

6.5. Конфигурация адаптера для n2disk

Чтобы использовать адаптер Napatech с n2disk, файл конфигурации /opt/napatech3/config/ntservice.ini должен содержать:

TimestampFormat = PCAP_NS
PacketDescriptor = PCAP
HostBufferSegmentSizeRx = 4

6.6. Napatech и копия пакета

Если вы используете PF_RING (не ZC) пакеты API читаются в zero-копии. Вместо этого если вы используете PF_RING ZC API, происходит попакетное копирование, которое необходимо для перемещения полезные данные из Napatech-памяти в память ZC. Имейте это в виду!

6.7. Поддержка передачи

Чтобы использовать Napatech при передаче, вам необходимо убедиться, что у вас есть настроил ТХ правильно. Отредактируйте /opt/napatech3/config/ntservice.ini и убедитесь, что у вас настроены следующие разделы

[Adapter0]
..
HostBuffersTx = [4,16,0]
..

[Отладка] RntcTxEnable=1

6.8. Аппаратная фильтрация

Napatech NICs поддерживают полноценную аппаратную фильтрацию «из коробки». Спасибо в nBPF мы преобразуем выражения BPF в аппаратные фильтры. Эта функция поддерживается прозрачно, и, таким образом, все PF_RING/libpcap-over-PF_RING могут получить выгоду от этого.

Пример:

pfcount -i nt:3 -f "tcp and port 80 and src host 192.168.1.1"

Поскольку аппаратные фильтры Napatech очень продвинуты, фильтрация осуществляется исключительно аппаратно.
