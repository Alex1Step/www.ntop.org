2. AF_XDP Поддержка

PF_RING (7.9 или более поздняя версия) включает поддержку адаптеров AF_XDP, при компиляции из исходного кода это включено по умолчанию (если только –отключить-xdp указан флаг конфигурации).

2.1. Предварительное условие

  • PF_RING 7.9.0-6671 или новее

  • Зависимости: libelf-dev

  • Ядро: >= 5.4 (настроено с помощью CONFIG_XDP_SOCKETS=y)

  • libbpf с последней поддержкой AF_XDP, установленной из <источник ядра>/tools/lib/bpf

  • Огромные страницы загружены

2.2. Версия ядра

Установите ядро ​​>= 5.4, которое включает поддержку невыровненных буферов копирования zero. Ubuntu 20 LTS в настоящее время использует ядро ​​5.4, которое полностью поддерживает AF_XDP. Однако рекомендуется использовать ядро ​​HWE 5.8, поскольку оно обеспечивает улучшенную поддержку AF_XDP.

Установить клевета-разработчик:

apt install libelf-dev

Ubuntu 18.04 вы можете использовать uktools, доступные по адресу https://github.com/usbkey9/uktools/ следуя инструкциям ниже:

git clone https://github.com/usbkey9/uktools && cd uktools
make

Скачайте и распакуйте исходники ядра 5.x:

wget http://cdn.kernel.org/pub/linux/kernel/v5.x/linux-5.8.tar.xz
tar xvf linux-5.8.tar.xz

Скомпилируйте и установите библиотека libbpf:

cd linux-5.8/tools/lib/bpf
make
sudo make install_lib
sudo make install_headers
sudo ldconfig

2.3. Установка

Установите PF_RING, как указано в Установка из пакетов раздел в поддерживаемой ОС с поддерживаемой версией ядра (например, Ubuntu 20) или скомпилируйте его из исходного кода. В последнем случае должна поддерживаться AF_XDP. автоматически обнаруживаться и включаться:

cd PF_RING/userland
./configure
make

Примечание. Флаг –enable-xdp требовался в предыдущих версиях pf_ring.

Убедитесь, что приведенный ниже вывод распечатан сценарием настройки. (это означает, что поддержка AF_XDP действительно обнаружена и включена).

checking PF_RING AF_XDP support... yes

2.4. Загрузите драйвер

Загрузите ванильные драйверы (используйте последние версии драйверов, включающие поддержку AF_XDP, PF_RING ZC). драйверы следует выгрузить, поскольку они поддерживают только режим PF_RING ZC).

2.5. Загрузка огромных страниц

Огромные страницы необходимы для работы поддержки AF_XDP (используется для распределения буферов). При установке из пакетов, следующих Установка из пакетов руководство это требуется только создать /etc/pf_ring/hugepages.conf, иначе могут получиться огромные страницы загружен:

echo 1024 > /sys/kernel/mm/hugepages/hugepages-2048kB/nr_hugepages
mount -t hugetlbfs nodev /dev/hugepages

2.6. Использование

Теперь вы готовы запустить любой пример приложения pf_ring, используя xdp:<interface>@<queue> в качестве имени интерфейса. Пример:

cd examples
sudo ./pfcount -i xdp:eth1@0

Обратите внимание, что если AF_XDP pf_ring прикрепляется к очереди NIC, отключите RSS или откройте все очереди.
