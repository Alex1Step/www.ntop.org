3. Использование PF_RING с CoreOS

В этом руководстве показано, как запускать приложения обработки пакетов на основе PF_RING. внутри контейнера, работающего на CoreOS Container Linux.

Обратите внимание, что CoreOS поставляется без набора инструментов компилятора и исходных кодов ядра. по этой причине компиляция происходит в контейнере с использованием исходных кодов ядра хост-системы.

PF_RING включают скрипты для автоматизации компиляции и установки модулей на CoreOS, как описано ниже. Обратите внимание, что обновление системы изменяет ядро, требующее перекомпиляции модулей.

3.1. Установка

Запустив сценарий build.sh, он скомпилирует и установит модуль ядра pf_ring и все драйверы ZC. Для установки можно выбрать версию pf_ring, изменив имя ветки в переменной PF_RING_VERSION в build.sh.

git clone https://github.com/ntop/PF_RING.git
cd PF_RING/package/coreos
./build.sh

После этого вы готовы загрузить модули ядра, установленные на хосте в /opt/pf_ring, пример:

sudo insmod /opt/pf_ring/7.2.0-stable/$(cat /etc/os-release|grep VERSION=|cut -d= -f2)/lib64/modules/$(uname -r)/kernel/net/pf_ring/pf_ring.ko

Чтобы протестировать драйверы, вы можете использовать образ pfring, доступный на Docker Hub:

docker run --net=host ntop/pfring:stable pfcount -i enp0s3
