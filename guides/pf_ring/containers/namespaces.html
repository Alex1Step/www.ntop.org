1. Сетевые пространства имен

Docker, LXC, — это виртуальные среды с гораздо меньшими накладными расходами по сравнению с виртуальными машинами, поскольку в них нет гостевой ОС. Контейнеры построены на следующих компонентах:

  • cgroups (группы управления), ограничивают и учитывают использование ресурсов набора процессов, включая CPU/ядра, память, блок ввода-вывода, сеть (tc, iptables).

  • Пространства имен изолируют и виртуализируют системные ресурсы набора процессов, включая PID, имена хостов, идентификаторы пользователей, сеть, файловые системы.

Сетевые пространства имен виртуализируют сетевой стек: сетевое пространство имен — это (логически) другая копия сетевого стека со своими собственными сетевыми интерфейсами, правилами iptables, таблицами маршрутизации, сокетами. При создании сетевое пространство имен содержит только устройство обратной связи, после чего вы можете создавать виртуальные интерфейсы или перемещать физические интерфейсы в пространство имен. Сетевой интерфейс принадлежит ровно одному сетевому пространству имен. Контейнеры обычно используют пары виртуальных интерфейсов (драйвер veth), eth0 в пространстве имен контейнера соединен (логически перекрестно связан) с vethXXX в пространстве имен хоста.

PF_RING изначально поддерживает сетевые пространства имен и экспортирует информацию о сокетах в /proc/net/pf_ring/. Для каждого пространства имен существует представление /proc/net/pf_ring/. Когда вы открываете сокет на интерфейсе, он захватывает трафик этого интерфейса в текущем пространстве имен. «Любой» интерфейс является исключением: трафик с этим именем интерфейса все пространства имен захватываются.

IP-сети Эту команду можно использовать для работы с сетевыми пространствами имен, как показано в примерах ниже.

Создайте сетевое пространство имен ns0:

ip netns add ns0

Перечислите все сетевые пространства имен:

ip netns list

Переместите сетевой интерфейс eth1 в сетевое пространство имен ns0:

ip link set eth1 netns ns0

Перечислите все интерфейсы, зарегистрированные с pf_ring на хосте (пространство имен по умолчанию):

ls /proc/net/pf_ring/dev/

Перечислите все интерфейсы, зарегистрированные с pf_ring в пространстве имен ns0:

ip netns exec ns0 ls /proc/net/pf_ring/dev/

Перенесите интерфейс eth1 в пространство имен ns0:

ip netns exec ns0 ifconfig eth1 up

Запустите pfcount в сетевом пространстве имен ns0, захватив данные из eth1:

ip netns exec ns0 pfcount -i eth1

Удалите сетевое пространство имен ns0 (все интерфейсы в ns0 вернутся в пространство имен хоста по умолчанию):

ip netns del ns0
