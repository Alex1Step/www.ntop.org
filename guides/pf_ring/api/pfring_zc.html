3. PF_RING ЗЦ API

PF_RING Заголовочный файл библиотеки ZC.

Этот заголовочный файл автоматически включается в любые приложения на основе PF_RING (когда определен макрос HAVE_PF_RING_ZC).

Определяет

PF_RING_ZC_ENABLE_VM_SUPPORT

pfring_zc_create_cluster() флаг: включить поддержку KVM (память округляется до степени 2, поэтому выделяется больше памяти!)

PF_RING_ZC_DEVICE_ASYMMETRIC_RSS

pfring_zc_open_device() флаг: использовать асимметричный аппаратный RSS для устройств с несколькими очередями.

PF_RING_ZC_DEVICE_FIXED_RSS_Q_0

pfring_zc_open_device() флаг: перенаправить весь трафик в первую очередь HW.

PF_RING_ZC_DEVICE_SW_TIMESTAMP

pfring_zc_open_device() флаг: вычисление временной метки SW (обратите внимание: это добавляет накладные расходы на каждый пакет).

PF_RING_ZC_DEVICE_HW_TIMESTAMP

pfring_zc_open_device() флаг: включить метку времени HW, если она доступна

PF_RING_ZC_DEVICE_STRIP_HW_TIMESTAMP

pfring_zc_open_device() флаг: удалить метку времени HW из пакета, если она доступна

PF_RING_ZC_DEVICE_IXIA_TIMESTAMP

pfring_zc_open_device() флаг: извлечь временную метку IXIA из пакета

PF_RING_ZC_DEVICE_NOT_REPROGRAM_RSS

pfring_zc_open_device() флаг: не перепрограммировать таблицу перенаправления RSS

PF_RING_ZC_DEVICE_CAPTURE_TX

pfring_zc_open_device() флаг: захват трафика RX+TX (игнорируется в режиме обхода ядра)

PF_RING_ZC_DEVICE_IPONLY_RSS

pfring_zc_open_device() флаг: вычислять хеш RSS только по IP (не по 4-кортежному коду)

PF_RING_ZC_DEVICE_NOT_PROMISC

pfring_zc_open_device() флаг: НЕ переводите устройство в неразборчивый режим

PF_RING_ZC_DO_NOT_STRIP_FCS

pfring_zc_open_device() флаг: НЕ удаляйте FCS (CRC), если он не удаляется адаптером

PF_RING_ZC_DEVICE_ARISTA_TIMESTAMP

pfring_zc_open_device() флаг: извлечь временную метку серии Arista 7150 из пакета

PF_RING_ZC_DEVICE_METAWATCH_TIMESTAMP

pfring_zc_open_device() флаг: извлечь метку времени Metawatch из пакета Arista

PF_RING_ZC_DEVICE_CAPTURE_INJECTED

pfring_zc_open_device() флаг: захватывать также внедренные пакеты (см. PF_RING_DISCARD_INJECTED_PKTS)

PF_RING_ZC_DEVICE_HW_TIMESTAMP_UNSYNC

pfring_zc_open_device() флаг: не устанавливать аппаратные часы при использовании PF_RING_ZC_DEVICE_HW_TIMESTAMP

UNDEFINED_QUEUEID

pfring_zc_get_queue_id() return val: идентификатор очереди недействителен

QUEUE_IS_DEVICE(я)

pfring_zc_get_queue_id() return val: идентификатор очереди — это закодированный индекс устройства

QUEUEID_TO_IFINDEX(я)

pfring_zc_get_queue_id() return val: преобразовать идентификатор очереди в индекс устройства, если QUEUE_IS_DEVICE(идентификатор)

IFINDEX_TO_QUEUEID(я)

pfring_zc_get_queue_id() return val: преобразовать обратно индекс устройства в идентификатор очереди, если QUEUE_IS_DEVICE(идентификатор)

PF_RING_ZC_PKT_FLAGS_GOOD_IP_CS

pfring_zc_pkt_buff.flags: обнаружена действительная контрольная сумма IP

PF_RING_ZC_PKT_FLAGS_BAD_IP_CS

pfring_zc_pkt_buff.flags: обнаружена неверная контрольная сумма IP

PF_RING_ZC_PKT_FLAGS_GOOD_L4_CS

pfring_zc_pkt_buff.flags: обнаружена действительная контрольная сумма TCP/UDP

PF_RING_ZC_PKT_FLAGS_BAD_L4_CS

pfring_zc_pkt_buff.flags: обнаружена неверная контрольная сумма TCP/UDP (примечание: на некоторых картах контрольная сумма UDP 0 определяется как плохая!)

PF_RING_ZC_PKT_FLAGS_FLOW_OFFLOAD_UPDATE

pfring_zc_pkt_buff.flags: Устарело

PF_RING_ZC_PKT_FLAGS_FLOW_OFFLOAD_PACKET

pfring_zc_pkt_buff.flags: Устарело

PF_RING_ZC_PKT_FLAGS_FLOW_OFFLOAD_MARKER

pfring_zc_pkt_buff.flags: Устарело

PF_RING_ZC_PKT_FLAGS_FLOW_OFFLOAD_1ST

pfring_zc_pkt_buff.flags: Устарело

PF_RING_ZC_BUILTIN_GTP_HASH_FLAGS_V1

pfring_zc_builtin_gtp_hash флаги: GTP v1

PF_RING_ZC_BUILTIN_GTP_HASH_FLAGS_V2

pfring_zc_builtin_gtp_hash флаги: GTP v2

PF_RING_ZC_BUILTIN_GTP_HASH_FLAGS_GTPC

pfring_zc_builtin_gtp_hash флаги: GTP-C

PF_RING_ZC_BUILTIN_GTP_HASH_FLAGS_GTPU

pfring_zc_builtin_gtp_hash флаги: GTP-U

PF_RING_ZC_API_CLUSTER_INFO
PF_RING_ZC_SEND_PKT_MULTI_MAX_QUEUES

pfring_zc_send_pkt_multi: максимальное количество очередей в Queues_mask

PF_RING_ZC_SEND_PKT_MULTI_V3_MAX_QUEUES

pfring_zc_send_pkt_multi_v3: максимальное количество очередей в Queues_mask

pfring_zc_cluster *pfring_zc_create_cluster(u_int32_t идентификатор_кластера, u_int32_t буфер_len, u_int32_t метаданные_len, u_int32_t tot_num_buffers, int32_t numa_node_id, константа голец *огромные страницы_mountpoint, u_int32_t флаги)

Создайте новый кластер.

Параметры:

  • идентификатор_кластера – Уникальный идентификатор кластера.

  • буфер_len – Размер каждого буфера: он должен быть не меньше размера заголовка MTU + L2 (он будет округлен до строки кэша) и не больше размера страницы.

  • метаданные_len – Размер метаданных каждого буфера.

  • tot_num_buffers – Общее количество буферов, которые необходимо зарезервировать для очередей/устройств/дополнительных выделений.

  • numa_node_id – Идентификатор узла NUMA для привязки cpu/памяти.

  • огромные страницы_mountpoint – Точка монтирования HugeTLB (NULL для автоматического определения) для выделения памяти.

  • флаги – Дополнительные флаги: 

    PF_RING_ZC_ENABLE_VM_SUPPORT enable KVM support (memory is rounded up to power of 2 thus it allocates more memory!)
Возврат:

Дескриптор кластера в случае успеха, в противном случае — NULL (errno устанавливается соответствующим образом).
