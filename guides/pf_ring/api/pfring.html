PF_RING_ZC_SYMMETRIC_RSS

pfring_open() флаг: установите функцию HW RSS в симметричный режим (оба направления одного и того же потока идут в одну и ту же очередь HW). Поддерживается только драйверами ZC. Эта опция также доступна в libpcap с поддержкой PF_RING через переменную среды PCAP_PF_RING_ZC_RSS.

PF_RING_REENTRANT

pfring_open() флаг: устройство открыто в реентерабельном режиме. Это реализовано с помощью семафоров, что приводит к несколько худшему результату. Используйте реентерабельный режим только для многопоточных приложений.

PF_RING_LONG_HEADER

pfring_open() флаг: если используется, PF_RING не заполняет поле Extended_hdr структуры. pfring_pkthdr. Если установлено, поле Extended_hdr также заполняется правильно. Если вам не нужна расширенная информация, установите это значение равным 0, чтобы ускорить работу.

PF_RING_ПРОМИСК

pfring_open() флаг: устройство открыто в беспорядочном режиме.

PF_RING_TIMESTAMP

pfring_open() флаг: принудительно установить PF_RING для установки временной метки полученных пакетов (обычно она не устанавливается при использовании zero-копии для оптимизации производительности).

PF_RING_HW_TIMESTAMP

pfring_open() флаг: включить аппаратную метку времени, если она доступна.

PF_RING_RX_PACKET_BOUNCE

pfring_open() флаг: Включить поддержку быстрой пересылки (см. pfring_send_last_rx_packet()).

PF_RING_ZC_FIXED_RSS_Q_0

pfring_open() флаг: установите hw RSS для отправки всего трафика в очередь 0. Другие очереди можно выбрать с помощью аппаратных фильтров (только карты ZC с аппаратной фильтрацией).

PF_RING_STRIP_HW_TIMESTAMP

pfring_open() флаг: удалить метку времени HW из пакета.

PF_RING_DO_NOT_PARSE

pfring_open() флаг: отключить анализ пакетов также при использовании 1 копии. (анализ уже отключен в zero-копии)

PF_RING_DO_NOT_TIMESTAMP

pfring_open() флаг: отключить метку времени пакета также при использовании 1 копии. (метка времени SW уже отключена в копии zero)

PF_RING_CHUNK_MODE

pfring_open() флаг: включить операции в режиме фрагментов. Этот режим поддерживается только определенными адаптерами и не предназначен для общего использования.

PF_RING_IXIA_TIMESTAMP

pfring_open() флаг: включить поддержку + удаление аппаратных меток времени ixiacom.com.

PF_RING_USERSPACE_BPF

pfring_open() флаг: принудительно использовать пользовательское пространство bpf даже со стандартными драйверами (не только с ZC).

PF_RING_ZC_NOT_REPROGRAM_RSS

PF_RING_ZC_IPONLY_RSS

PF_RING_FLOW_OFFLOAD

PF_RING_FLOW_OFFLOAD_NOUPDATES

Функции

пфринг *pfring_open(константа голец *имя_устройства, u_int32_t каплен, u_int32_t флаги)

Этот вызов используется для инициализации сокета PF_RING, следовательно, для получения дескриптора типа struct pfring, который можно использовать в последующих вызовах. Обратите внимание, что:

  1. вы можете использовать физические (например, ethX) и виртуальные (например, TapX) устройства, RX-очереди (например, ethX@Y) и дополнительные модули (например, zc:ethX@Y, dag:dagX:Y, «multi:ethA\@X;ethB\@Y;ethC\@Z», «stack:ethX»).

  2. вам нужны права суперпользователя, чтобы открыть устройство.

Параметры:

  • имя_устройства – Символическое имя устройства с поддержкой PF_RING, которое мы пытаемся открыть. Синтаксис:

    • интерфейс eth0 eth0, все каналы

    • интерфейс eth0@1 eth0, канал 1

    • интерфейс eth0,eth1 eth0 и eth1, все каналы

    • eth0,eth1@1 интерфейс eth0 и eth1, канал 1

    • интерфейс eth0@1,5 eth0, каналы 1 и 5

    • интерфейс eth0@1-5 eth0, каналы 1,2…5

    • eth0@1-3,5-7 интерфейс eth0, каналы 1,2,3,5,6,7 Примечание:

    • ',' и '-' поддерживаются только стандартными драйверами/драйверами захвата ядра.

    • в случае нескольких интерфейсов каналы одинаковы для всех интерфейсов

  • каплен – Максимальный размер захвата пакетов (также известный как snaplen).

  • флаги – Позволяет указать несколько параметров в компактном формате с использованием растровых изображений (см. макросы PF_RING_*).

интервал pfring_set_poll_watermark(пфринг *кольцо, u_int16_t водяной знак)

Значение по умолчанию для водяного знака (т. е. если приложения пользовательского пространства не манипулируют этим значением посредством этого вызова) — 128.

Параметры:

  • кольцо – Дескриптор PF_RING для включения.

  • водяной знак – Водяной знак опроса пакетов.

Возврат:

0 в случае успеха, в противном случае отрицательное значение.

PF_RING позволяет фильтровать пакеты двумя способами: точным (так называемая хеш-фильтрация) или фильтрацией по подстановочным знакам. Точная фильтрация используется, когда необходимо отслеживать точное соединение из 6 кортежей <vlan Идентификатор, протокол, IP-адрес источника, порт источника, IP-адрес назначения, порт назначения>. Вместо этого используется фильтрация по подстановочным знакам, когда фильтр может содержать подстановочные знаки в некоторых полях (например, сопоставлять все пакеты UDP независимо от их пункта назначения). Если для какого-либо поля установлено значение zero, оно не будет участвовать в расчете фильтра.

typedef struct { … charreflector_device_name[REFLECTOR_NAME_LEN]; … } filtering_rule;

  • кольцо – Дескриптор PF_RING, к которому будет добавлено правило.
