4. PF_RING FT API

PF_RING Заголовочный файл библиотеки FT.

Определяет

FT_API_VERSION
PFRING_FT_ACTION_DEFAULT
PFRING_FT_ACTION_FORWARD
PFRING_FT_ACTION_DISCARD

Отбросить пакет из-за фильтра или шунта

PFRING_FT_ACTION_USER_1
PFRING_FT_ACTION_USER_2
PFRING_FT_ACTION_SLICE

Срез заголовков пакетов

PF_RING_FT_FLOW_FLAGS_L7_GUESS

pfring_ft_flow_value.flags: обнаружен протокол L7 — предположение.

PFRING_FT_TABLE_FLAGS_DPI

pfring_ft_create_table() флаг: включить поддержку nDPI для обнаружения протокола L7

PFRING_FT_TABLE_FLAGS_DPI_EXTRA

pfring_ft_create_table() флаг: включить nDPI дополнительное рассечение (больше метаданных потока)

PFRING_FT_DECODE_TUNNELS

pfring_ft_create_table() флаг: декодировать туннели (GTP, L2TP, CAPWAP)

PFRING_FT_IGNORE_HW_HASH

pfring_ft_create_table() флаг: игнорировать хэш пакета (например, когда он асимметричен, что приводит к одному потоку в каждом направлении)

PFRING_FT_IGNORE_VLAN

pfring_ft_create_table() флаг: не включать vlan в ключ потока

PFRING_FT_TABLE_FLAGS_NO_GUESS

pfring_ft_create_table() флаг: не угадывать протокол, если он не обнаружен с помощью DPI

PFRING_FT_KEY_EXT_MAC

pfring_ft_create_table() флаг: включить MAC-адрес источника и назначения в ключ потока

Функции

pfring_ft_table *pfring_ft_create_table(u_int32_t флаги, u_int32_t max_flows, u_int32_t flow_idle_timeout, u_int32_t flow_lifetime_timeout, u_int32_t user_metadata_size)

Создайте новую таблицу потоков.

Параметры:

  • флаги – Флаги для включения выбранных функций таблицы потоков.

  • max_flows – Максимальное количество одновременных потоков, которые должна обрабатывать таблица (используйте 0, если не уверены в использовании настроек по умолчанию).

  • flow_idle_timeout – Максимальное время простоя потока (в секундах) до истечения срока действия (используйте 0, если не уверены в использовании значения по умолчанию: 30 с).

  • flow_lifetime_timeout – Максимальная продолжительность потока (в секундах) до истечения срока действия (используйте 0, если не уверены в использовании значения по умолчанию: 2 м).

  • user_metadata_size – Размер метаданных пользователя в pfring_ft_flow_value->user.

Возврат:

Таблица потоков в случае успеха, NULL в случае неудачи.

пустота pfring_ft_destroy_table(pfring_ft_table *стол)

Уничтожить таблицу потоков.

Параметры:

пустота pfring_ft_flow_set_flow_slicing(pfring_ft_table *стол, u_int32_t flow_slice_timeout)

Включите разделение потока для периодического экспорта обновлений потока, даже если настроенное значение flow_lifetime_timeout не достигнуто.

Параметры:

  • стол – Ручка таблицы потоков.

  • flow_slice_timeout – Максимальная продолжительность среза потока (секунды). Это значение должно быть ниже, чем flow_lifetime_timeout.

пустота pfring_ft_set_l7_detected_callback(pfring_ft_table *стол, pfring_ft_flow_packet_func перезвонить, пустота *пользователь)

Установите функцию, которая будет вызываться, когда пакет и его поток обработаны и только что обнаружен протокол l7.

  • пользователь – Пользовательские данные, предоставленные обратному вызову.

пустота pfring_ft_set_flow_export_callback(pfring_ft_table *стол, pfring_ft_export_flow_func перезвонить, пустота *пользователь)

Установите функцию, которая будет вызываться, когда поток истекает и его необходимо экспортировать. Обратный вызов должен освободить поток, вызывающий pfring_ft_flow_free(flow).

Параметры:

  • стол – Ручка таблицы потоков.

  • перезвонить – Обратный звонок.

  • пользователь – Пользовательские данные, предоставленные обратному вызову.

пустота pfring_ft_set_flow_list_export_callback(pfring_ft_table *стол, pfring_ft_export_list_func перезвонить, пустота *пользователь)

Установите функцию, которая будет вызываться, когда какой-либо поток истекает и его необходимо экспортировать. Это можно использовать как оптимизированную альтернативу pfring_ft_set_flow_export_callback(). Обратный вызов должен освободить все потоки в списке, вызывая pfring_ft_flow_free(flow) для каждого потока. Можно перебрать все потоки в списке, используя pfring_ft_list_get_next().

Параметры:

  • стол – Ручка таблицы потоков.

  • перезвонить – Обратный звонок.

  • пользователь – Пользовательские данные, предоставленные обратному вызову.

pfring_ft_action pfring_ft_process(pfring_ft_table *стол, константа u_char *пакет, константа pfring_ft_pcap_pkthdr *заголовок, константа pfring_ft_ext_pkthdr *ext_header)

Предоставьте необработанный пакет в таблицу потоков для обработки. Обычно основной цикл захвата передает все пакеты в хеш-таблицу, вызывающую эту функцию.

Параметры:

  • стол – Ручка таблицы потоков.

  • пакет – Необработанный пакет.

  • заголовок – Метаданные пакета (включая длину и временную метку).

  • ext_header – Дополнительные метаданные пакета недоступны в заголовке pcap (включая хэш).

Возврат:

Действие над пакетом, если заданы правила фильтрации.

интервал pfring_ft_housekeeping(pfring_ft_table *стол, u_int32_t эпоха)

Его следует вызывать, когда нет пакетов для обработки и основной цикл простаивает, для выполнения служебных операций в таблице потоков.

Параметры:

  • стол – Ручка таблицы потоков.

  • эпоха – Текущая эпоха (сек).

Возврат:

1, если есть еще работа, 0, если вызывающий абонент может немного поспать.

Параметры:

стол – Ручка таблицы потоков.

интервал pfring_ft_flow_get_users(pfring_ft_flow *поток)
