5. Либкап API

PF_RING включает исправленный libpcap, который обеспечивает ускорение PF_RING через леги pcap API. Очевидно, что приложение на основе pcap должно быть связано с libpcap с поддержкой PF_RING, чтобы использовать его. Ожидайте снижения производительности относительно PF_RING API, поскольку pcap API вносит дополнительные накладные расходы.

5.1. API Расширения

В этом разделе перечислены расширения, добавленные к устаревшим pcap API. Обратите внимание, что они не обязательны для работы, поверх них может работать устаревшее приложение на базе pcap этой библиотеки без изменений (требуется только линковка).

  • pcap_get_pfring_handle — возвращает дескриптор pfring.

  • pcap_get_pfring_id — оболочка для pfring_get_ring_id API.

  • pcap_set_master_id — оболочка для pfring_set_master_id API.

  • pcap_set_master — оболочка для pfring_set_master API.

  • pcap_set_application_name — оболочка для pfring_set_application_name API.

  • pcap_set_cluster — оболочка для pfring_set_cluster API.

  • pcap_set_watermark — оболочка для pfring_set_poll_watermark API.

  • pcap_set_poll_watermark_timeout — оболочка для pfring_set_poll_watermark_timeout API.

5.1.1. Переменные среды

В этом разделе перечислены переменные среды, поддерживаемые расширенной библиотекой pcap. для управления режимом работы без изменения приложения на базе pcap.

  • PCAP_PF_RING_ACTIVE_POLL — установить активный опрос (CPU крутится)

  • PCAP_PF_RING_RSS_REHASH — установить перехеширование RSS в ядре со стандартными драйверами.

  • PCAP_PF_RING_ALWAYS_SYNC_FD — всегда синхронизировать дескриптор файла после получения

  • PCAP_PF_RING_ZC_RSS — установить симметричный RSS на драйверах ZC

  • PCAP_PF_RING_STRIP_HW_TIMESTAMP — установка аппаратного удаления меток времени из пакетов.

  • PCAP_PF_RING_HW_TIMESTAMP — включить аппаратную метку времени

  • PCAP_PF_RING_USERSPACE_BPF - принудительно использовать пользовательское пространство BPF вместо внутриядерной оценки BPF

  • PCAP_PF_RING_RECV_ONLY — установить для сокета режим только приема

  • PCAP_PF_RING_APPNAME — установить имя приложения

  • PCAP_PF_RING_CLUSTER_ID — установить идентификатор кластера ядра
