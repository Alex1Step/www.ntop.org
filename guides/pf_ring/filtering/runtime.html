2. Фильтрация во время выполнения

PF_RING 8.5 или новее включает встроенную поддержку фильтрации во время выполнения, то есть возможность добавлять правила фильтрации во время работы приложения бежит.

Правила фильтрации автоматически преобразуются в аппаратные правила и вводится непосредственно в адаптер для аппаратной оценки и добавьте zero накладные расходы. Для этого требуется адаптер, поддерживающий аппаратное обеспечение. фильтрация (например, NVIDIA/Mellanox ConnectX).

Это позволяет запускать приложения, связанные с CPU (например, IDS/IPS) и получать (процессировать) только выбранный трафик, согласно правилам, которые динамически создаются и передаются в механизм захвата. Для того, чтобы Для достижения этой цели адаптер настроен на отбрасывание всего трафика путем по умолчанию и пересылать только пакеты, соответствующие хостам, требующим внимания.

Фильтры передаются в механизм захвата посредством очереди Redis, и их можно добавлять и удалять с помощью команд типа «добавить хост» или «удалить хост».

2.1. Включение фильтрации во время выполнения

Чтобы включить фильтрацию времени выполнения в PF_RING, PF_RING_RUNTIME_MANAGER должна быть установлена переменная среды, используя в качестве значения имя Redis очередь, используемая для отправки команд фильтрации.

Пример использования pfcount:

PF_RING_RUNTIME_MANAGER="pfring.mlx5_0.filter.host.queue" pfcount -i mlx:mlx5_0 -0

2.2. Нажатие фильтров

Фильтры можно помещать в очередь Redis программно или вручную. используя команду «+<IP>», чтобы добавить правило для определенного хоста, а Команда «-<IP>» для удаления правила.

Пример использования redis-cli:

redis-cli RPUSH pfring.mlx5_0.filter.host.queue "+10.0.0.1" "+10.0.0.2" "+10.0.0.3"
redis-cli RPUSH pfring.mlx5_0.filter.host.queue "-10.0.0.2"

2.3. Redis Настройки подключения

По умолчанию при включении фильтрации времени выполнения PF_RING подключается к Redis на локальном хосте. порт 6379. Этим можно управлять через среду PF_RING_REDIS_SETTINGS. переменная. Поддерживаемые форматы:

  • хост: порт

  • хозяин@redis_экземпляр

  • хост: порт@redis_instance

  • хост:порт:пароль@redis_экземпляр

Примеры:

PF_RING_REDIS_SETTINGS="@2"
PF_RING_REDIS_SETTINGS="129.168.1.3"
PF_RING_REDIS_SETTINGS="129.168.1.3:6379@3"
PF_RING_REDIS_SETTINGS="129.168.1.3:6379:nt0pngPwD@0"
PF_RING_REDIS_SETTINGS="/var/run/redis/redis.sock"
PF_RING_REDIS_SETTINGS="/var/run/redis/redis.sock@2"

2.4. Отладка

Для отладки компонента Runtime Filtering можно включить ведение журнала. правил, при этом сообщение выводится на stderr каждый раз, когда правило добавляется или удаляется. Это можно включить, установив переменную среды PF_RING_RUNTIME_MANAGER_DEBUG.

Пример

PF_RING_RUNTIME_MANAGER="pfring.mlx5_0.filter.host.queue" PF_RING_RUNTIME_MANAGER_DEBUG="1" pfcount -i mlx:mlx5_0
