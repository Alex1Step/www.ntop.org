Intel Процессоры

В разделе AMD описывается, как настроить процессоры AMD RYZEN или EPYC в случае проблемы с запуском PF_RING ZC. На самом деле на AMD часто возникают проблемы с IOMMU из-за того, как память приложения предоставляется сетевой карте с Драйверы ZC для прямой передачи пакетов с помощью DMA.

На Intel обычно все работает просто из коробки. Однако в зависимости от CPU, BIOS и ядро, аналогичная проблема может возникнуть на процессорах Intel.

Признак состоит в том, что приложение не может захватывать трафик, захватывать пустые пакеты или просто погибнуть из-за плохого доступа к памяти. Примеры:

# pfcount -i zc:enp179s0f0 -v 1
[RX][if_index=0][hash=4294967295][00:00:00:00:00:00 -> 00:00:00:00:00:00] [eth_type=0x0000] [caplen=1536][len=65531][eth_offset=0][l3_offset=14][l4_offset=0][payload_offset=0]
[RX][if_index=0][hash=4294967295][00:00:00:00:00:00 -> 00:00:00:00:00:00] [eth_type=0x0000] [caplen=1536][len=65531][eth_offset=0][l3_offset=14][l4_offset=0][payload_offset=0]

# pfcount -i zc:enp179s0f0
Killed

Это также можно проверить, просмотрев dmesg на наличие сообщений, связанных с IOMMU или DMAR. Пример:

[232592.844165] DMAR: DRHD: handling fault status reg 202
[232592.845073] DMAR: [DMA Write NO_PASID] Request device [b3:00.0] fault addr 0xa6dd9000 [fault reason 0x05] PTE Write access is not set
[232592.846495] DMAR: [DMA Write NO_PASID] Request device [b3:00.0] fault addr 0xb3b9f000 [fault reason 0x05] PTE Write access is not set
[232592.847911] DMAR: [DMA Write NO_PASID] Request device [b3:00.0] fault addr 0xb96bd000 [fault reason 0x05] PTE Write access is not set

Чтобы это исправить, вам необходимо отключить поддержку IOMMU.

  1. (Необязательно) Установите для параметра IOMMU (или VT-d / Поддержка виртуализации) значение «Отключено» в BIOS.

2. Отключите intel_iommu в параметрах загрузки GRUB, добавив «intel_iommu=off». в GRUB_CMDLINE_LINUX /etc/default/grub и запустите update-grub на Ubuntu или «grub2-mkconfig -o /boot/grub2/grub.cfg» на CentOS.

Теперь вы сможете запустить ZC.

Общие проблемы

Если вы используете систему на базе UEFI с CentOS/RHEL, обратите внимание, что шаги по настройке grub немного отличаются. В этом случае вам следует запустите «grub2-mkconfig -o /boot/efi/EFI/redhat/grub.cfg», чтобы обновить загрузочный файл.
