1. Установка из пакетов

Готовые к использованию пакеты PF_RING доступны по адресу http://packages.ntop.org, следуйте инструкциям на той же странице для настройки репозитория. и установить пфринг и pfring-dkms. При желании вы также можете установить pfring-drivers-zc-dkms если вам нужны драйверы ZC для захвата скорости линии на адаптерах Intel.

В этом разделе вы узнаете, как настроить PF_RING с помощью сценариев инициализации. (init.d или systemctl в зависимости от вашего дистрибутива Linux), содержащийся в пфринг пакет, чтобы автоматизировать загрузку модуля ядра и драйверов. Альтернативно, пожалуйста обратите внимание, что можно автоматически настроить PF_RING и драйверы с помощью pf_ringcfg скрипт (начиная с PF_RING 7.5) или через nBox GUI.

1.1. Мастер настройки (pf_ringcfg)

Начиная с версии PF_RING 7.5, пакет pfring включает в себя pf_ringcfg сценарий, который может быть используется для автоматического создания конфигурации модуля ядра PF_RING и драйверов. Предполагается, что это работает в большинстве случаев, однако для конкретных/пользовательских конфигураций, пожалуйста, обратитесь к Ручная настройка настройки.

Настройка и загрузка драйвера ZC для интерфейса с pf_ringcfg является прямым, это можно сделать в несколько шагов:

  1. Настройте репозиторий, как описано в http://packages.ntop.org и установите пфринг пакет, который включает скрипт pf_ringcfg (пример для Ubuntu ниже):

apt-get install pfring

  1. Перечислите интерфейсы и проверьте модель драйвера:

pf_ringcfg --list-interfaces
Name: em1                  Driver: igb        [Supported by ZC]
Name: p1p2                 Driver: ixgbe      [Supported by ZC]
Name: p1p1                 Driver: ixgbe      [Supported by ZC]

  1. Настройте и загрузите драйвер, указав модель драйвера и (необязательно) количество очередей RSS на интерфейс:

pf_ringcfg --configure-driver ixgbe --rss-queues 1

  1. Убедитесь, что драйвер успешно загружен, выполнив поиск «Работающий ZC»:

pf_ringcfg --list-interfaces
Name: em1                  Driver: igb        [Supported by ZC]
Name: p1p2                 Driver: ixgbe      [Running ZC]
Name: p1p1                 Driver: ixgbe      [Running ZC]

1.2. Ручная настройка

Сценарий инициализации действует следующим образом:

  1. он загружает модуль ядра pf_ring.ko, считывая параметры модуля из /etc/pf_ring/pf_ring.conf

  2. он сканирует /etc/pf_ring/zc/{igb,ixgbe,ixgbevf,i40e,iavf,ice,mlx}/ в поисках файлов конфигурации драйверов:

    • {igb,ixgbe,ixgbevf,i40e,iavf,ice,mlx}.conf, независимо параметры драйвера

    • {igb,ixgbe,ixgbevf,i40e,iavf,ice,mlx}.start это должен быть просто пустой файл

  3. он загружает драйверы, для которых имеется соответствующий файл {igb,ixgbe,ixgbevf,i40e,iavf,ice,mlx}.start, выгружая стандартный драйвер.

  4. если драйвер ZC загружен, он настраивает огромные страницы, считывая конфигурацию из /etc/pf_ring/hugepages.conf. Каждая строка (одна на CPU) файла конфигурации должна содержать:

node=<NUMA node id> hugepagenumber=<number of pages> [gid=<GID>]

Ниже вы можете найти базовая конфигурация пример использования PF_RING с стандартные драйверы на Ubuntu с помощью systemd. В этом примере мы настраиваем размер буфера ядра (параметр min_num_slots). для улучшения производительности и поглощения всплесков трафика:

apt-get install pfring-dkms
echo "min_num_slots=65536" > /etc/pf_ring/pf_ring.conf
systemctl restart pf_ring

Чтобы использовать pf_ring с драйверами ZC, вам нужно прежде всего разобраться, что такое модель драйвера вашей сетевой карты. Для этого используйте ethtool -i <interface>. Пример:

ethtool -i eth1 | grep driver
driver: ixgbe

Ниже вы можете найти базовая конфигурация пример для двухпортового ixgbe карта с Драйверы ZC на Ubuntu с использованием systemd конфигурация для других моделей карт аналогична (замените ixgbe на ваша настоящая семья водителей).

apt-get install pfring-dkms pfring-drivers-zc-dkms
mkdir -p /etc/pf_ring/zc/ixgbe
echo "RSS=1,1" | tee /etc/pf_ring/zc/ixgbe/ixgbe.conf
touch /etc/pf_ring/zc/ixgbe/ixgbe.start
echo "node=0 hugepagenumber=1024" | tee /etc/pf_ring/hugepages.conf
systemctl restart pf_ring

Обратите внимание, что в этой конфигурации RSS отключен (RSS=1 означает одну очередь). Чтобы узнать больше о RSS и включить несколько очередей для распределения трафика пожалуйста, прочитайте RSS раздел.

Ниже вы можете узнать, что должна содержать папка /etc/pf_ring после создания. конфигурацию, как описано в примере выше.

tree /etc/pf_ring/
|-- hugepages.conf
|-- pf_ring.conf
`-- zc
    `-- ixgbe
        |-- ixgbe.conf
        `-- ixgbe.start

Чтобы запустить сценарий инициализации после настройки всех файлов, если ваша система использует systemd, запустите:

systemctl restart pf_ring

В противном случае вы можете использовать скрипт init.d:

touch /etc/pf_ring/pf_ring.start
/etc/init.d/pf_ring start

Вы можете проверить, что драйвер ZC действительно работает:

cat /proc/net/pf_ring/dev/eth1/info | grep ZC
Polling Mode:      ZC/NAPI

Примечание. Если вы пытаетесь загрузить драйвер ZC на карту, которую в данный момент используете в качестве управляющей, вам может потребоваться принудительно создать принудительный запуск файл конфигурации. _(Предупреждение: это может привести к нарушению сетевого подключения, не пытайтесь подключиться к удаленной системе без возможности восстановления.)_

touch /etc/pf_ring/forcestart

В качестве альтернативы вы можете явно указать сценарию инициализации, какие интерфейсы вы используете для управления, а какие — для перехвата пакетов, создав файл конфигурации /etc/pf_ring/interfaces.conf, содержащий:

MANAGEMENT_INTERFACES="eth0 eth1"
CAPTURE_INTERFACES="eth2 eth3 eth4 eth5"

Если вы принудительно pf_ring перезагрузите драйвер, который используется интерфейсом управления, вам, вероятно, потребуется переконфигурируйте интерфейс после загрузки драйвера ZC. Сценарий systemd поддерживает пользовательские почта сценарии (а также предварительно скрипты), которые выполняются сразу после загрузки модуля pf_ring и драйверов, все, что вам нужно нужно создать скрипт /etc/pf_ring/post, как показано в примере ниже:

echo "ifconfig eth0 192.168.1.1" > /etc/pf_ring/post
chmod +x /etc/pf_ring/post

1.3. Разгрузки

Служба pf_ring по умолчанию отключает всю разгрузку сетевых интерфейсов на машине. поскольку эти разгрузки изменяют пакеты (например, GRO объединяет несколько пакетов в один) и такое поведение нежелательно при мониторинге трафика, поскольку это приводит к плохим показателям. (например, количество пакетов в сети, размер пакета и т. д.). Однако это может повлиять на производительность при использовании интерфейсов для подключения к хосту. Обратите внимание, что pf_ring не отключает настройки разгрузки для интерфейса управления (когда настроен с помощью MANAGEMENT_INTERFACES в /etc/pf_ring/interfaces.conf, как описано выше, или в противном случае определяется автоматически). Однако можно полностью отключить это для всех. интерфейсы, создав держать разгрузку файл (если pf_ring уже запущен, перезагрузите компьютер чтобы оно было эффективным).

touch /etc/pf_ring/keepoffload

1.4. Конфигурация виртуальных функций

PF_RING также предоставляет драйверы ZC для интерфейсов виртуальных функций (ixgbe/ixgbevf и i40e/iavf). Включение и настройка виртуальных функций на физическом интерфейсе требует нескольких шагов.

Прежде всего, ядро должно быть настроено для создания виртуальных функций. добавив хотя бы pci=назначить-шины параметр в параметры grub. Пример:

cat /etc/default/grub | grep GRUB_CMDLINE_LINUX_DEFAULT
GRUB_CMDLINE_LINUX_DEFAULT="iommu=1 msi=1 pci=assign-busses intel_iommu=on"

Примечание. Включение iommu и intel_iommu может создать проблемы в некоторых системах и может потребоваться. чтобы отключить их, пожалуйста, также проверьте Процессоры AMD и Intel Процессоры разделы.

Это изменение необходимо применить с помощью update-grub и перезагрузить систему.

update-grub
reboot

В качестве второго шага следует создать виртуальные функции через /sys fs, указав количество виртуальных функций. Функция, которую мы хотим включить для каждого физического интерфейса. Некоторые дополнительные настройки через ИП команда также требуется для запуска виртуальной функции в беспорядочном режиме (доверять режим) или назначить VLAN. Это можно автоматизировать с помощью предварительно/почта сценарии. Пример:

cat /etc/pf_ring/zc/iavf/iavf.pre
echo '2' > /sys/bus/pci/devices/$(ethtool -i enp1s0f1 | grep bus-info | cut -d ' ' -f2)/sriov_numvfs
ip link set enp1s0f1 vf 0 vlan 10
ip link set dev enp1s0f1 vf 0 trust on

Добавьте права выполнения скрипту, чтобы включить его:

chmod +x /etc/pf_ring/zc/iavf/iavf.pre

1.5. Конфигурация балансировщика трафика

PF_RING включает универсальное приложение балансировки трафика под названием zbalance_ipc, которое можно использовать для распределения трафика между приложениями. Здесь вы можете узнать больше о его конфигурации и параметрах запуска.
