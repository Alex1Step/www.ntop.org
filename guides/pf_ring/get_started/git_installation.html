2. Установка из GIT

PF_RING можно загрузить в исходном формате из GIT по адресу https://github.com/ntop/PF_RING/ или установить из пакетов, используя наши репозитории по адресу http://packages.ntop.org как описано в Установка из пакетов раздел. В этой главе мы рассмотрим установку из исходного кода.

Клонируйте наш репозиторий, чтобы загрузить исходный код PF_RING:

git clone https://github.com/ntop/PF_RING.git

Исходный код PF_RING включает в себя:

  • Пользовательское пространство SDK.

  • Расширенная версия libpcap, которая прозрачно использует преимущества PF_RING.

  • Модуль ядра PF_RING.

  • PF_RING Драйверы ZC.

2.1. Установка модуля ядра

Чтобы скомпилировать модуль ядра PF_RING, вам нужны заголовки ядра Linux. (или исходный код ядра).

cd PF_RING/kernel
make
sudo make install

2.2. Бег PF_RING

Перед использованием любого приложения PF_RING необходимо загрузить модуль ядра pf_ring:

cd PF_RING/kernel
sudo insmod ./pf_ring.ko [min_num_slots=N] [enable_tx_capture=1|0] [ enable_ip_defrag=1|0]

Где:

min_num_slots

Минимальное количество пакетов, которые модуль ядра должен иметь возможность поставить в очередь (по умолчанию — 4096).

Enable_tx_capture

Установите значение 1 для захвата исходящих пакетов, установите значение 0 для отключения захвата исходящих пакетов (по умолчанию – RX+TX).

Enable_ip_defrag

Установите значение 1, чтобы включить дефрагментацию IP, дефрагментируется только RX-трафик (по умолчанию — отключено).

Пример:

cd PF_RING/kernel
sudo insmod pf_ring.ko min_num_slots=65536 enable_tx_capture=0

2.3. Драйверы

Если вы хотите добиться захвата пакетов со скоростью линии 10 Гигабит и выше на адаптерах Intel, тебе следует использовать Драйверы ZC. Вы можете проверить семейство драйверов с использованием ethtool:

ethtool -i eth1 | grep driver
driver: ixgbe

и загрузите соответствующий драйвер, используя load_driver.sh скрипт в папке драйвера:

cd PF_RING/drivers/intel
./configure && make
cd ixgbe/ixgbe-*-zc/src
sudo ./load_driver.sh

2.4. Установка Libpfring и Libpcap

И libpfring (библиотека пользовательского пространства PF_RING), и libpcap распространяются в исходном формате. Их можно скомпилировать и установить следующим образом:

cd PF_RING/userland/lib
./configure && make
sudo make install
cd ../libpcap
./configure && make
sudo make install

Обратите внимание, что устаревшие статически связанные приложения на основе pcap необходимо перекомпилировать с использованием новый libpcap.a с поддержкой PF_RING, чтобы воспользоваться преимуществами PF_RING. Не ждите, что в этом случае используйте PF_RING без перекомпиляции существующего приложения.

2.5. Примеры применения

Если вы новичок в PF_RING, вы можете начать с нескольких примеров. Папка userland/examples богат готовыми к использованию PF_RING приложениями:

cd PF_RING/userland/examples
make

Например, pfcount позволяет вам получать пакеты, выводящие некоторую статистику:

sudo ./pfcount -i zc:eth1
...
=========================
Absolute Stats: [64415543 pkts rcvd][0 pkts dropped]
Total Pkts=64415543/Dropped=0.0 %
64'415'543 pkts - 5'410'905'612 bytes [4'293'748.94 pkt/sec - 2'885.39 Mbit/sec]
=========================
Actual Stats: 14214472 pkts [1'000.03 ms][14'214'017.15 pps/9.55 Gbps]
=========================

Другой пример — pfsend, который позволяет отправлять пакеты (синтетические пакеты, или, опционально, pcap файл) с произвольной скоростью:

sudo ./pfsend -f 64byte_packets.pcap -n 0 -i zc:eth1 -r 5
...
TX rate: [current 7'508'239.00 pps/5.05 Gbps][average 7'508'239.00 pps/5.05 Gbps][total 7'508'239.00 pkts]

2.6. PF_RING Дополнительные модули

Библиотека PF_RING имеет модульную архитектуру, что позволяет использовать дополнительные модули захвата, отличные от стандартного модуля ядра PF_RING. Эти компоненты включается во время выполнения в зависимости от фактического используемого адаптера. PF_RING модулей на данный момент включить поддержку Fiberblaze, Napatech и других, пожалуйста, также прочитайте Драйверы и модули раздел.
