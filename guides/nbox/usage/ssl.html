2. SSL Сертификат

Пользовательский интерфейс nBox основан на Cockpit, для связи с которым требуется SSL/TLS. Веб-браузер. Cockpit прослушивает соединения HTTP и HTTPS на одном и том же порту, по умолчанию 9090. Если установлено соединение HTTP, Cockpit перенаправит это соединение. до HTTPS.

По умолчанию используется самозаверяющий сертификат, обратитесь к документации Cockpit. в https://cockpit-project.org/guide/latest/https правильно настроить сертификат для производственного использования.
