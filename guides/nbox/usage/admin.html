5. Обновления системы

Страница «Обновления системы» позволяет администратору управлять обновлениями всего программного обеспечения, включая приложения и драйверы ntop.

В качестве альтернативы можно запускать обновления, подключаясь к устройству через страницу терминала или SSH и используя стандартный менеджер пакетов для используемого дистрибутива Linux. Пример систем на основе apt (Ubuntu/Debian)

sudo apt-get update
sudo apt-get upgrade
