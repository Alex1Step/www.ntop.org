nBox UI Documentation

nBox UI is a web-based interface that can simplify the ntop’s software configurations, assist with complex things such as creating configuration files, and let you focus on using ntop applications rather than on their configuration. nBox can be used to configure and run ntopng, nProbe, nProbe Cento, n2disk and the PF_RING ZC Cluster.
