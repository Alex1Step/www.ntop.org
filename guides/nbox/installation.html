Начать

Для установки пользовательского интерфейса nBox потребовалась установка nboxui упаковка. Ниже приведены инструкции в соответствии с дистрибутивом Linux.

Debian/Ubuntu

apt install nboxui

Вы можете запустить службу как

service cockpit start

RedHat/Рокки Линукс

yum install nboxui
systemctl enable --now cockpit.socket

После установки пакета можно получить доступ к GUI, подключаясь к IP-адрес машины с помощью браузера через порт 9090 (например. http://192.168.1.1:9090).

ntop Брендинг

После установки nboxui скопируйте на целевой компьютер файлы, находящиеся в этом каталоге. https://github.com/ntop/cockpit-ntop/tree/dev/branding в /usr/share/cockpit/branding/ubuntu/

git clone https://github.com/ntop/cockpit-ntop.git
cd cockpit-ntop
cp -r branding/* /usr/share/cockpit/branding/ubuntu/
