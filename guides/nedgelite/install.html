Установка

В этом разделе представлены подробные инструкции по установке nEdge Lite в вашей системе Linux.

Установка из пакетов

В репозитории доступны готовые пакеты для многих дистрибутивов Linux.

  1. Установите репозиторий, следуя инструкциям по адресу http://packages.ntop.org/

  2. Установите негелит упаковка.

Установка лицензии

Для работы nEdge Lite требуется действительный файл лицензии. Файл лицензии следует разместить в одном из следующих мест:

  • nedgelite.license (текущий каталог)

  • /etc/nedgelite.license (общесистемный)

Команды управления лицензиями

# Verify installation
nedgelite --version

# Display system ID for license generation
nedgelite --show-system-id

# Check license validity
nedgelite --check-license

# Check maintenance status
nedgelite --check-maintenance

Свяжитесь с ntop.org или посетите http://shop.ntop.org/ получить коммерческую лицензию.

Действия после установки

После установки nEdge Lite выполните следующие шаги настройки:

  1. Проверка установки

    nedgelite --version
nedgelite --help

  2. Настроить сетевой фильтр

    Настройте правила iptables (см. Настройка сетевого фильтра подробнее):

    # For bridge mode
sudo /usr/share/nedgelite/scripts/bridge_setup.sh lan0 wan0

# For single interface mode
sudo /usr/share/nedgelite/scripts/default_setup.sh eth0

  3. Установить лицензию

    Скопируйте файл лицензии:

    sudo cp nedgelite.license /etc/nedgelite.license
nedgelite --check-license

  4. Тестирование основных операций

    Запустите nEdge Lite с минимальной конфигурацией:

    sudo nedgelite -q 0 -v

    Нажмите Ctrl+C, чтобы остановить. Вы должны увидеть успешный запуск nEdge Lite.

Следующие шаги

  • Быстрый старт: Следуйте Краткое руководство руководство по первому развертыванию

  • Настройка сетевого фильтра: Настройте правила сетевого фильтра в Настройка сетевого фильтра

  • ntopng Интеграция: Настройте интеграцию ntopng в ntopng Интеграция

Удаление

Ubuntu/Debian:

sudo apt-get remove nedgelite
sudo apt-get purge nedgelite  # Also remove configuration files

CentOS/Рокки:

sudo yum remove nedgelite

Удалить конфигурацию

sudo rm -rf /etc/nedgelite
sudo rm -f /etc/nedgelite.license
