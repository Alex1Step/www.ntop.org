Документация nEdge Lite

nEdge Lite — это приложение для фильтрации пакетов уровня 7 и глубокой проверки пакетов (DPI) на основе сетевого фильтра, которое интегрируется с ntopng. Он использует очереди сетевого фильтра Linux для перехвата пакетов, выполняет обнаружение протокола с помощью nDPI, применяет правила политики и экспортирует информацию о потоках для мониторинга и управления политиками.
