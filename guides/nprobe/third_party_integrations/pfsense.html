pfsense

nProbe можно установить на pfsense с помощью командной строки. Для этого требуется настроить репозиторий FreeBSD как описано в https://packages.ntop.org/FreeBSD/.

Конфигурация репозитория

Войдите в оболочку pfsense как администратор (выберите вариант 8).

И установите репозиторий, используя команду, указанную по адресу https://packages.ntop.org/FreeBSD/ (вы можете вырезать и вставить команду ниже).

pkg add https://packages.ntop.org/FreeBSD/FreeBSD:11:amd64/latest/ntop-1.0.txz

Результат должен выглядеть так, как показано ниже.

Установка пакета

После входа в оболочку pfsense выполните приведенную ниже команду для установки. пакет nProbe:

pkg install nprobe

Конфигурация лицензии

Запустите команду ниже, чтобы получить всю необходимую информацию. генератором лицензий (Версия и Идентификатор системы).

/usr/local/bin/nprobe --version

Лицензия должна быть установлена ​​в /usr/local/etc/nprobe.license.

echo LICENSE_KEY > /usr/local/etc/nprobe.license

nProbe Конфигурация

Пример файла конфигурации nProbe находится в каталоге /usr/local/etc/nprobe/nprobe.conf.sample, скопируйте его в /usr/local/etc/nprobe.conf и на всякий случай откройте его в предпочитаемом редакторе. настройки по умолчанию должны быть изменены.

Включите nProbe с помощью следующих команд:

sysrc nprobe_enable="YES"

Запустите службу nProbe:

service nprobe start
