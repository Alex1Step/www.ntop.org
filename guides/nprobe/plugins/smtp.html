SMTP Плагин

Этот плагин анализирует трафик SMTP и сохраняет его в файлах дампа, а также экспортирует информацию через NetFlow/IPFIX, используя следующие информационные элементы.

[NFv9 57657][IPFIX 35632.185][Len 64 varlen] %SMTP_MAIL_FROM                    Mail sender
[NFv9 57658][IPFIX 35632.186][Len 64 varlen] %SMTP_RCPT_TO                      Mail recipient

SMTP опция поддержки плагинов --smtp-dump-dir <dump dir>. При использовании этой опции nProbe записывает файлы дампа SMTP в <dump dir>. Несколько файлов создаются в иерархическом дереве каталогов ГГГГ/ММ/ДД, длина каждого файла не превышает 1000 строк.

Дополнительную команду можно выполнять каждый раз, когда nProbe завершает выгрузку каталога с помощью опции --smtp-exec-cmd <cmd>. Команда <cmd> выполняется с использованием системного вызова system().

Примечание

Поскольку этот плагин анализирует пакеты трафика, он доступен только при использовании nProbe в режиме проверки.
