Плагин GTPv0

Этот плагин анализирует сигнальную информацию GTPv0 (GTP-C) и сохраняет ее в файлах дампа, а также экспортирует информацию через NetFlow/IPFIX, используя следующие информационные элементы.

%GTPV0_REQ_MSG_TYPE               GTPv0 Request Msg Type
%GTPV0_RSP_MSG_TYPE               GTPv0 Response Msg Type
%GTPV0_TID                        GTPv0 Tunnel Identifier
%GTPV0_APN_NAME                   GTPv0 APN Name
%GTPV0_END_USER_IP                GTPv0 End User IP Address
%GTPV0_END_USER_MSISDN            GTPv0 End User MSISDN
%GTPV0_RAI_MCC                    GTPv0 Mobile Country Code
%GTPV0_RAI_MNC                    GTPv0 Mobile Network Code
%GTPV0_RAI_CELL_LAC               GTPv0 Cell Location Area Code
%GTPV0_RAI_CELL_RAC               GTPv0 Cell Routing Area Code
%GTPV0_RESPONSE_CAUSE             GTPv0 Cause of Operation

Плагин поддерживает следующие параметры командной строки, которые используются для указания места сохранения (необязательного) файла журнала GTP. Как описано ранее для -P, дампы вложены в каталоги. Можно указать nProbe выполнить команду, когда каталог (не файл журнала) полностью сброшен (т. е. nProbe перешел в следующий каталог по времени).

--gtpv0-dump-dir <dump dir> Directory where GTP logs will be dumped
--gtpv0-exec-cmd <cmd>    Command executed whenever a directory has been dumped

Обратите внимание, что GTP-U обрабатывается не этим плагином, а ядром nProbe, когда используется опция –tunnel.
