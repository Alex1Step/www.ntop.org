BGP Плагин¶

С помощью плагина nProbe BGP можно экспортировать первые десять Автономные системы (АС) как на пути AS к клиенту, так и к сервер каждого потока.

AS-пути, являющиеся общеизвестными обязательными атрибутами BGP, определяется путем установления сеанса BGP с BGP-маршрутизатором. BGP сеансы устанавливаются вспомогательным скриптом bgp_probe_client.pl который инкапсулирует все функциональность, необходимая для установления и поддержания сеанса пиринга BGP и обмениваться информацией об обновлении маршрутизации. В частности, сценарий:

  • Устанавливает сеанс BGP с BGP-маршрутизатором.
  • Считывает BGP обновлений для извлечения AS-путей.
  • Отправляет AS-пути на nProbe

BGP с nProbe и bgp_probe_client.pl

Скрипт может быть бесплатно скачать отсюда.

После загрузки скрипта его необходимо настроить с помощью IP-адрес и AS маршрутизатора BGP, а также IP-адрес и порт хоста, на котором работает nProbe.

Конфигурация выполняется простым редактированием первых строк файла загруженный скрипт и включает в себя следующие переменные:

  • $local_ip устанавливает идентификатор BGP (IP-адрес) локального узла сессии BGP. Требуется строка в десятичном формате IP, разделенном точками. обозначения.
  • $local_as устанавливает номер AS локального узла BGP BGP сеанс. Он принимает целое значение в диапазоне 16-битного беззнаковое целое число.
  • $remote_ip устанавливает идентификатор BGP (IP-адрес) удаленного узла сессии BGP. Требуется строка в десятичном формате IP, разделенном точками. обозначения.
  • $remote_as устанавливает номер AS BGP удаленного узла BGP сеанс. Он принимает целое значение в диапазоне 16-битного беззнаковое целое число.
  • $nprobe_ip устанавливает IP-адрес хоста, на котором работает nProbe. Скрипт попытается подключиться к $nprobe_ip на $nprobe_port для обмена информацией о AS-путях.
  • $nprobe_port устанавливает порт, на котором находится nProbe прослушивание входящих BGP AS-путей. Это должен быть тот же порт, что и указан в опции nProbe --bgp-port.

Пример конфигурации выглядит следующим образом:

# BGP
my $local_ip = '192.168.48.2';
my $local_as = 65498;
my $remote_ip = '192.168.48.1';
my $remote_as = 2597;

# nProbe
my $nprobe_ip   = '127.0.0.1';
my $nprobe_port = 4096;

В приведенной выше конфигурации удаленный узел AS-2597 BGP-маршрутизатор находится в состоянии 192.168.48.1. Скрипт подключится к удаленному узлу заявляя о себе как AS-65498 вглядеться 192.168.48.2. nProbe предполагается, что он работает на том же самом localhost скрипта, прослушивающего соединения на порту 4096.

После завершения настройки nProbe можно запустить с помощью опции --bgp-port <port>, где <port> установлено значение $nprobe_port. Наконец, сценарий можно запустить, чтобы он подключитесь к nProbe на указанном порту.

Этот плагин определяет следующие информационные элементы, которые могут быть используется в шаблоне как любой другой обычный информационный элемент:

%SRC_AS_PATH_1                    Src AS path position 1
%SRC_AS_PATH_2                    Src AS path position 2
%SRC_AS_PATH_3                    Src AS path position 3
%SRC_AS_PATH_4                    Src AS path position 4
%SRC_AS_PATH_5                    Src AS path position 5
%SRC_AS_PATH_6                    Src AS path position 6
%SRC_AS_PATH_7                    Src AS path position 7
%SRC_AS_PATH_8                    Src AS path position 8
%SRC_AS_PATH_9                    Src AS path position 9
%SRC_AS_PATH_10                   Src AS path position 10
%DST_AS_PATH_1                    Dest AS path position 1
%DST_AS_PATH_2                    Dest AS path position 2
%DST_AS_PATH_3                    Dest AS path position 3
%DST_AS_PATH_4                    Dest AS path position 4
%DST_AS_PATH_5                    Dest AS path position 5
%DST_AS_PATH_6                    Dest AS path position 6
%DST_AS_PATH_7                    Dest AS path position 7

Пример¶

$ sudo nprobe --bgp-port 9999 --zmq "tcp://*:5556" -i none \
  -n none --collector-port 2055 \
  -T "@NTOPNG@ %SRC_TOS %DST_TOS %INPUT_SNMP %OUTPUT_SNMP \
  %SRC_AS_PATH_1 %SRC_AS_PATH_2 %SRC_AS_PATH_3 %SRC_AS_PATH_4 \
  %SRC_AS_PATH_5 %SRC_AS_PH_6 %SRC_AS_PATH_7 %SRC_AS_PATH_8 \
  %DST_AS_PATH_1 %DST_AS_PATH_2 %DST_AS_PATH_3 %DST_AS_PATH_4 \
  %DST_AS_PATH_5 %DST_AS_PATH_6 %DST_AS_PATH_7 %DST_AS_PATH_8"

Экземпляр nProbe, выполненный выше, экспортируется через ZMQ (--zmq "tcp://*:5556") NetFlow данные, собранные в порту 2055 (--collector-port 2055), включая первые 8 AS в AS-путь к клиенту и к серверу. nProbe ожидает bgp_probe_client.pl работать и экспортировать в порт 9999 (--bgp-port 9999).
