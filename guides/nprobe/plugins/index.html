nProbe Плагины

nProbe был разработан как механизм, обрабатывающий пакеты и вычисляющий базовую статистику, а также плагины, расширяющие ядро ​​дополнительными возможностями. Каждый плагин анализирует определенный трафик (например, трафик электронной почты SMTP), но вы можете включить использование нескольких плагинов одновременно.

Примечание

nProbe на основе конфигурации шаблона (-T) выборочно включает плагины и определяет столько шаблонов, сколько необходимо. Их количество зависит от включенных плагинов и от того, можете ли вы включить поддержку трафика IPv4 и/или IPv6.

Предупреждение

Для включения плагинов требуется лицензия. Видеть Лицензирование для получения дополнительной информации. Элементы шаблона, специфичные для плагина, будут игнорироваться, если соответствующий плагин не лицензирован.

Справку по плагинам можно распечатать с помощью опции -H.

nprobe -H

При этом будет распечатана расширенная справка со всеми доступными плагинами, а также их соответствующими параметрами и поддерживаемыми элементами информации о потоке. Например, для плагина HTTP при использовании будет напечатана следующая информация: nprobe -H:

[HTTP Protocol]
  --http-dump-dir <dump dir>                         | Directory where HTTP logs will be dumped
  --http-content-dump-dir <dump dir>                 | Directory where HTTP content (request only) will be dumped
  --http-content-dump-response                       | Dump both HTTP request and response with --http-content-dump-dir
  --http-exec-cmd <cmd>                              | Command executed whenever a directory has been dumped
  --dont-hash-cookies                                | Dump cookie string instead of cookie hash
  --http-verbose-level <level>                       | 0 - Relevant info,  1 - Very verbose (default: 1)
  --http-ports                                       | List of ports used for http protocol (default: 80)
  --proxy-ports                                      | List of ports used for proxy protocol (default: 3128, 8080)
  --http-parse-geolocation                           | Dump geolocation info if explicitly present inside mobile app protocol (e.g., "Nimbuzz")

Plugin HTTP Protocol templates:
[NFv9 57652][IPFIX 35632.180][Len 128 varlen] %HTTP_URL                         HTTP URL (IXIA URI)
[NFv9 57832][IPFIX 35632.360][Len 4 varlen] %HTTP_METHOD                        HTTP METHOD
[NFv9 57653][IPFIX 35632.181][Len 2] %HTTP_RET_CODE                             HTTP return code (e.g. 200, 304...)
[NFv9 57654][IPFIX 35632.182][Len 128 varlen] %HTTP_REFERER                     HTTP Referer
[NFv9 57655][IPFIX 35632.183][Len 256 varlen] %HTTP_UA                          HTTP User Agent
[NFv9 57656][IPFIX 35632.184][Len 256 varlen] %HTTP_MIME                        HTTP Mime Type
[NFv9 57659][IPFIX 35632.187][Len 64 varlen] %HTTP_HOST                         HTTP(S) Host Name (IXIA Host Name)
[NFv9 57833][IPFIX 35632.361][Len 64 varlen] %HTTP_SITE                         HTTP server without host name
[NFv9 57932][IPFIX 35632.460][Len 256 varlen] %HTTP_X_FORWARDED_FOR             HTTP X-Forwarded-For
[NFv9 57933][IPFIX 35632.461][Len 256 varlen] %HTTP_VIA                         HTTP Via

В следующих разделах описаны элементы конфигурации и информации, предоставляемые каждым отдельным плагином. Большинство плагинов доступны также в исходном формате, но иногда из-за лицензионных ограничений (например, плагин спонсируется компанией, которая не хочет, чтобы другие имели доступ к исходному коду) мы не можем выпустить все плагины в исходном формате.
