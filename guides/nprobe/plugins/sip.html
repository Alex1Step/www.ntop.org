SIP Плагин

Этот плагин анализирует информацию о трафике SIP и сохраняет ее в файлах дампа, а также экспортирует информацию через NetFlow/IPFIX, используя следующие информационные элементы.

%SIP_CALL_ID               SIP call-id
%SIP_CALLING_PARTY         SIP Call initiator
%SIP_CALLED_PARTY          SIP Called party
%SIP_RTP_CODECS            SIP RTP codecs
%SIP_INVITE_TIME           SIP time (epoch) of INVITE
%SIP_TRYING_TIME           SIP time (epoch) of Trying
%SIP_RINGING_TIME          SIP time (epoch) of RINGING
%SIP_INVITE_OK_TIME        SIP time (epoch) of INVITE OK
%SIP_INVITE_FAILURE_TIME   SIP time (epoch) of INVITE FAILURE
%SIP_BYE_TIME              SIP time (epoch) of BYE
%SIP_BYE_OK_TIME           SIP time (epoch) of BYE OK
%SIP_CANCEL_TIME           SIP time (epoch) of CANCEL
%SIP_CANCEL_OK_TIME        SIP time (epoch) of CANCEL OK
%SIP_RTP_IPV4_SRC_ADDR     SIP RTP stream source IP
%SIP_RTP_L4_SRC_PORT       SIP RTP stream source port
%SIP_RTP_IPV4_DST_ADDR     SIP RTP stream dest IP
%SIP_RTP_L4_DST_PORT       SIP RTP stream dest port
%SIP_RESPONSE_CODE         SIP failure response code
%SIP_REASON_CAUSE          SIP Cancel/Bye/Failure reason cause
%SIP_UAC                   SIP user-agent client
%SIP_UAS                   SIP user-agent server
%SIP_C_IP                  SIP C IP adresses
%SIP_CALL_STATE            SIP Call State

Клиент пользовательского агента (UAC) — это объект, который отправляет запросы SIP и получает SIP ответов. Например, телефон SIP является UAC, потому что он отправляет запрос INVITE для создания голосового вызова. Пользовательский агент Сервер (UAS) — это объект, который принимает SIP запросов и отправляет SIP ответы. БПЛА отправит SIP запросы РЕГИСТРАЦИЯ, но это не так. считаются сообщениями о создании сеанса. Также есть телефон SIP. UAS, потому что он принимает запросы INVITE для звонка телефону и предупредите пользователя. Из-за их двойной роли пользовательский агент Клиент (%SIP_UAC) и сервер агента Sser (%SIP_UAS) являются выражается относительно клиента и сервера потока.

Примечание

Поскольку этот плагин анализирует пакеты трафика, он доступен только при использовании nProbe в режиме проверки.
