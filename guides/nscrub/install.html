Установка

Для запуска nscrub необходимы следующие основные шаги:

  1. Установите и настройте драйверы PF_RING и ZC (далее в этой главе).

  2. Установите nScrub (далее в этой главе) и настройте его для работы с оптимальными настройками (главы «Конфигурация двигателя», «Производительность» и «Настройка»).

  3. Настройте nScrub для снижения трафика (глава «Конфигурация контроля трафика»).

Предпосылки:

  • PF_RING для ускорения захвата пакетов

  • redis-сервер для хранения конфигурации и состояния системы

Обратите внимание, что установочные пакеты предоставляются для некоторых дистрибутивов Linux, включая Ubuntu, Debian и CentOS по адресу http://packages.ntop.org/. Пожалуйста, следуйте инструкциям на веб-сайте для настройки репозитория и установите хотя бы pfring-dkms, pfring-drivers-zc-dkms и nscrub.

PF_RING

После установки pfring-dkms и pfring-drivers-zc-dkms, можно использовать сценарий инициализации в /etc/init.d/pf_ring для автоматизации загрузки модуля ядра и драйверов, как описано в PF_RING Руководстве пользователя по адресу http://www.ntop.org/guides/pf_ring/get_started/packages_installation.html

Для нетерпеливых это пример минимальной конфигурации двухпортовой карты ixgbe (замените ixgbe на свою модель драйвера) на однопроцессоре:

touch /etc/pf_ring/pf_ring.start
mkdir -p /etc/pf_ring/zc/ixgbe
touch /etc/pf_ring/zc/ixgbe/ixgbe.start
echo "RSS=0,0" > /etc/pf_ring/zc/ixgbe/ixgbe.conf
echo "node=0 hugepagenumber=1024" > /etc/pf_ring/hugepages.conf

Обратите внимание, что RSS=0,0 создаст столько очередей интерфейса, сколько количество ядер, однако, поскольку большинство карт Intel поддерживают до 16 очередей RSS для балансировки нагрузки, в случае процессоров с большим количеством ядер рекомендуется принудительно увеличить их до 16, используя RSS=16,16.

Также обратите внимание, что количество огромных страниц, необходимое для выделения памяти, зависит от количества интерфейсных очередей (и вспомогательных очередей, если таковые имеются) и MTU. Например, если вы настраиваете 12 очередей RSS с MTU 1500 байт, вам, вероятно, понадобится до 2048 огромных страниц; если вы настраиваете 16 очередей RSS, общая конфигурация составляет 4096 огромных страниц.

Чтобы загрузить pf_ring, если ваша система использует systemd, запустите:

systemctl start pf_ring

В противном случае используйте сценарий init.d:

/etc/init.d/pf_ring start

nScrub

Установка nscrub довольно проста, просто установите nscrub пакет из репозитория, а затем перейдите к следующим главам.

Примечание

Не существует учетных данных по умолчанию для подключения к движку через nscrub-cli или REST API, необходимо настроить пароль для администратор следуя инструкциям, изложенным в Установка пароля REST API раздел в главе «Конфигурация контроля трафика».
