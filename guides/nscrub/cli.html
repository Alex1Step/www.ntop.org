Инструменты командной строки

nscrub-cli

nscrub-cli — это инструмент командной строки для настройки nScrub с использованием автозаполнения вместо использования REST API вручную.

Вы можете запустить nscrub-cli чтобы получить доступ к конфигурации nscrub, без каких-либо опций или передачи пользователя/пароля и хоста/порта, если вы настроили конфигурацию nscrub.

nscrub-cli -h
nscrub-cli [-v] [-h] [-a <user>:<password>] [-c <host>:<port>]

Бегать nscrub-cli чтобы открыть консоль, затем введите «help», чтобы получить полный список поддерживаемых команд. Пожалуйста, обратитесь к REST API для описания.

Мастер-инструмент nscrub-добавить также доступен для создания новой цели с базовой конфигурацией, предоставляющей идентификатор цели, подсеть и тип службы.

nscrub-add [options] <target id> <subnet> <target type>

Пример:

nscrub-add WEBSERVER 192.168.1.1/32 web

Обратите внимание, что для создания оптимальной конфигурации на основе конкретной цели обычно необходимы дополнительные настройки. Можно использовать nscrub-cli для этого.

nscrub-cli также позволяет вам передать файл конфигурации, содержащий nscrub-cli команды с использованием канала. Пример:

cat nscrub.conf
targets add TEST 192.168.1.2/32
targets add TEST 192.168.1.3/32
cat nscrub.conf | nscrub-cli -a admin:<password>

Пожалуйста, обратитесь к nscrub-cli help для обновленного списка команд, как в примере ниже.

nscrub-cli -a admin:<password>
localhost:8880> help

nscrub-экспорт

nscrub-экспорт может использоваться для дампа/резервного копирования конфигурации/политик конкретной цели (или всех целей).

Все настроенные цели можно просмотреть с помощью команды list:

nscrub-export list
webserver1
webserver2

Чтобы сбросить конфигурацию для конкретного целевого запуска nscrub-экспорт с именем цели (или «все» для всех целей):

nscrub-export dump webserver1

В приведенном ниже примере мы создаем резервную копию и восстанавливаем конфигурацию цели, используя nscrub-экспорт в сочетании с nscrub-cli:

nscrub-export dump webserver1 > webserver1.dump
cat webserver1.dump | nscrub-cli -a admin:<password>
