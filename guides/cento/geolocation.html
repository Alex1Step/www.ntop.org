База данных геолокации

nProbe Cento включает поддержку геолокации, предоставляемую следующими компаниями

  • МаксМинд https://www.maxmind.com

  • БД-ИП https://db-ip.com

Реализация геолокации основана на файле базы данных, хранящемся локально без какого-либо доступа к облаку.

Вы можете установить бесплатные (хотя и не очень точные) базы данных GeoIP или коммерческие.

Использование геолокации MaxMind

Новые правила конфиденциальности, такие как GDPR и CCPA, накладывают ограничения, которые влияют на нашу способность распространять базы данных MaxMind GeoLite2 в наших пакетах. Причины подробно описаны на следующей странице. https://blog.maxmind.com/2019/12/18/significant-changes-to-accessing-and-using-geolite2-databases/. По этой причине вам необходимо зарегистрировать учетную запись MaxMind и получить лицензионный ключ для загрузки баз данных геолокации GeoLite2.

Следующие шаги необходимы для использования геолокации.

Зарегистрируйте учетную запись MaxMind на сайте https://www.maxmind.com/en/geolite2/signup.

Создайте лицензионный ключ на https://www.maxmind.com/en/accounts/current/license-key.

  1. Выберите «Создать новый лицензионный ключ».

  2. Добавьте описание лицензионного ключа и ответьте «Да» на вопрос «Будет ли этот ключ использоваться для обновления GeoIP?».

  3. Затем выберите один из двух доступных вариантов «Сгенерировать лицензионный ключ и файл конфигурации». Выбор зависит от установленного геоипобновление версия. Скорее всего, установленная версия старше 3.1.1, поэтому правильный вариант выбора — «Создать лицензионный ключ и файл конфигурации для использования с геоипобновление версии старше 3.1.1". Если вы не знаете тип версии геоипдате -V.

После создания лицензии вам будет предложено загрузить файл. GeoIP.conf который содержит идентификатор учетной записи и лицензионный ключ, необходимые для загрузки баз данных. Загрузите и поместите этот файл в /etc/GeoIP.conf.

Убедитесь, что Идентификаторы издания раздел (или Идентификаторы продуктов согласно геоипобновление версия) в /etc/GeoIP.conf содержит GeoLite2-Страна GeoLite2-Город GeoLite2-ASN (ГеоЛайт2-АСН может отсутствовать по умолчанию).

Бегать sudo geoipupdate загрузить файлы базы данных или загрузить файлы базы данных вручную GeoLite2-ASN.mmdb и GeoLite2-City.mmdb из раздела «GeoIP2 / GeoLite2» > «Загрузить файлы» на странице вашей учетной записи MaxMind.

Чтобы обновить базу данных, вы можете использовать геоипобновление. Инструкции по использованию геоипобновление доступны на https://dev.maxmind.com/geoip/geoipupdate/

Использование DB-IP Lite

Базы данных геолокации DB-IP Lite dbip-city-lite, dbip-asn-lite и dbip-country-lite можно скачать с https://db-ip.com/db/

Установить файлы БД

Загруженные файлы базы данных (mmdb) следует переместить в одну из следующих папок:

  • /var/lib/GeoIP

  • /usr/доля/GeoIP

  • ./geoip (при запуске nProbe Cento вручную, та же папка)

И их имя должно соответствовать:

  • GeoLite2-ASN.mmdb

  • GeoLite2-City.mmdb

или

  • dbip-asn*.mmdb

  • dbip-city*.mmdb

mkdir /var/lib/GeoIP
mv GeoLite2-ASN.mmdb /var/lib/GeoIP
mv GeoLite2-City.mmdb /var/lib/GeoIP

Перезагрузите nProbe Cento. После перезапуска программное обеспечение автоматически найдет и загрузит загруженные базы данных.
