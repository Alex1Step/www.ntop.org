Системад

cento управляется с помощью утилиты системаctl по операционным системам и дистрибутивы, использующие системный менеджер службы.

После успешной установки пакета служба cento автоматически запускается на интерфейсе обратной связи. В сервисе используется файл конфигурации, который находится по адресу /etc/cento/cento.conf и который заполняется некоторыми значениями по умолчанию во время установки. файл конфигурации можно редактировать и расширять любой конфигурацией опция, поддерживаемая cento. Требуется перезапуск службы после модификации файла конфигурации.

Служба cento всегда запускается при загрузке по умолчанию. Сервис необходимо отключить, чтобы предотвратить такое поведение.

Файл конфигурации службы cento

Конфигурационный файл находится по адресу /etc/cento/cento.conf.

Управление центо

Чтобы запустить, остановить и перезапустить тип службы cento:

systemctl start cento
systemctl stop cento
systemctl restart cento

Чтобы предотвратить запуск cento при типе загрузки:

systemctl disable cento

Чтобы запустить cento при загрузке, если он ранее был отключен, тип:

systemctl enable cento

Чтобы проверить статус службы, включая ее выходные данные и PID, введите:

systemctl status cento

Созданные сервисы cento

Существуют обстоятельства, при которых несколько экземпляров cento служба может работать на том же хосте. Чтобы управлять конкретным <экземпляр> услуги, добавьте @<экземпляр> к центо название услуги.

Обычно <экземпляр> соответствует имени интерфейса (например, ено1). Это соглашение позволяет легко определить назначение каждого обслуживание. Тем не менее, любая строка приемлема в качестве значения для <экземпляр>.

<экземпляр> однозначно идентифицирует услугу и соответствующую ей файл конфигурации, который находится под /etc/cento/cento-<экземпляр>.conf.

Например, чтобы запустить две службы Cento, на интерфейсе ено1 и еще один интерфейс копирования zero eth1 соответственно, можно создать следующие файлы конфигурации:

/etc/cento/cento-eno1.conf
/etc/cento/cento-zc:eth1.conf

А затем запустите службы с помощью:

systemctl start cento@eno1
systemctl start cento@zc:eth1

При желании можно запустить службы при загрузке с помощью:

systemctl enable cento@eno1
systemctl enable cento@zc:eth1

Статус вышеперечисленных услуг можно контролировать с помощью:

systemctl status cento@eno1
systemctl status cento@zc:eth1
