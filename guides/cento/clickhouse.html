ClickHouse Экспорт

nProbe™ Cento может экспортировать записи потоков непосредственно в ClickHouse база данных. Формат экспорта совместим с дампом потока ntopng ClickHouse, что позволяет ntopng визуализировать и анализировать записи потока, созданные nProbe™ Cento.

Эта интеграция предназначена для высокоскоростных сред мониторинга, где nProbe™ Cento обрабатывает захват пакетов и генерацию потока на скорости линии, а ntopng обеспечивает визуализацию потока, исторический анализ и составление отчетов путем считывания потоков непосредственно из общей базы данных ClickHouse.

Обзор

Типичное развертывание включает в себя:

  1. nProbe™ Центо захватывает пакеты и экспортирует записи потока в ClickHouse.

  2. ClickHouse сохраняет записи потока в формате, совместимом с ntopng.

  3. ntopng подключается к той же базе данных ClickHouse в режиме только для чтения для визуализации и анализа потоков.

Network Traffic -> nProbe Cento (write) -> ClickHouse -> ntopng (read-only)

Связь

--clickhouse Опция указывает адрес и порт сервера ClickHouse. Порт относится к порту собственного протокола ClickHouse TCP (по умолчанию: 9000). Чтобы включить шифрование SSL, добавьте s на номер порта.

Примеры:

# Connect to localhost on default port 9000
cento -i zc:eth1 --clickhouse 127.0.0.1

# Connect to a remote host on default port 9000
cento -i zc:eth1 --clickhouse 192.168.1.1

# Connect with SSL encryption
cento -i zc:eth1 --clickhouse 192.168.1.1:9000s

Аутентификация

--clickhouse-auth опция указывает учетные данные ClickHouse в user:password формат. По умолчанию используется ClickHouse default пользователь.

cento -i zc:eth1 --clickhouse 192.168.1.1 --clickhouse-auth myuser:mypassword

Имя базы данных

--clickhouse-dbname Опция указывает имя базы данных. Значение по умолчанию: ntopng, что соответствует имени базы данных, используемому ntopng при выгрузке потоков в ClickHouse.

cento -i zc:eth1 --clickhouse 192.168.1.1 --clickhouse-dbname ntopng

Идентификатор интерфейса

--clickhouse-interface-id Опция устанавливает идентификатор интерфейса ntopng, связанный с экспортируемыми потоками. Этот идентификатор используется ntopng для идентификации исходного интерфейса при чтении потоков. Значение по умолчанию: 0.

cento -i zc:eth1 --clickhouse 192.168.1.1 --clickhouse-interface-id 3

Поддержка кластеров

--clickhouse-cluster Опция включает экспорт в кластер ClickHouse. Если указано, nProbe™ Cento создает базу данных и выгружает потоки в кластер, обеспечивая репликацию данных между узлами кластера.

cento -i zc:eth1 --clickhouse 192.168.1.1 --clickhouse-cluster mycluster

Эта опция предназначена для использования с правильно настроенным кластером ClickHouse. При подключении к экземпляру ClickHouse с одним узлом опустите этот параметр.

Интеграция с ntopng

Экспорт потока в ClickHouse предназначен для совместимости с дампом потока ntopng в ClickHouse. Это позволяет ntopng напрямую читать исторические записи потоков, созданные nProbe™ Cento, без необходимости создания дампа потоков.

ntopng поддерживает режим только для чтения, специально разработанный для этой интеграции, при запуске с --readonly-flows-dump вариант. С помощью этой опции ntopng подключается к ClickHouse для чтения потоков, созданных nProbe™ Cento, без записи каких-либо данных потока.

Шаг 1: Запустите nProbe Cento

Запустите nProbe™ Cento с включенным дампом ClickHouse в дополнение к экспорту ZMQ:

cento -i zc:eth1 --zmq tcp://127.0.0.1:5556 --clickhouse 192.168.1.1 --dpi-level 2

Шаг 2. Запустите ntopng в режиме только для чтения.

Начните ntopng с поддержкой ClickHouse в режиме только для чтения, используя -F clickhouse и --readonly-flows-dump параметры:

ntopng -i tcp://*:5556c -F clickhouse --readonly-flows-dump

В этой конфигурации ntopng считывает исторические данные о потоке, созданные nProbe™ Cento из ClickHouse, и обеспечивает визуализацию и анализ исторического потока без выполнения какого-либо дампа потока. В то же время ntopng обрабатывает живой трафик, собирая потоки от ZMQ.

Пожалуйста, обратитесь к ntopng документация для получения дополнительной информации о настройке ntopng с ClickHouse.
