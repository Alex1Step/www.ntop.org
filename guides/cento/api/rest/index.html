RESTful API

Cento реализует RESTful API, используя встроенный сервер HTTP, для динамической реконфигурации механизма пересылки.

RESTful API можно включить, добавив [--rest-address|-Y] <address> доступ к нему осуществляется через HTTP (по умолчанию порт 8880) или через HTTPS (по умолчанию порт 4443).

Порты HTTP и HTTPs можно изменить с помощью [--rest-http-port|-T] <port> и [--rest-https-port|-S] <port> параметры.

Для использования HTTP требуется сертификат. Создайте его с помощью:

mkdir -p /usr/local/share/cento/httpdocs/ssl
openssl req -new -x509 -sha1 -extensions v3_ca -nodes -days 365 -out cert.pem
cat privkey.pem cert.pem > /usr/local/share/cento/httpdocs/ssl/ssl-cert.pem

Пример командной строки с использованием опции --rest-address для включения REST API:

cento-ids -i zc:eth1 --aggregated-egress-queue --egress-conf egress.example --dpi-level 2 -v 4 --rest-address 127.0.0.1

Настройки по умолчанию:

  • HTTP порт: 8880

  • HTTPs порт: 4443

Учетных данных по умолчанию нет: пароль должен быть настроен в Redis для пользователя перед REST API примет аутентификацию от имени этого пользователя. См. Аутентификация раздел REST API спецификация, как ее установить.

Пожалуйста, проверьте спецификации REST API для получения информации о доступных конечных точках REST.

Это доступно на центо-ид и центо-мост только потому, что он в основном используется чтобы изменить выходную конфигурацию во время выполнения.
