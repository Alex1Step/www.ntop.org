6. npcapmanage

Эта утилита используется для управления хранением данных путем перечисления или удаления трафика старше указанного интервала времени. Он работает со структурой каталогов временной шкалы, созданной n2disk, и может эффективно удалять файлы pcap, их индексы и связанные ссылки на временной шкале в пределах заданного диапазона времени.

npcapmanage особенно полезен для реализации политик хранения данных, освобождения дискового пространства и обеспечения соответствия требованиям к хранению данных.

Доступные варианты:

[-d]                  | Delete all PCAPs in the specified time interval
[-t] <timeline dir>   | Timeline directory created by n2disk
[-b] <begin time>     | Begin time (format: YYYY-MM-DD HH:MM:SS)
[-e] <end time>       | End time (format: YYYY-MM-DD HH:MM:SS)
[-v] <verbosity>      | Verbosity level (0-6, default: 2)
[-h]                  | Help

6.1. Как это работает

При запуске с -d флаг, npcapmanage выполняет следующие операции для каждого файла pcap в указанном диапазоне времени:

  1. Сканирует структуру каталогов временной шкалы с интервалом в 10 минут.

  2. Идентифицирует файлы pcap в указанном диапазоне времени на основе их временных меток.

  3. Следует по символическим ссылкам от временной шкалы к фактическим местам хранения.

  4. Удаляет файл pcap из хранилища.

  5. Удаляет соответствующий индексный файл (.idx).

  6. Удаляет символические ссылки временной шкалы (файлы .timeline).

  7. Очищает пустые подкаталоги временной шкалы.

Инструмент предназначен для обработки структуры двунаправленной символической ссылки, используемой n2disk, где:

  • Каталог временной шкалы содержит ссылки, указывающие на файлы хранилища.

  • Файлы хранилища содержат обратные ссылки (.timeline), указывающие на записи временной шкалы.

6.2. Пример использования

Удалить все файлы pcap, снятые в определенное время:

npcapmanage -t /storage/n2disk/timeline -b "2024-09-01 00:00:00" -e "2024-09-15 23:59:59" -d

Список файлов, которые будут удалены (без флага -d инструмент будет сканировать и регистрировать, но не удалять):

npcapmanage -t /storage/n2disk/timeline -b "2024-09-01 00:00:00" -e "2024-09-15 00:00:00" -v 3

Удалить последние 5 минут захваченного трафика:

npcapmanage -t /timeline -b "2024-09-30 14:55:00" -e "2024-09-30 15:00:00" -d

6.3. Важные примечания

  • -d Флаг необходим для фактического удаления файлов. Без него npcapmanage будет только сканировать и сообщать.

  • Формат времени должен быть именно таким: YYYY-MM-DD HH:MM:SS

  • Время начала является инклюзивным, время окончания является исключительным (файлы с отметкой времени >= времени окончания не удаляются)

  • Инструмент обрабатывает как абсолютные, так и относительные символические ссылки.

  • Пустые каталоги временной шкалы автоматически удаляются после удаления файла.

  • Используйте более высокие уровни детализации (-v 6), чтобы просмотреть подробную информацию о каждой файловой операции.

  • Инструмент сообщает общее количество удаленных файлов и время обработки после завершения.
