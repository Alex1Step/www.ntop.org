9. ндедуп

ndedup — это инструмент, реализующий дедупликацию пакетов. Дедупликация пакетов — важная функция очистка и оптимизация потока трафика в сторону инструментов мониторинга и безопасности путем удаления избыточные пакеты. Дублированные пакеты могут присутствовать по многим причинам, например, при использовании SPAN-порты для мониторинга нескольких каналов. Дублированные пакеты представляют собой проблему для инструмента мониторинга, поскольку анализ дублирующихся пакетов выдает неправильные цифры в вашей аналитике, а также требует более высокой обработки и пространства. ресурсы для системы мониторинга.

ndedup — это инструмент, работающий в режиме реального времени, как прозрачный мост. Когда приходит пакет, инструмент использует одностороннее шифрование для преобразования пакета в сильное, устойчивое к коллизиям хеш-значение. Этот хэш по сравнению с хешем каждого пакета, который пришел до него в заранее настроенном временном окне (например, последний 50 мс), и все это на очень высокой скорости (до 100Gbps). Благодаря этому этот инструмент можно развернуть спереди. любого устройства, на котором установлено программное обеспечение для мониторинга сети (включая n2disk).

Этот инструмент может работать поверх любого адаптера (Intel, Mellanox, Napatech) и увеличивать производительность. используя технологию RSS.

Поддерживаемые варианты:

-i <device>     Ingress device name. Multiple interfaces/queues supported:
                - Multiple -i to run on multiple segments (e.g. -i eth0@0 -i eth0@1 -o eth1@0 -o eth1@1)
                - RSS short notation (e.g. -i eth0@[0-3] means -i eth0@0 -i eth0@1 -i eth0@2 -i eth0@3)
-o <device>     Egress device name (see -i for supported notations)
-c <cluster id> cluster id
-b              Bridge mode (forward in both directions)
-B              Enable burst API
-g <core id>    Bind this app to a core (with -b use <core id>:<core id>)
-a              Active packet wait
-f              Flush packets immediately
-d <msec>       Deduplication window size (msec)
-s <gbps>       Link Speed (default: 10 Gbps)
-S <core id>    Enable Time Pulse thread and bind it to a core
-R <nsec>       Time resolution (nsec) when using Time Pulse thread
                Note: in non-time-sensitive applications use >= 100usec to reduce cpu load
-v              Verbose

Пример (Intel ZC):

ndedup -i zc:eth1 -o zc:eth2 -d 10 -s 10 -S 0 -g 1 -B

Пример (RSS = 4):

ndedup -i zc:eth1@[0-3] -o zc:eth2@[0-3] -d 10 -s 10 -S 0 -g 1:2:3:4 -B
