2. Napatech Настройка

Чтобы n2disk работал с максимальной производительностью на адаптерах Napatech, необходимо правильно настроить систему. После установки программного обеспечения Napatech вам следует настроить файл конфигурации /opt/napatech3/config/ntservice.ini, изменив параметры, как показано ниже.

Стандартный PCAP с метками времени в микросекундах:

TimestampFormat = PCAP

PCAP с наносекундными метками времени:

TimestampFormat = PCAP_NS

Дескриптор пакета:

PacketDescriptor = PCAP

Размер сегмента (максимум 4 МБ):

HostBufferSegmentSizeRx = 4

При желании увеличьте буфер хоста RX до 128 MB:

HostBuffersRx = [4,128,0]

После завершения настройки драйвер Napatech можно запустить с помощью:

/opt/napatech3/bin/ntstart.sh

Драйвер PF_RING можно загрузить с помощью systemctl:

systemctl start pf_ring

Теперь вы готовы начать n2disk:

n2disk -o /storage -p 1000 -b 4000 -i nt:0 -q 1 -C 1024 -c 1 -z 2 -w 3 -n 50 -m 100

где nt:0 означает Napatech порт 0.

Карте Napatech можно дать команду создать поток, например объединить два порта. Можно открыть поток, используя nt:stream<ID> в качестве имени интерфейса. Пример:

ntpl -e "Assign[streamid=0] = port == 0,1"

n2disk -o /storage -p 1000 -b 4000 -i nt:stream0 -q 1 -C 1024 -w 0 -c 1 --disk-limit 80%
