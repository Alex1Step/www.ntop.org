3. Silicom FPGA Настройка

Чтобы n2disk работал на адаптерах Silicom FPGA (Fiberblaze), на адаптере необходимо настроить группу PRB (конфигурация потоков). Для получения дополнительной информации посетите документацию PF_RING. Обратите внимание, что для обеспечения высокой производительности n2disk автоматически настраивается режим фрагментов на адаптере. Никакой специальной конфигурации для применения не требуется.

Пожалуйста, просто убедитесь, что драйвер PF_RING загружен с помощью systemctl:

systemctl start pf_ring

Затем начните n2disk:

n2disk -o /storage -p 1000 -b 4000 -i fbcard:0:a00 -q 1 -C 1024 -c 1 -z 2 -w 3 -n 50 -m 100
