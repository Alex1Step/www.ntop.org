Как начать n2disk

Системы на базе Systemd

Служба n2disk управляется с помощью утилиты systemctl в операционных системах и дистрибутивах, использующих диспетчер служб systemd.

Файлы конфигурации

На одном компьютере могут одновременно выполняться несколько экземпляров n2disk. Обычно каждый экземпляр привязан к интерфейсу. Чтобы разрешить запуск разных экземпляров n2disk с независимыми конфигурациями, в каталоге сосуществуют несколько файлов конфигурации:

/etc/n2disk/

Каждый файл конфигурации начинается с «n2disk-» и заканчивается суффиксом, соответствующим имени интерфейса, с которым он связан. Например, если предположить, что два разных демона n2disk должны запускаться независимо для eth0 и eth4, должны присутствовать следующие файлы конфигурации:

# ls -lha /etc/n2disk/
4.0K -rw-r--r--   1 root root  211 Mar 15 17:54 n2disk-eth0.conf
4.0K -rw-r--r--   1 root root  195 Jan  8 17:17 n2disk-eth4.conf

Формат файла конфигурации

Файл конфигурации содержит те же параметры, которые в противном случае указаны в командной строке. Единственная разница между командной строкой и файлом конфигурации заключается в том, что в разных строках необходимо указывать разные параметры. Например:

n2disk -i eth0 -o /storage

то же самое, что:

n2disk /etc/n2disk/n2disk-eth0.conf

где :code`/etc/n2disk/n2disk-eth0.conf` содержит следующие строки:

 # cat /etc/n2disk/n2disk-eth0.conf
-i=eth0
-o=/storage

Автоматический запуск

Чтобы запустить, остановить и перезапустить службу типа n2disk:

systemctl start n2disk@eth0
systemctl stop n2disk@eth0
systemctl restart n2disk@eth0

Чтобы предотвратить запуск n2disk при типе загрузки:

systemctl disable n2disk@eth0

Или, чтобы запустить n2disk при загрузке, если он ранее был отключен, введите:

systemctl enable n2disk@eth0

Чтобы проверить статус службы, включая ее выходные данные и PID, введите:

systemctl status n2disk@eth0

системы на основе инициализации

Службой n2disk можно управлять в старых системах на основе инициализации с помощью скрипта, расположенного по адресу:

/etc/init.d/n2disk

Чтобы автоматически запускать демоны n2disk при запуске системы, в том же каталоге, что и файлы конфигурации, необходимо создать пустые файлы, заканчивающиеся на «.start».

# ls -lha /etc/n2disk
-rw-r--r--   1 root root  211 mar 15 17:54 n2disk-eth0.conf
-rw-r--r--   1 root root    0 mar 17 15:44 n2disk-eth0.start

Этими конфигурациями можно управлять с помощью сценария /etc/init.d/n2disk. Скрипт принимает на вход различные параметры и одно или несколько имен интерфейсов. Вызов сценария без параметров дает следующую краткую справку:

sudo /etc/init.d/n2disk

Usage: /etc/init.d/n2disk {start|force-start|stop|restart|status} [interface(s)]

Опции и использование сценария управления демоном обсуждаются ниже.

начинать

Эта опция используется для запуска демона n2disk для интерфейсов, имеющих файл «.start». Вызов start на интерфейсах с отсутствующими файлами «.start» приводит к ошибке. Например

# ls -lha /etc/n2disk
-rw-r--r--   1 root root  211 mar 15 17:54 n2disk-eth0.conf
-rw-r--r--   1 root root    0 mar 17 15:44 n2disk-eth0.start
-rw-r--r--   1 root root  195 Jan  8 17:17 n2disk-eth4.conf
# /etc/init.d/n2disk start eth0
Starting n2disk eth0
# /etc/init.d/n2disk start eth4
n2disk eth4 not started: missing /etc/n2disk/n2disk-eth4.start

принудительный запуск

Эта опция используется для запуска демона n2disk для экземпляров, у которых нет файла «.start». Вызов принудительного запуска на интерфейсе eth4, показанном в примере выше, не вызывает никаких ошибок, и демон запускается правильно.

# /etc/init.d/n2disk force-start eth4
Starting n2disk eth4

останавливаться

Эта опция используется для остановки экземпляра демона n2disk. Например

# /etc/init.d/n2disk stop eth4
Stopping n2disk eth4

перезапуск

Эта опция вызывает перезапуск демона, связанного с данным интерфейсом. Пример:

# /etc/init.d/n2disk restart eth0
Stopping n2disk eth0
Starting n2disk eth0

статус

Эта опция отображает статус демона, связанного с данным интерфейсом. Пример:

# /etc/init.d/n2disk status eth0

n2disk running
