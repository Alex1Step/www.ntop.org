Storage Sizing

This section provides some guidelines for sizing the disk according to the traffic throughput and desired data retention.

The table below highlights the minimum requirements for a storage able to dump traffic according to the sustained traffic throughput. Please note that medium/high end enterprise disks are considered, with high write throughput designed for endurance. RAID 0 is considered here, more disks are required with parity (e.g. with RAID 5/50/6).
