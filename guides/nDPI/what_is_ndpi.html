Что такое nDPI

nDPI — это набор инструментов DPI (глубокая проверка пакетов), способный:

  • Обнаружение протокола приложения в потоках трафика

  • Анализируйте потоки зашифрованного трафика через ET (анализ зашифрованного трафика)

  • Извлечь метаданные выбранного протокола из трафика

  • Внедрение API для анализа трафика

Релизы и возможности

nDPI Жизненный цикл разработки обычно составляет от 6 до 9 месяцев. История изменений и функций, реализованных в каждом выпуске, доступна на его Журнал изменений.

Установка

nDPI имеет открытый исходный код и доступен на GitHub. Кроме того, предварительно скомпилированные двоичные файлы Пакеты nDPI доступны как для Linux, так и для других платформ. Установка инструкции для бинарных пакетов доступны ниже.

Установка в Linux

Инструкции по установке можно найти на сайте http://packages.ntop.org/. Разработка и стабильные сборки доступен. Стабильные сборки предназначены для производственных сред, тогда как сборки для разработки предназначены для тестирования или раннего доступа к функциям.

Обновления программного обеспечения

Общие инструкции по обновлению программного обеспечения можно найти по адресу http://packages.ntop.org/ вместе с инструкцией по установке. В зависимости от операционной системы nDPI также поддерживает автоматические обновления. через GUI, как описано в разделах ниже.

Обновление программного обеспечения в Linux

Инструкции по обновлению программного обеспечения через командную строку можно найти в http://packages.ntop.org/. Например, в системах Ubuntu/Debian команды ниже обновят репозиторий, проверят наличие обновлений и установят последнее обновление программного обеспечения, если таковое имеется:

apt-get update
apt-get upgrade
