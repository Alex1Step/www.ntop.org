«tls»

«dpi.эвристика»,

0x00

0x00

0x07

Включите/отключите некоторые эвристики для обнаружения зашифрованных/запутанных/проксированных потоков TLS. Значение представляет собой битовую маску. Значения: 0x0 = отключено; 0x01 = включить базовое обнаружение (т. е. зашифровано TLS без какой-либо инкапсуляции); 0x02 = включить обнаружение более TLS (т.е. TLS-в-TLS); 0x04 = включить обнаружение через HTTP (т. е. TLS-через WebSocket). Если этот параметр включен, ожидаются некоторые ложные срабатывания. Видеть: https://www.usenix.org/conference/usenixsecurity24/presentation/xue-fingerprinting

«tls»

«dpi.heuristics.max_packets_extra_dissection»,

25

0

255

Если включена хотя бы одна эвристика TLS (см. tls»,dpi.эвристика», этот параметр устанавливает верхний предел количества требуемых/обработанных пакетов для каждого поток. Чем выше значение, тем ниже уровень ложных срабатываний, но для обработки требуется больше пакетов на nDPI.
