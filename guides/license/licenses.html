Управление лицензиями

Менеджер лицензий ntop позволяет вам управлять лицензиями на продукты ntop, такие как nprobe и ntopng. В этом разделе объясняется, как добавлять и настраивать новые лицензии.

Покупка лицензии

Первым шагом является покупка лицензии у https://shop.ntop.org. После покупки вы получите получите идентификатор заказа, который необходим для активации лицензии.

Создать новый лицензионный ключ

Для генерации лицензионного ключа вам понадобится:

  • Системный идентификатор (полученный через `ntop-license-manager -v`)

  • Идентификатор заказа (полученный после покупки)

  • Адрес электронной почты, использованный для покупки

  • Версия продукта (от `nprobe --version` или `ntopng --version`, например 10.2.240123)

Добавление новой лицензии

Лицензии должны быть помещены в `/etc/ntop/license_manager/`. При запуске менеджера лицензий он сканирует папку и загружает все действительные лицензии.

Если вам нужно добавить новые лицензии во время работы менеджера лицензий:

  1. Создайте новый файл в /etc/ntop/license_manager/ с новым уникальным именем.

  2. Добавьте свой лицензионный ключ в этот файл

  3. Горячая перезагрузка конфигурации менеджера лицензий с помощью следующей команды:

systemctl kill -s HUP ntop-license-manager

Проверьте перезагрузку, проверив журналы:

journalctl -u ntop-license-manager -f

Вы должны увидеть вывод, похожий на:

server systemd[1]: ntop-license-manager.service: Sent signal SIGHUP to main process 2401413 (ntop-license-ma) on client request.
server ntop-license-manager[2401413]: 31/Jan/2025 15:36:11 [Manager.cpp:25] Reloading licenses...
server ntop-license-manager[2401413]: 31/Jan/2025 15:36:11 [Manager.cpp:132] Scanning license directory /etc/ntop/license_manager
server ntop-license-manager[2401413]: 31/Jan/2025 15:36:11 [Manager.cpp:205] [VALID] License files verified successfully

Вывод журнала подтвердит, что ваши лицензии были загружены и успешно проверены.
