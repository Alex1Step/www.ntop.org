Install ntop software

Pick your system, pick what to install, copy the commands, run them once.

Which package do I need?

I want toInstallGuide
See every host and flow on one networkntopngInstall ntopng
Read NetFlow, IPFIX or sFlow from routersntopng + nProbeNetFlow quickstart
Collect flows only, feed another toolnProbeNetFlow quickstart
Monitor 10 to 100 Gbit mirror portsntopng + CentoCento quickstart
Run a gateway with policies and bandwidth controlnEdgenEdge quickstart
Record packets to diskn2diskn2disk product page
Capture traffic on remote hosts or VMsnTapnTap product page
Everything at onceAll ntop packagesPick “All ntop packages” below

Stable is for production. Dev is the nightly build for testing. Ubuntu 26.04 and Debian 13 are dev builds for now.
