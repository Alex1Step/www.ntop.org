Установите программное обеспечение ntop

Выберите свою систему, выберите, что установить, скопируйте команды и запустите их один раз.

Какой пакет мне нужен?

Я хочуУстановитьГид
Просматривайте каждый хост и работайте в одной сетиntopngУстановить ntopng
Чтение NetFlow, IPFIX или sFlow с маршрутизаторовntopng + nProbeNetFlow краткое руководство
Собирать только потоки, подать другой инструментnProbeNetFlow краткое руководство
ntopng + ЧентоКраткое руководство по Cento
Запустите шлюз с политиками и контролем пропускной способности.nEdgeКраткое руководство по nEdge
Запись пакетов на дискn2diskn2disk страница продукта
Захват трафика на удаленных хостах или виртуальных машинахnTapnTap страница продукта
