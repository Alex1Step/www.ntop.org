Часть первая – PF_RING

Если у вас уже установлен pf_ring, вы можете сделать:

судо rmmod pf_ring

Если вы не уверены, что у вас установлен pf_ring, вы можете сделать:

sudo modinfo pf_ring

Получите последние источники pf_ring:

экспорт svn https://svn.ntop.org/svn/ntop/trunk/PF_RING/ pfring-svn-latest

Скомпилируйте и установите PF_RING

Далее введите следующие команды для настройки и установки:

(!!! НЕ КОРЕНЬ !!!)

    cd pfring-svn-latest/kernel

сделать && sudo make install

cd ../пользовательская среда/lib

./configure –prefix=/usr/local/pfring && make && sudo make install

cd ../libpcap-1.1.1-кольцо

./configure –prefix=/usr/local/pfring && make && sudo make install

компакт-диск ../tcpdump-4.1.1

./configure –prefix=/usr/local/pfring && make && sudo make install

судо ldconfig

Затем загружаем модуль:

sudo modprobe pf_ring

Поднимите права root и проверьте, есть ли у вас все необходимое — введите:

modinfo pf_ring && cat /proc/net/pf_ring/info

Увеличьте скорость дроссельной заслонки модуля ixgbe:

modprobe ixgbe InterruptThrottleRate=4000

oisf/ &&  git clone https://github.com/ironbee/libhtp.git -b
0.5.х

Скомпилируйте и установите

./autogen.sh && LIBS=-lrt ./configure –enable-pfring –enable-geoip \

--with-libpfring-includes=/usr/local/pfring/include/ \

--with-libpfring-libraries=/usr/local/pfring/lib/ \

--with-libpcap-includes=/usr/local/pfring/include/ \

--with-libpcap-libraries=/usr/local/pfring/lib/ \

--with-libnss-libraries=/usr/lib \

--with-libnss-includes=/usr/include/nss/ \

--with-libnspr-libraries=/usr/lib \

--with-libnspr-includes=/usr/include/nspr \

&& sudo make clean && sudo make && sudo make install && sudo ldconfig

«LIBS=-lrt» перед «./configure» выше — на случай, если вы получите следующую ошибку без использования «LIBS=-lrt»:

checking for pfring_open in -lpfring... no

   from https://www.ntop.org/PF_RING.html

ПРИМЕЧАНИЕ: Когда одно приложение использует интерфейс DNA, никакое другое приложение не может использовать тот же интерфейс. Например, если у вас есть Suricata, работающий с этим руководством, и если вы захотите выполнить «./pfcount», вы не сможете это сделать, поскольку интерфейс DNA уже используется приложением. В тех случаях, когда вы хотите, чтобы несколько приложений использовали один и тот же интерфейс ДНК, вам следует рассмотреть Libzero.
