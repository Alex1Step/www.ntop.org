The recommendation

Who should choose nAnalyst

nAnalyst is an AI analyst layer for ntopng. Choose it when your problem is interpretation, not visibility: you want to ask questions in plain language and get queries, charts, evidence and suggested next steps, with your data staying on-premise.

  • Analysts spend hours investigating alerts and traffic.
  • You want policies written in plain language and turned into alerts.
  • You want to query ntopng from Claude Code, Cursor or any MCP client.

The ideal use case

Ideal use case for nAnalyst

  • Environment: ntopng deployments with flows, hosts, asset inventory, SNMP and alerts. Fully on-prem capable.
  • Team: network and security analysts, with usage and cost tracked per user and per model.
  • Technical requirements: ntopng Enterprise L with nAnalyst, and an LLM of your choice. Also available as an MCP server on ntopng.
  • Problem solved: faster traffic and alert investigation, with reasoning steps, tool calls and raw SQL visible, and a full action audit trail.

Ideal for Every Environment

Deployment scenarios

Traffic Investigation

In seconds, users go from raw traffic to insights and next steps.

  1. Question: “Show me DNS query volume for each hour in the last day and top queried domains”
  2. The agent collects DNS traffic data and hourly volume
  3. Generates a line chart embedded in the chat
  4. Reports a table of evidence and suggests next steps, e.g. “Investigate the two most contacted domains…”
Policy Generation & Alerting

From idea to detection to alerts in seconds.

  1. “No SSH for host 192.168.2.38 during business hours”
  2. The agent generates an SQL query, executed periodically (1 or 5 minutes, hourly, daily)
  3. An alert is generated if the policy is violated
  4. The agent runs the query, explains the result, and registers the alert

Complex policies such as “traffic 2x the hourly baseline” and similar behavioral rules are also supported.

Alert Investigation via MCP

nAnalyst is also accessible as an MCP server running on ntopng, with no additional installation required. Connect from Claude Code, Cursor, or any MCP client to interact with ntopng data directly, correlate alerts, and get full security assessments with recommended remediation steps.

The alternatives

nAnalyst alternatives, compared

Same criteria for each option: role, when to choose it, limits and cost.

Generic AI assistant
  • Role: Generic web search, not network-specific.
  • Choose it when: You only need general advice.
  • Limits: Black box, no audit trail, cloud only.
  • Cost: N/A
ntopng alone
  • Role: Dashboards and alerts.
  • Choose it when: You investigate manually.
  • Limits: Interpretation takes analyst time.
  • Cost: Community free

The tradeoffs

When nAnalyst is not the right choice

  • It extends ntopng and is not a standalone tool.
  • It needs ntopng Enterprise L.
  • Questions work in any language supported by your preferred LLM.
  • It can act on your behalf (policies, alerts), so use the audit trail to review actions.
